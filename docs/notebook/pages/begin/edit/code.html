编程代码

对于代码，可以如下录入： 

<pre tag="langName">
    代码
</pre>

其中langName表示代码语言，下面一一列举支持的配置。

不设置

如果你不确定你的代码，可以不设置。 

<pre tag>
    // todo
</pre>

运行效果： 

    // todo

html 

<pre tag="html">
<h2>标题</h2>
</pre>

运行效果： 

标题

css 

<pre tag="css">
.cls{
    color: red;
    font-size: 12px;
}
</pre>

运行效果： 

.cls{
    color: red;
    font-size: 12px;
}

javascript 

<pre tag="javascript">
   console.log("你好呀！");
</pre>

运行效果： 

    console.log("你好呀！");

xml 

<pre tag="xml">
<uses-permission android:name="android.permission.INTERNET" />
</pre>

运行效果： 

<uses-permission android:name="android.permission.INTERNET" />

此外，还支持这些语言（tag值）：

  • 网页相关：html、xml、css、javascript
  • 编程语言：python、java、go、c、kotlin
  • 数据格式：json、toml、sql、mysql、markdown（别名 md）
  • 脚本与终端：shell、bash、zsh

toml 与 bash 的着色规则同样适用于 ini、sh 这类相近格式。
