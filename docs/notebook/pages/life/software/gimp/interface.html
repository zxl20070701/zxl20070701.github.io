界面与快捷键

GIMP 的默认快捷键和 Photoshop 几乎一致（都是单键选工具），但有几个关键差异会让人不适应。这篇只讲「哪里不一样」，重复的按键不再赘述。

与 Photoshop 的主要差异

操作 Photoshop GIMP
取消选择 Shift+Ctrl+A Shift+Ctrl+A（相同）
取消选择（图层无选区时） Ctrl+D Ctrl+Shift+A，因为 Ctrl+D 在 GIMP 里是「取消选择边界」
全选 Ctrl+A Ctrl+A（相同）
自由选区（套索） L F
魔棒 W U
裁剪 C Shift+C（Shift+C 是剪裁，C 被分给柔化/锐化）
缩放 Ctrl+ +/- Z 切换缩放工具，再点击；或 Ctrl+ +/- 直接缩放
测量 Shift+R Shift+M
剪贴/复制为新图 Ctrl+Shift+V Ctrl+Shift+V 在 GIMP 里是「作为新图像粘贴」
显示/隐藏面板 Tab Tab（相同）
最容易踩的两个：Ctrl+Shift+A 才是取消选择，F 是自由套索不是 L。记错了会以为 GIMP 坏了。

工具快捷键

GIMP 的工具箱设计是单键直达，比 PS 需要配合工具组再按字母高效得多：

类别 按键与工具
选择类 R 矩形选择、E 椭圆选择、F 自由选择、U 魔棒、Shift+O 按颜色选择、I 剪刀
绘画类 P 画笔、N 铅笔、Shift+B 填充桶、G 渐变、E/Shift+E 橡皮擦、A 喷枪、K 墨水、Y MyPaint 笔刷
修复类 C 仿制图章、H 修复画笔、S 涂抹、Shift+U 模糊/锐化、Shift+D 减淡/加深
变换类 M 移动、Shift+C 裁剪、Shift+R 旋转、Shift+S 缩放、Shift+H 切变、Shift+P 透视、Shift+F 翻转、Shift+L 变形（Handles）、Shift+G 笼形、W 扭曲变形
其它 B 路径（钢笔）、T 文字、O 取色器、Z 缩放、Q 对齐与分布
几乎每个工具都有 Shift + 快捷键的备用绑定（GIMP 设计成单键冲突时用），比如 Shift+M 测量、Shift+F 翻转。记不住就按 / 搜索。

两个特别实用的快捷键

  • Shift+X：在最近使用的两个工具间来回切换。比如画笔和涂抹之间反复横跳，一键搞定
  • /：搜索所有动作，包括滤镜。3.0 起 GEGL 滤镜也能直接搜到，还能显示它在菜单里的位置

界面操作

操作 按键 说明
临时隐藏面板 Tab 全屏专注看图，再按恢复
呼出工具箱 Ctrl+B Tab 隐藏状态下临时唤出
放大 Ctrl + + 以鼠标位置为中心缩放
缩小 Ctrl + - 同上
适合窗口 Ctrl+Shift+J 显示完整图像
临时快速蒙版 Shift+Q 选区可视化，再按返回

Shift+Q（快速蒙版）是排查选区问题最有效的工具。按下后被选中区域会显示红色蒙版，一眼看清选区到底覆盖了什么。Photoshop 里对应的是 Q。

工具选项面板

GIMP 把所有工具参数集中在工具选项面板，这是它和 PS 最大的交互差异——PS 每个工具有自己的浮动面板，GIMP 全部集中在一处。

  • 点击工具箱图标本身（不是选工具，是打开选项）
  • Windows → Dockable Dialogs → Tool Options
  • 快捷键 Shift+Alt+T

常用参数集中在顶部：

  • 画笔大小/硬度：用 [ 和 ] 快速调节，Shift+[ / Shift+] 调硬度
  • D：恢复默认前景色/背景色（黑白）
  • X：交换前景色与背景色
  • Alt+点击颜色块：打开颜色选择器
  • Shift+拖拽前景色块：直接进入色轮调整
[ / ] 调笔刷大小在任何画笔类工具下都可用，不用去工具选项里拖滑块。这是从 PS 迁移过来最先要改的习惯。

画笔动态（笔刷手感）

GIMP 的画笔可以挂Dynamics（动态），让笔刷对手压、速度、方向产生响应，是手绘质感的关键：

Windows → Dockable Dialogs → 笔刷动态 → 新建编辑 → 把「Opacity」「Size」「Pressure」拖到编辑器里连线 → 在画笔工具选项里启用

工具选项里有一个 Enable Dynamics（启用动态） 勾选框（3.0 起直接放在工具选项里，不用再去动态列表里找「Dynamics Off」）。如果笔刷行为奇怪，第一件事就是检查它有没有被意外关掉。

自定义快捷键

编辑 → 键盘快捷键 打开配置界面，或在首选项的「键盘快捷键」里点「配置快捷键…」。操作方式：

在搜索框输入命令名 → 选中命令行，点击「快捷键」列 → 直接按想要的组合键

默认勾选「退出时保存快捷键」，改动会在关闭 GIMP 时自动写入。如果不想自动保存，取消勾选后需要手动点「Save」。按键冲突时 GIMP 会提示该组合已被哪个命令占用，可以覆盖或取消。

右键与中键行为

GIMP 允许自定义右键和中键的行为（PS 做不到），在首选项的 画布交互 → 修饰键 里设置：

可设行为 用途
右键 = 画笔 左手控制画笔、右手操作快捷键
右键 = 缩放画布旋转 快速摆正画布角度（绘画时很实用）
右键 = 菜单 恢复默认右键弹出菜单
中键 = 缩放/平移 传统三键鼠标用户
画布旋转是 GIMP 独有的优势。Windows → 图像 → 旋转画布可以把画布转到任意角度，配合「右键 = 旋转」几乎能替代 PS 的转动画布，非常适合画斜线、画对称构图。

界面显示相关

  • Windows → Hide Docks（Tab）：隐藏所有面板
  • Windows → Single-Window Mode：单窗口 / 多窗口切换
  • Windows → Reset Window Layout：面板乱了就用这个恢复默认
  • Windows → Recently Closed Docks：找回误关的面板
  • 颜色面板（Windows → Dockable Dialogs → 颜色）：可在 3.2 的 System 主题下自动跟随系统深浅色
深色模式下笔刷和字体预览会有强光刺眼问题。3.2 的笔刷和字体面板加了 「Use theme colors for preview」 开关，开启后预览色会跟着主题变，强烈建议打开。

常见问题排查

工具选项面板不见了

它可能被拖成了独立窗口，或者被折叠了。先按 Shift+Alt+T 找回；如果面板布局全乱，Windows → Reset Window Layout 一键恢复。

画笔突然「不听话」

检查三件事：工具选项里的 Enable Dynamics 是否被关闭、画笔是否选错（笔刷面板当前高亮的那个）、不透明度是否是 0（按 Ctrl+Shift+Z 恢复历史或直接重设）。

按快捷键没反应

多数情况是焦点不在画布上——焦点在某个输入框或面板时按键会被拦截。点击一下画布再试。另外检查 Tab 是否处于「隐藏面板」状态，或者当前工具的快捷键和你以为的不一样（用 / 搜索确认）。

颜色拾取不准

取色器（O）在 3.0 之后可以选择取样不同色彩空间。另外注意：如果开启了几何变换（旋转/缩放画布），取色器取的是变换后的坐标。要在原始像素上取色，先复位画布变换。

画布能无限放大吗

可以。首选项 系统资源 里控制最大内存占比，画布边长上限也能调。默认限制是 8192 像素，改大之前先确认内存足够。
