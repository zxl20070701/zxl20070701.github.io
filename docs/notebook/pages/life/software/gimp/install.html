安装与入门

GIMP 是自由软件里最成熟的图像编辑器，功能上足以替代 Photoshop 的绝大多数日常场景。它最大的优势是免费、无需账号、跨平台，以及脚本能力非常强（Python-Fu / Script-Fu），做批量处理比 PS 更省心。

下载与安装

官网 gimp.org 提供官方安装包。注意辨别：GIMP 基金会从 2021 年起不再使用 "GIMP" 作为产品名，部分下载页显示为 "GNU Image Manipulation Program"，是同一个软件。

平台 推荐方式 说明
Windows 官网下载 .exe 安装包 安装时可选是否关联图片格式；建议勾选，双击图能直接打开
macOS 官网下载 .dmg 注意区分 Intel 与 Apple Silicon 版本；右键打开可绕过 Gatekeeper 提示
Linux 发行版软件源 / Flatpak Flatpak 版启动命令是 flatpak run org.gimp.GIMP
macOS 从 3.2.6 版本开始改用官方直接构建的 .dmg，同时可以通过 Homebrew 和 MacPorts 安装（brew install --cask gimp），不再需要从第三方仓库折腾。

首次启动

3.0 之后 GIMP 启动会弹出一个欢迎对话框，可以在「创建 / Personalize」区域快速设置：

  • 图标主题：符号 / 彩色 / 传统
  • 主题：浅色 / 灰色 / 深色，以及跟随系统的 System 选项
  • 工具分组：把工具箱图标折叠成组，减少占用空间
  • 合并工具栏与菜单栏：释放顶部空间
偏好里还有一个Playground（实验特性）区域，默认隐藏。需要用 gimp --show-playground 启动才能看到，比如「Paint Select 画笔选区」这类新工具。稳定生产环境不建议开。

配置文件在哪

GIMP 首次运行会创建一个配置目录，所有偏好、笔刷、脚本、预设都在里面。备份和迁移只需要复制这个目录：

系统 路径
Linux ~/.config/GIMP/3.2/
Windows %APPDATA%\GIMP\3.2\（即 C:\Users\用户名\AppData\Roaming\GIMP\3.2\）
macOS ~/Library/Application Support/GIMP/3.2/

目录结构大致如下，值得认识一下，因为改配置和装插件都要用到： 

~/.config/GIMP/3.2/
├── gimprc              # 主配置文件
├── toolrc              # 工具选项（笔刷大小等）
├── unitrc              # 颜色单位
├── parasites-filterrc  # 特殊格式插件（文件浏览器扩展）
├── plug-ins/           # 插件文件放这里
├── scripts/            # 脚本文件放这里
├── brushes/            # 自定义笔刷
├── gradients/          # 自定义渐变
├── palettes/           # 自定义调色板
├── patterns/           # 自定义图案
└── fonts/              # 私有字体
删掉这个目录 = 重置所有设置，GIMP 会重新初始化。如果遇到无法解决的界面错乱或插件导致崩溃，这是最干净的重置方式（前提是先备份）。

核心概念

GIMP 的概念模型和 Photoshop 基本一致，但有几个用词差异，初学时不适应的话容易卡住：

Photoshop GIMP 说明
画板 / 文档 图像（Image） GIMP 一个 image 可以有很多 layer
图层（Layer） 图层（Layer） 相同；3.2 起支持图层组和嵌套
形状蒙版 / 图层蒙版 图层蒙版（Layer Mask） 都靠黑色隐藏、白色显示
通道（Channel） 通道（Channel） 3.0 起通道也能挂非破坏性滤镜
剪贴蒙版 图层组 + Pass Through GIMP 没有直接对应功能，用「穿透」组模拟调整图层
智能对象 链接图层（Link Layer） 3.2 新增，类似 PS 的链接智能对象，外部文件改动会同步
形状图层 矢量图层（Vector Layer） 3.2 新增，路径自带描边和填充

文件格式

GIMP 的原生格式是 XCF，它和 PSD 一样能保存图层、蒙版、路径。保存工作成果一定要用 XCF，导出成 PNG/JPG 会丢失所有图层信息。

操作 快捷键 结果
保存 Ctrl+S 存成 .xcf，可重复覆盖
另存为 Ctrl+Shift+S 换个文件名或位置存 XCF
导出 Ctrl+E 按原文件名导出（第一次会问格式）
导出为 Ctrl+Shift+E 换名字或格式导出，可转 JPG/PNG/WebP 等
「保存」和「导出」是两件独立的事。Ctrl+S 永远存 XCF，Ctrl+E 才是导出图片。新手最常见的困惑就是「保存完发给别人却只有一张图」，因为该用导出。

首次界面速览

GIMP 默认是单窗口模式（3.0 起的默认），所有面板集中在主窗口内：

区域 快捷键打开 用途
工具箱 Ctrl+B 左侧工具栏，Tab 可临时隐藏所有面板
图层对话框 Ctrl+L 核心面板，几乎全程都要用
工具选项 点击工具图标 画笔大小、硬度、不透明度等，所有工具参数都在这里
历史记录 Windows → Dockable Dialogs GIMP 的撤销史是线性且可无限回溯的，比 PS 的历史记录板更好用
界面被弄乱了可以 Windows → 隐藏 docks（Tab）临时清空再恢复，或者 Windows → Reset window layout 恢复默认布局。单窗口 / 多窗口模式也可以在首选项里切换，老用户更习惯多窗口。

退出前确认

GIMP 的未保存提示不如 PS 醒目，关之前留意几点：

  • 标题栏带 * 或 ! 表示有未保存改动
  • 记住 XCF 才是保存，导出成 JPG 不会保留可编辑状态
  • 「单窗口模式下关闭标签页」会提示是否保存，别一路点忽略
