图层与蒙版

GIMP 3.0 之后最大的变化就是非破坏性（Non-Destructive）工作流：滤镜不再直接烙进像素，图层组、矢量图层、链接图层都可以反复编辑。这篇是 GIMP 里最值得花时间掌握的一块。

图层基础

和 Photoshop 基本一致，几个值得注意的差异：

操作 快捷键 说明
新建图层 Ctrl+Shift+N 弹窗选项和 PS 很像
复制图层 Ctrl+Shift+D 注意 PS 是 Ctrl+J
上移/下移一层 Ctrl+] / Ctrl+[ 相同
上移/下移到顶/底 Ctrl+Shift+] / Ctrl+Shift+[ 相同
合并可见图层 Ctrl+M 相同
选中上方/下方图层 PageUp / PageDown 相同
悬停预览图层 无默认键 GIMP 特有：鼠标悬停即临时显示该图层，不影响实际激活项
悬停预览是 GIMP 比 PS 顺手的地方——想看某个隐藏图层的内容，鼠标移上去就行，不用点它激活、再点回去取消隐藏。

图层组与穿透模式

GIMP 从 3.0 开始支持图层组，而且支持无限嵌套。组的价值在于整体管理和承载效果。

Pass Through（穿透）

这是 GIMP 特有的混合选项，也是实现 PS「调整图层」的关键：

组模式 行为
Pass Through（穿透） 组内图层和组下方的图层一起参与混合。挂在组上的滤镜会影响到组外
Normal 等其它模式 组先合成一个整体，再与下方混合，效果被限制在组内

用穿透组做调整图层的标准流程：

新建一个空图层组，模式设为 Pass Through → 在组内新建一个调整用的 GEGL 滤镜效果 → 效果会自动作用于组下方所有像素

3.2 进一步明确了这个用法：空的穿透组 + NDE 滤镜 = 传统软件的调整图层。同组上可以叠加多个滤镜组合出复杂效果，效果不限于组内。

组的其它能力

  • 整体调不透明度：组不透明度会把组内所有图层一起压暗
  • 整体改混合模式：Normal 模式下组可当容器，Pass Through 则向外延伸
  • 组内可以放组：没有嵌套层数上限，只受内存限制

图层蒙版

GIMP 的图层蒙版逻辑和 Photoshop 一致：黑隐藏、白显示、灰半透明，不影响原始像素。

添加蒙版的几种方式

图层 → 蒙版 → 添加图层蒙版（无默认快捷键）会打开一个对话框，这比 PS 多给了几种初始化方式：

初始化方式 效果 用途
白色（全不透明） 全部显示 从零开始擦
黑色（全透明） 全部隐藏 从零开始画显示区域
图层的 Alpha 通道 用现有透明度生成，会加深半透明区域的透明 不太常用
转移图层的 Alpha 通道 同上，但重置 Alpha 为全不透明，外观不变 从已有透明度的图层生成蒙版
选区 选区为白，未选为黑 最常用，先选后加
图层的灰度副本 用图层亮度生成 为后续叠加内容做准备
通道 用已存的通道生成 复用之前存好的蒙版
从 Photoshop 迁移过来最直接的对应关系：Alt+点击蒙版按钮（PS）≈ 在对话框里选「Selection」（GIMP）。选区初始化是两边都最常用的方式。

蒙版相关操作

  • 在图层面板上右键蒙版缩略图 → 应用图层蒙版：把蒙版烧进像素，不可逆
  • 停用图层蒙版：临时关闭效果，可对比
  • 显示图层蒙版：单独查看蒙版内容
  • 蒙版转选区 / 添加到选区 / 从选区减去 / 与选区交叉：四种组合运算
  • 删除蒙版：图层对话框里右键蒙版缩略图 → 删除图层蒙版
3.0 之后所有这些蒙版命令都支持多选同时操作——可以一次给多个图层加蒙版、一次应用全部蒙版。这是 3.0 新增的多选能力带来的直接好处。

常用绘制技巧

  • 选蒙版面板后，Ctrl+点击前景/背景色可直接把黑白填进蒙版
  • Shift+X 交换前景色和背景色，在黑白之间快速切换
  • 蒙版上用柔边画笔处理边缘，硬度调低到 20-40

非破坏性滤镜（NDE）

这是 GIMP 3.0 的核心特性，也是和 2.10 差别最大的地方。在 2.10 里，滤镜一旦应用就烙进像素，想改参数只能反复撤销；3.0 之后默认行为是滤镜保持激活、可反复编辑。

应用滤镜后，图层面板会出现滤镜效果堆栈： 

图层：背景
  └ 效果：亮度-对比度 → 曲线 → 高斯模糊
     ↑ 可单独开关、删除、重排序

能做什么

  • 双击效果图标 → 重新打开参数对话框，随时改数值
  • 点击效果左侧的眼睛图标 → 临时开关单个滤镜
  • 右键 → 删除效果 → 只删这一个，保留其他
  • 右键 → 合并滤镜（Merge Filters） → 一次性烘焙成像素，回到传统行为
  • 保存到 XCF 后重新打开，滤镜设置依然保留可编辑
想要 PS 那种「滤镜烙进像素」的确定感？在应用滤镜时选 Merge Filters，而不是保持 NDE 状态。做一次性素材时这样更干净，避免一堆效果堆栈让文件变大。

找到 GEGL 滤镜

GIMP 的滤镜分两套系统：

类型 说明
GEGL 操作 底层运算引擎，滤镜基础都来自这里
GIMP 滤镜 传统菜单滤镜，基于 GEGL 或脚本实现

搜索 GEGL 滤镜的两种方式：

按 / 打开搜索对话框，输入滤镜名 → 结果会显示菜单位置和帮助按钮

或者用 工具 → GEGL 操作，它是一个工具形态的滤镜浏览器，可以并排比较不同滤镜的参数效果。

按 / 是找滤镜最快的路径——比在十几层菜单里翻找快得多。搜索结果里直接标出了「这个滤镜在菜单的哪个位置」，还能点帮助按钮看说明。

矢量图层（3.2 新增）

3.2 终于把「路径」升级成了真正的图层。用路径工具（B）画出路径后，在路径对话框点「转换为矢量图层」，就得到一个带描边和填充的矢量图层：

  • 形状随路径自动更新：改路径，图层跟着变
  • 描边宽度、颜色、填充都可独立编辑
  • 可以非破坏性地旋转、缩放、变换
  • 把颜色或图案色块拖到图层上即可改填充
需要破坏性编辑时用 Rasterize（栅格化） 转为普通图层，之后可用 Revert Rasterize 撤回。矢量图层和文字图层、链接图层一样支持这组往返操作。

链接图层（3.2 新增）

链接图层（Link Layer）类似 Photoshop 的「链接智能对象」：把外部文件（如 SVG）链接进合成，外部文件在别的软件里改动，GIMP 会自动更新。

文件 → 作为链接图层打开（Open as Link Layer） → 选择外部文件（如 Inkscape 存的 SVG） → 在 Inkscape 里编辑并保存 → 回到 GIMP，内容已同步

更换链接的文件：双击图层打开图层属性对话框，或图层菜单 → 编辑图层属性。

SVG logo 用链接图层 + Inkscape 是很爽的组合：logo 保持矢量无损，编辑实时同步。做品牌物料时比来回导出 PNG 方便得多。

文字图层

GIMP 的文字图层也是非破坏性的，3.0 起做了不少改进：

  • 字体识别更准：能区分同字体家族内的不同字重，显示真实的粗体/斜体而非「合成效果」
  • 文字颜色支持浮点精度，配合广色域色彩空间不再有色彩断层
  • 非破坏性描边：直接在工具选项里设描边宽度、样式、颜色
  • 3.2 支持描边方向：内描边 / 外描边 / 居中
  • 画布上的文字编辑器可以拖动移开，缩放时不想被挡住就拖到一边
  • 编辑器内支持 Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+Shift+V 粘贴无格式文本

矢量图层、链接图层、文字图层统称为非破坏性图层，都可以挂 GEGL 滤镜，都用 Rasterize / Revert Rasterize 往返。

调整图层

GIMP 没有 PS 那种独立的「调整图层」类型，但有两个实现路径：

方式一：穿透组 + NDE 滤镜（推荐）

新建空图层组，设为 Pass Through → 组内用 GEGL 操作添加曲线/色平衡等 → 效果作用于组下方所有内容

这种方式的优势是组可以随意移动位置，且能叠加多个滤镜组合，效果完全可回溯。

方式二：纯色填充层 + 蒙版

用纯色填充或渐变填充图层，混合模式设为叠加/柔光等，再用蒙版控制范围。这是 PS 剪贴蒙版的等价做法。

两种方式可以叠加使用：穿透组做大范围色调，填充层+蒙版做局部强调。关键是记住穿透组是「向下影响」，只能作用于组下方，插错位置是新手最常见的问题。

合并与整理

GIMP 的图层数多起来同样会卡，但清理逻辑比 PS 简单——因为滤镜是堆栈，删掉效果不影响像素：

  • 图像 → 合并可见图层（Ctrl+M）：只合并可见图层
  • 图像 → 展平图像：合并全部并丢 alpha 通道
  • 不想合并图层时，可只删掉不用的滤镜效果来减负，效果删了像素不变

另外 GIMP 有图层组（Layer Set）功能（3.0 新增），可以在同一个文档里分门别类放多个图层组切换显示，类似 PS 的图层组管理。配合图层搜索，找层更方便。

常见问题排查

「很多操作都做不了」

按官方文档的说法，第一个要查的是是否存在浮动选区（Floating Selection）。有浮动选区时，大部分操作都会被阻止：

按 Ctrl+L 打开图层面板，看最上层是否是「Floating Selection」 → 右键 → 锚定图层（Ctrl+H） 或 → 右键 → 转为新图层（Ctrl+Shift+N）

滤镜列表是空的 / 找不到滤镜

按 / 搜索能直接搜到 GEGL 操作，包括第三方滤镜。如果搜不到，检查图层是不是文字/矢量这类非破坏性图层（它们支持滤镜但列表可能为空），或者是否装了第三方滤镜但没装 GEGL 依赖。

蒙版画了没反应

检查：画笔颜色是否为黑/白、是否误点了「停用图层蒙版」、图层不透明度是否为 0。GIMP 特有的一种情况是画笔的 Dynamics 被意外关闭——工具选项里的 Enable Dynamics 勾选框要确认是勾上的。

穿透组没有影响下方

两种可能：组不是 Pass Through 模式（点开组看混合模式）；或者效果加在了组外的图层上。穿透只对组内的滤镜生效，且只向下延伸。

应用蒙版后想反悔

用历史记录回退。GIMP 的历史记录是线性且可无限回溯的（受首选项里「最小撤销级别」和内存限制影响），比 PS 的历史记录板更可靠。这也是 GIMP 里应该大胆尝试的原因。

合成半透明边缘发灰

从 PS 迁移过来常见的遗留问题。修法一样：在新背景上加一层混合模式为 Multiply（正片叠底） 的图层，把主体副本放上去，让半透明边缘重新与背景融合。注意 GIMP 里「正片叠底」叫 Multiply，而 PS 的「滤色」在 GIMP 里叫 Linear Dodge（线性减淡）。
