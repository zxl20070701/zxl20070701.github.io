选区与抠图

GIMP 的选区逻辑和 Photoshop 完全一致：选区只是「哪些像素会被后续操作影响」的标记，本身不改图像。差异主要在工具命名和快捷键上。

基础操作

操作 快捷键 说明
全选 Ctrl+A —
取消选择 Shift+Ctrl+A 与 PS 相同
取消选择边界 Ctrl+D GIMP 特有：取消「虚线边界」显示，选区本身仍在
浮动选区 Ctrl+Shift+L PS 里是 Shift+Ctrl+L，位置刚好换了一下
反选 Ctrl+I PS 里 Ctrl+I 是反相（蒙版），GIMP 里是反选
羽化 Shift+F6 相同
缩放选区 Shift+F6 后调整 GIMP 羽化对话框里能同时设定羽化半径和扩展量
变换选区 无默认键 选择 → 变换选区
快速蒙版 Shift+Q PS 里是 Q
Ctrl+D 与 Shift+Ctrl+A 的区别是 GIMP 新手最常混淆的点：Ctrl+D 只是把边界虚线藏起来（选区还在），Shift+Ctrl+A 才是真的清空选区。养成按 Shift+Ctrl+A 的习惯。

四种选区模式

和 PS 相同的四种组合方式，在选区工具状态下用图标或快捷键切换：

模式 快捷键 行为
新选区 默认 替换原选区
添加到选区 Shift 并集
从选区减去 Alt 差集，用于挖洞
与选区交叉 Shift+Alt 交集

更方便的做法是按住 Shift 拖拽任意选区工具，直接进入加选状态，不用管当前是哪个图标。

选择工具对照

工具 快捷键 说明

前景选择值得重点说

这是 GIMP 相对 PS 的一个优势工具。它基于机器学习模型，能自动识别主体边缘，包括一些 PS 处理不好的软边、半透明区域。官方文档也提醒：它很吃内存，大图上容易变慢甚至崩溃。

流程比想象中多一步，必须先手动画一个粗略轮廓把主体圈出来：

选择 → 前景选择 → 像自由套索一样沿主体画一圈（留一点背景），起点变黄时点击或双击闭合 → 按 Enter 或在圈内双击，进入笔刷状态 → 用画笔在主体上涂几笔标记「要保留」 → Enter 预览 / 再按 Select 确认

三个绘制模式

模式 作用
绘制前景 画到的地方算主体，会被保留
绘制背景 画到的地方排除，用来去掉误选的背景
绘制未知 在轮廓外的「未知区」里画，扩展选区到圈外，补上漏掉的部分

预览模式切到 Grayscale（灰度） 时，看到的就是最终的灰度蒙版效果，和图层蒙版一致。主体与背景颜色接近时用灰度预览更容易分辨。

两个容易踩的点：一是必须先闭合轮廓才能进入笔刷阶段，起点处鼠标变黄就是闭合信号；二是Matting Levin 引擎在 Windows 上暂时被移除（因崩溃），只能用 Matting Global，后者速度快但精度略低。大图上可以把 Levels 调高来换速度。

魔棒的容差

容差（Tolerance） 默认值 32，表示颜色相似度阈值。与 PS 逻辑相同：太小选区断裂，太大连带背景。按住 Shift 加选、Alt 减选，可多区域累积。

通道

GIMP 的通道面板（Windows → Dockable Dialogs → 通道）和 PS 概念一致，但有一个 3.0 新增的重要能力：

GIMP 3.0 起，通道也能挂非破坏性滤镜。这意味着你可以对 Alpha 通道做模糊而不影响颜色，比 PS 只能在外挂滤镜里折腾方便得多。

通道选区的标准工作流

通道的真正用途是精细处理半透明边缘。以头发抠图为例：

先用前景选择/魔棒粗选出主体 → 选择 → 转子为通道（Shift+Ctrl+C） → 在通道面板用柔边黑白画笔涂抹发丝区域 → 重复涂抹加深，过渡到半灰 → 转回选区（Shift+Ctrl+V） → 用这个选区生成图层蒙版

通道能处理 PS 的选区做不到的事：连续的灰度过渡。选区只有「选中/不选中」两种状态（加羽化算例外），通道是完整的灰度图，所以能表达发丝那种半透明质感。

常用通道命令

  • 选择 → 转子为通道（Shift+Ctrl+C）：把当前选区存进通道
  • Shift+拖拽通道：快速建立多选区（PS 的同款技巧）
  • 选择 → 从通道建立选区（Shift+Ctrl+V）：反向使用
  • 通道可以取反、羽化、阈值化，做精细控制

路径与钢笔

钢笔工具在 GIMP 里快捷键是 B（PS 是 P），和「画笔（Brush）」撞了：

  • B：钢笔/路径工具
  • P：铅笔（Pencil）
  • Shift+B：油漆桶填充

路径转选区

GIMP 3.2 之前，路径和选区的转换比较绕；3.2 有了矢量图层之后顺畅很多：

用钢笔画好路径，闭合 → 路径面板 → 右键 → 转换为矢量图层 → 对该图层右键 → 栅格化（如需） → 再用图层蒙版控制显隐

直接从路径建立选区：路径面板菜单 → 路径转选区。未闭合的路径也可以转，GIMP 会自动用直线连接起终点。矢量图层还支持拖拽颜色/图案到图层上改填充，和 PS 的形状图层操作一致。

路径与文字

路径面板里的路径可以指定给文字图层，让文字沿路径排列。和 PS 不同的是，GIMP 的文字沿路径不做自动变形（PS 的「变形」那样），路径只控制基线方向。

抠边缘

GIMP 没有 PS 的「选择并蒙版」智能半径那一套，但有几个对应的工具：

羽化扩展

选择 → 羽化（Shift+F6）的对话框有两个参数，比 PS 单一半径更灵活：

  • 羽化半径：边缘过渡的宽度（像素）
  • 扩展量：整体向外或向内偏移，用来吃掉背景残留
「扩展量」是 GIMP 的独门参数：羽化同时向外扩、边缘更干净但会吃掉主体细节；负值则向内收，保护主体但留背景色。配合使用比单纯调半径精细得多。

生长 / 收缩

  • 选择 → 生长：选区向外扩 1-4 像素，用于防止边缘残留背景色
  • 选择 → 收缩：向内收，用于消除多余的半透明羽化
  • 选择 → 边界锐化：把过渡区收紧成硬边，避免蒙版上的灰边

去除杂边

抠完在白底上能看到一圈灰边或彩边，就是杂边。处理办法：

选区完成后，菜单栏右侧的「选择 → 去除杂边」类命令 或 Windows → Dockable Dialogs → 颜色拾取器，把前景色设为背景色 → 在选区内用油漆桶（Shift+B）填充

半透明边缘（头发、纱、玻璃）不要指望一步抠干净。正确做法是保留灰度信息：在通道里画出过渡，再转成蒙版。硬去黑边只会让边缘看起来假。

合成时的边缘发灰

这是从 PS 迁移过来最常见的遗留问题。修法和新背景有关：

  • 在新背景上新建一层，混合模式设为 Multiply（正片叠底）
  • 把抠好的主体层复制一份放上去
  • 边缘的半透明像素会重新与背景色融合，灰边消失

这就是 PS 里的「色彩加深」技巧，只是 GIMP 的模式叫 Multiply。

实战流程

一键抠主体换背景

选择 → 前景选择，先沿主体画一圈闭合轮廓 → Enter 进入笔刷状态，涂几笔标记主体 → Shift+F6 羽化 + 扩展量微调 → 图层 → 蒙版 → 添加图层蒙版，选「选区」 → 在蒙版上用黑白画笔修边缘 → 添加新背景图层

抠半透明主体（头发/纱）

粗选出主体 → 转子为通道 → 柔边画笔刷出发丝灰度 → 转回选区生成蒙版 → 换背景后用 Multiply 修灰边

抠硬边（产品/logo）

钢笔（B）画路径，闭合 → 路径转选区 → 羽化 0.5-1px → 生成蒙版

保留阴影抠商品

前景选择只涂商品不涂阴影（闭合轮廓时也把阴影排除） → 生成蒙版 → 在蒙版上用软笔刷把阴影刷回来（灰色即半透明）

常见问题排查

操作没反应 / 大部分命令点不动

检查是否有浮动选区（Floating Selection）。这是 GIMP 官方的「卡住」排查手册里的第一条。处理：Ctrl+H 锚定或 Ctrl+Shift+N 转为新图层。

操作只作用在一小块

选区还残留。按 Shift+Ctrl+A 清空，或按 Shift+Q 打开快速蒙版确认选区范围。

边缘出现「锯齿」

硬选区直接删除的结果。修法是在删除前 Shift+F6 羽化 1-2px，或用 选择 → 边界锐化 先收一下再去黑边。

抠完边缘有彩边

没有处理杂边。用 选择 → 生长 往外扩一点把背景像素包进去，或者在通道里手动画灰度过渡。彩边通常在纯色背景上最明显，换个复杂背景验证一下就知道是否真的干净。

魔棒选不中

背景不连续或有渐变时容差要求太大。用前景选择（机器学习）替代，或者在通道里按亮度手动画选区，通常更可靠。

羽化后蒙版边缘发灰

这是正常现象——羽化本就是要有过渡。问题在于合并到新背景时灰边显脏，用 Multiply 那招修正即可。
