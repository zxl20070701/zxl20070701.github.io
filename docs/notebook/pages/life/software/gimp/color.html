滤镜与调色

GIMP 的滤镜体系在 3.0 发生了根本变化：底层统一到 GEGL，并且默认非破坏性。调色思路和 Photoshop 基本一致，但工具位置和实现方式差别不小。

GEGL 是什么

GEGL（Generic Graphical Library）是 GIMP 的图像处理底层引擎。理解这一点能解释很多现象：

  • 菜单里的绝大多数滤镜，本质都是 GEGL 操作的封装入口
  • 有些 GEGL 操作没有菜单入口（实验性或不重要），需要通过 GEGL 工具访问
  • 第三方开发者写的新滤镜也会出现在同一个列表里

访问全部 GEGL 操作：工具 → GEGL 操作。这个对话框支持画布实时预览，可以并排比较不同参数的效果，比菜单滤镜更适合探索。

找滤镜最快的路径是按 / 打开动作搜索。3.0 起可以直接搜到 GEGL 操作（包括第三方滤镜），而且结果会显示它在菜单里的位置，还能点帮助按钮看说明。

非破坏性滤镜

这是 GIMP 3.0 最重要的行为变化。应用滤镜后，效果会出现在图层面板下方的滤镜堆栈里，而不是烙进像素：

堆栈能做什么

  • 双击效果 → 重新打开参数对话框，随时改数值
  • 眼睛图标 → 单独开关某个效果
  • 右键 → 删除 → 只删这一个，不影响其它
  • 右键 → 重新排序 → 调整滤镜执行顺序
  • 右键 → 合并滤镜 → 一次性烘焙成像素

保留到 XCF

非破坏性滤镜的设置会随 XCF 一起保存，下次打开还能继续编辑。这意味着可以把 XCF 发给同事，对方打开后还能调整你的调色参数——这是 PS 做不到的（PS 的智能滤镜只在智能对象上部分支持）。

用「合并滤镜」烘焙时会提示第三方滤镜可能被丢弃——因为那些滤镜在对方机器上不一定装了。纯 GEGL 内置滤镜则完全没问题。

调色顺序

和 Photoshop 一样的逻辑（详见 Photoshop 的《调色与滤镜》一篇），GIMP 下的对应关系是： 

① 色彩空间 / 白平衡    → 图像 → 色彩管理
② 色阶 / 曲线          → 颜色 → 亮度-对比度、色阶、曲线
③ 色相饱和度 / 色彩平衡 → 颜色菜单
④ 锐化                → 滤镜 → 增强 → 锐化
⑤ 输出                → 文件 → 导出为
锐化永远放最后，它会放大前面所有的噪点和压缩瑕疵。这条在哪个软件里都一样。

常用调色工具

亮度-对比度

颜色 → 亮度-对比度。GIMP 的实现与 PS 有一处重要差别：它的对比度滑块以中灰为轴对称调整，会同时影响亮部和暗部。想只压暗部或只提亮部，用曲线更可控。

色阶 / 曲线

颜色 → 色阶 和 颜色 → 曲线。逻辑与 PS 一致：

  • 色阶：拖黑白场修反差，拖灰场改整体明暗
  • 曲线：S 形加对比，暗部左下上提做「胶片感」，可分 RGB 通道调

GIMP 的曲线工具支持在对话框里直接显示直方图，边调边看分布，比 PS 更直观。

色相/饱和度/明度

颜色 → 色相-饱和度。默认是全图调整，但可以勾选「分范围调整」（GIMP 里叫 Master/Red/Yellow/Green/Cyan/Blue/Magenta 分档）分别调某个颜色区间。

调整人像肤色时：切到 Red 档，色相往橙推一点、明度略提。黄色档降饱和去黄。这套逻辑和 PS 的 HSL 一致，只是入口不同。

色彩平衡

颜色 → 色彩平衡，按阴影/中间调/高光三段加冷暖，用途与 PS 相同：阴影加蓝让风光通透，高光加黄模拟暖阳。

黑白转换

颜色 → 灰度 直接去色；更好的做法是 颜色 → 色度饱和度 把饱和度拉到 0，同时保留明度细节。

GIMP 在这一点上弱于 PS——它没有 PS 那种能分别控制六个颜色范围明暗的「黑白」调整图层。需要精细控制黑白时，得用通道混合器逐个调 RGB 通道，或者在通道里按亮度手动画曲线。

色调映射

颜色 → 色调映射 是 GIMP 的独门工具，用来把 HDR/高动态范围图像压缩到普通范围，保留高光和暗部细节。做风景和 HDR 照片时很有用，PS 里没有直接对应的功能。

修复类工具

GIMP 的修图工具比 PS 更底层，也更直白。它们都是直接改像素的（不参与非破坏性堆栈）：

工具 快捷键 用途
修复画笔 H 像 PS 的污点修复画笔，自动采样周边像素
仿制图章 C 手动指定源位置复制，PS 里也是 C
Heal/接缝 — 纹理合成算法，效果比仿制图章自然
涂抹 S 取样周围颜色推抹，用于柔化
减淡/加深 Shift+D 压暗/提亮局部
模糊/锐化 Shift+U 局部处理，PS 里是同一个键
仿制图章用 Ctrl+点击 设置源点，然后 Alt+点击 切换成 Clone（对齐） 模式——源点会跟着你涂抹的位置一起移动。这是 PS 用户最容易忽略的开关，开了之后连续涂抹才不会「拉丝」。

修复工具的坑

官方文档里提到一个已知问题：修复画笔在涂抹超出图层边界时可能产生深色污渍。规避方法是先把图层扩大到和画布一样大（图层 → 图层边界大小 → 图层边界），再执行修复。

常用滤镜

高斯模糊

滤镜 → 模糊 → 高斯模糊。GIMP 3.0 起它是 NDE 滤镜，会进入堆栈可以反复调。它还是 3.2 新增的可编辑渐变工具的依赖项。

用法和 PS 一样：高斯模糊 + 渐变蒙版 = 景深/投影。或者放在图层下方，用纯色层盖住原图做柔和投影。

锐化

滤镜 → 增强 → 锐化（Unsharp Mask）。三个参数：

  • 半径：边缘检测范围，一般 1-3 像素
  • 数量：锐化强度，从 30%~50% 起步
  • 阈值：多大的差异才算边缘，防噪关键，调到 3-5 避免锐化噪点
GIMP 的默认值偏激进，容易把 JPEG 压缩瑕疵一起放大。阈值一定要调，这是 GIMP 锐化和 PS 锐化最大的实践差异。

其它值得知道的滤镜

  • 滤镜 → 扭曲 → 波浪：GIMP 独有的强效扭曲，比 PS 的同款更彻底
  • 滤镜 → 渲染 → 云朵 / 分形棕榈：程序化生成纹理，比 PS 的同类更强大
  • 滤镜 → 风格化：描边、浮雕、油画等，逻辑与 PS 相同
  • 滤镜 → 开发：随机噪点、差值等，调试利器

重复与重显上次滤镜

  • Ctrl+F：用相同参数重复上一次的滤镜
  • Ctrl+Shift+F：重新打开上一次的滤镜对话框（改参数用这个）

这两个快捷键和 Photoshop 一致，是批量处理同类图片时最省时间的组合。

色彩管理

GIMP 3.0 起重做了色彩管理，支持广色域 RGB 空间（不止 sRGB）：

图像 → 色彩管理 → 配置显示器 → 选择或获取显示器 ICC 配置文件

显示器校色是所有调色的前提。未校色的显示器上看到的颜色是不可信的，此时无论怎么调参数都是白调。这个优先级高于本文所有技巧。

软打样（Soft-Proofing）的开关在状态栏右下角，可以切换到目标印刷色彩空间预览。打开带 AdobeRGB 配置的图，GIMP 会保留色彩空间信息不丢失——这在 PS 里也支持，但 GIMP 的实现同样彻底。

非破坏性工作流的构建

把前面的工具组合起来，就是一条完整的 GIMP 调色链路：

新建图层组，混合模式设为 Pass Through → 组内加色阶/曲线（用 / 搜索 GEGL 操作） → 再加一个色相-饱和度 → 组下方是需要调色的图层

效果会作用到组下所有内容，且每一步都能双击回去改。这是 GIMP 3.0 之后最值得掌握的调色方式，比 PS 的调整图层更灵活（因为穿透组能移动、能叠加）。

常见问题排查

滤镜列表里找不到想要的

按 / 搜索。如果确实没有，去 工具 → GEGL 操作 里找——有些操作没有菜单入口但在这里能访问到。

应用滤镜后无法修改参数

检查是否用了「合并滤镜」把效果烘焙成了像素。用过之后只能撤销。如果是想得到确定的结果而烘焙，注意第三方滤镜在别人机器上可能无法重现。

滤镜太慢或崩溃

大图上 GEGL 运算很吃内存和显存。处理办法：先用 GIMP 裁剪工具把处理区域缩小（图像大小而不是裁剪，这样像素还在），处理完再放回去。滤镜库里的高斯模糊半径很大时会明显变慢。

锐化后噪点变多

阈值参数没调。GIMP 默认值会把噪点当成边缘来锐化。把阈值调到 3-5，只锐化真正的轮廓。

颜色在不同设备上不一致

显示器未校色，或者文档色彩空间与导出色彩空间不一致。GIMP 里有独立的「图像精度」设置（8-bit / 16-bit / 32-bit 浮点），高精度能减少色阶断层，但也更吃内存。做大幅印刷或重度调色时，建议一开始就用 32-bit 浮点避免后期损失。

修复画笔留下黑斑

已知问题：涂抹超出图层边界时会出现。把图层边界扩到和画布一致（图层 → 图层边界大小 → 图层边界）后再修。

高斯模糊边缘出现暗角

模糊采样到了图层边界外的透明区域（透明像素带黑色分量）。修法：先给图层补 alpha 或把图层边界扩大，让模糊采样到有效像素。这是 GIMP 的经典问题，PS 因为默认保留 RGB 分量所以不明显。
