环境搭建

本文使用本地ollama搭建的大模型，CodeX使用APP版本（不同方式配置有差异，如果有需要告诉我们，我们再补充）。

安装CodeX

打开下载地址 https://openai.com/zh-Hans-CN/codex/get-started/ ，按照提示安装CodeX，到这里以后，就可以开始配置CodeX了。

配置CodeX

打开文件 ~/.codex/config.toml，添加以下内容（如果文件不存在，需要手动创建）： 

# 可选全局超时兜底
http_timeout = 300
stream_timeout = 240
model_context_window = 8192

model = "qwen3.5:latest"
model_provider = "ollama-local"

[model_providers.ollama-local]
name = "Ollama"
base_url = "http://localhost:11434/v1"
wire_api = "responses"

[projects.default]
trust_level = "trusted"

上面的 model = "qwen3.5:latest" 是我本地ollama提前安装好的，你可以根据需要修改。具体的应该使用 ollama list 查询可用的（不要缩写，比如 qwen3.5 这样的，可能会报错）。

启动Ollama

打开终端，输入以下命令启动Ollama服务： 

export OLLAMA_CONTEXT_LENGTH=8192
ollama serve
当然，也可以用Ollama.app启动，只是注意把上下文调整到8K：

启动CodeX

一定要在配置修改后，彻底退出CodeX后再打开，就可以正常使用了。
