环境搭建

本文将详细介绍如何安装和配置 Claude Code 及其配套工具 cc-switch，帮助你快速上手使用。

安装 Claude Code

首先，通过 npm 全局安装 Claude Code 包： 

npm install -g @anthropic-ai/claude-code

安装完成后，验证安装是否成功： 

claude --version

安装 cc-switch

cc-switch 是社区第三方开发的 API 配置管理工具，非 Anthropic 官方组件，适合需要频繁切换多服务商 API Key、自定义反向代理地址的场景，一键切换 Claude Code 调用配置。 

brew install Linuxdazhao/cc-switch/cc-switch

安装完成后，查看安装路径： 

brew list Linuxdazhao/cc-switch/cc-switch
补充说明：正常 brew 安装完成后会自动配置环境变量，绝大多数环境无需手动修改 PATH。

输出示例： 

/opt/homebrew/Cellar/cc-switch/0.1.41/bin/cc-switch

将 cc-switch 添加到系统环境变量中： 

vi ~/.profile

在文件末尾添加以下内容（请根据实际路径修改）： 

export PATH=$PATH:/opt/homebrew/Cellar/cc-switch/0.1.41/bin

让配置立即生效： 

source ~/.profile
为了省去每次手动执行 source ~/.profile，建议在 ~/.bashrc 和 ~/.zshrc 中都加上一行 source ~/.profile，这样新开的终端窗口就能自动加载环境变量，直接使用 cc-switch 命令了。

验证 cc-switch 是否安装成功： 

cc-switch --version

配置与使用

cc-switch 的核心功能是管理多套API配置，让你可以在不同模型间快速切换。 

# 1.新增一套配置
cc-switch add [别名] -t sk-[大模型密钥] -u [大模型地址] -m [大模型名称]

# 2.查看所有保存配置
cc-switch list

# 3.启用[别名]配置（自动注入环境变量，claude-code立刻生效）
cc-switch use [别名]

比如我们本地启动了一个ollama，有一个qwen3.5的模型，新增配置语句如下： 

cc-switch add cn -t sk-ollama -u http://localhost:11434 -m qwen3.5

我们上面配置了一个叫做"cn"（就是上面的[别名]=cn）的API，启用cn配置并打开claude界面只需要： 

cc-switch use cn

使用中可能需要修改配置，直接： 

cc-switch

报错解决

如果使用中遇到如下错误：

API Error: 400 1 validation error:('type': 'literal_error', 'loc'¥('body'messages', 1, 'role'), 'msg':"Input should
        be 'user'or 'assistant'",'input': 'system'('expected': "'user' or 'assistant'"}}
File "/usr/local/lib/python3.12/dist-packages/vllm/entrypoints/utils.py",line 48, in create_messagesPOST /V1/mesages
        [('type': 'literal error','loc : ('body', Imesages', 1, 'role'), 'msg': "Input should be 'user'
        or'asistant'",'input':system', 'ctx': {'expected': "'user' or 'assistant'"}}]

修改方案：打开配置目录 ~/.claude/settings.json，在顶层 env 节点添加变量： 

{
  "env": {
    "CLAUDE_CODE_SIMPLE": "1"
  }
}

保存后彻底重启 Claude Code。

这可能和你使用Claude Code是最新的有关（会把系统提示词直接以 role: system 塞进 messages 对话数组里），但你对接的LLM 模型可能有严格校验：messages 数组内只允许 user / assistant 两种角色，不识别数组里的 system 角色，直接返回 400 校验错误。
