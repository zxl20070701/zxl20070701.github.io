画笔与绘画

PS 的绘画能力集中在画笔设置上。一个笔刷的行为由「笔尖 + 动态（Dynamics）」两部分决定：笔尖决定形状，动态决定它如何随笔画变化。理解了这两层，其余工具都是变体。

绘画工具总览

工具 快捷键 特性
画笔 B 最通用，所有动态和笔尖都支持，可画可涂可仿修
铅笔 无 硬边，不抗锯齿，画出的每个像素都是实色，适合像素画
铅笔的「像素画模式」 — 像素级绘画，禁用抗锯齿和动态
橡皮擦 E Shift+E 在橡皮擦和背景色橡皮擦间切换
背景色橡皮擦 Shift+E 只擦到同色区域，保护不同色像素，用于精细抠图
渐变 Shift+G Shift+G 在渐变和油漆桶间切换
油漆桶 Shift+G 按颜色填充容差区域
混合器橡皮擦 Shift+E 循环 擦除时把底层颜色带上来
Shift+单击工具图标循环切换同组工具是 PS 的核心交互（详见《界面与快捷键》）。Shift+E 循环出三种橡皮擦，Shift+G 循环出渐变和油漆桶。

画笔设置面板

打开方式：窗口 → 画笔设置，或双击画笔工具图标。面板分两块，核心是右侧的「Brush」区域：

基本参数

参数 作用 说明
Brush（画笔） 选择笔尖形状 硬边圆刷、软边圆刷、自定义笔尖
Mode（模式） 笔刷混合模式 与图层混合模式同名，笔刷自己的
Opacity（不透明度） 笔画最大不透明度 选项栏那个是上限，这里是笔刷内部的
Flow（流量） 单个笔尖印记的不透明度 与不透明度的区别见下文
Airbrush（喷枪） 按住不放会持续出色 喷枪效果，不勾选就是单次笔画
Smoothing（平滑） 笔迹平滑程度 默认 10%，压感笔建议调高

Opacity 与 Flow 的区别

这是画笔最容易混淆的一对参数。行为差异：

  • Opacity 不透明度：控制整个笔画累积后的最终不透明度。低不透明度画一条线，反复涂同一处也不会变浓（因为每次都从原状态计算）
  • Flow 流量：控制单个笔尖印记的浓度。低流量画多次，同一处会越来越浓
画阴影、烟雾、光效时用低 Flow，反复叠加能得到自然的深浅过渡。画实心线条时把 Flow 拉到 100%，避免边缘出现颗粒感。这是最常用的画笔技巧之一。

笔尖的硬度

[ / ] 调大小，Shift+[ / Shift+] 调硬度。

硬度滑块只对圆刷有效。导入的笔刷（.abr）如果是用图片做的，硬度是烘焙在笔尖图里的，滑块会显示为灰色不可调——这是正常的，不是出问题。

动态（Brush Dynamics）

动态让笔刷随笔画过程变化，是让绘画从「生硬」变「自然」的关键。画笔设置面板下方有三大类：

形状动态（Shape Dynamics）

控制笔尖的尺寸和形状如何变化。每项都有「Jitter（随机度）」和「Control（控制方式）」两个参数：

参数 作用 Control 的选项
Size Jitter 笔尖大小的随机变化 关闭 / 渐隐 / 笔压 / 笔倾斜 / 笔轮
Minimum Diameter 笔尖能缩到原直径的百分之几 配合 Size Jitter 使用
Angle Jitter 笔尖角度随机变化 额外有初始方向 / 当前方向选项（按笔画走向定向）
Roundness Jitter 笔尖圆度变化（做出扁笔效果） 同角度动态

颜色动态（Color Dynamics）

控制画出来的颜色如何变化，主要用于做纹理和自然笔触：

  • Apply Per Tip（逐笔尖应用）：开启后每一笔尖印记都独立随机变化，关闭则整条笔画一个颜色。这是最关键的一个开关
  • Foreground/Background Jitter：前景色与背景色之间的随机混合，让笔画有自然色差
  • Hue / Saturation / Brightness Jitter：色相、饱和度、明度的随机偏移
  • Purity（纯度）：-100% 到 100%，控制饱和度增减
做草地、头发、毛绒质感时，前景/背景 Jitter + 逐笔尖应用是核心组合。前景和背景设成接近的颜色，Jitter 给 30%~50%，出来的笔触会非常自然。

传输动态（Transfer）

控制不透明度和流量如何变化：

  • Opacity Jitter：不透明度随机，但不会超过选项栏设定的值
  • Flow Jitter：流量随机，同样不超过选项栏的值
  • 两者的 Control 都可以选笔压 / 笔倾斜 / 笔轮，让效果跟随数位笔

笔压控制需要数位笔

动态的 Control 选项里，笔压（Pen Pressure）、笔倾斜（Pen Tilt）、笔轮（Stylus Wheel）、旋转（Rotation）都需要压感数位笔。没有数位笔时选了这些，PS 面板会出现警告图标，且控制无效。用鼠标的话只能选「关闭」或「渐隐」。

画笔预设

选笔预设面板

双击画笔工具图标打开，会弹出当前笔刷的选笔预设列表：

  • 点击预设即时预览效果，满意后回车确认
  • 点击面板文件夹图标，可把当前设置存为预设
  • 列表里 [默认] 开头的项是内置的，末尾的 [当前] 是正在编辑的

工具预设

工具预设保存的不只是笔刷，还包括工具本身和全部参数。用法：

配置好画笔 + 不透明度 + 混合模式 → 点击选项栏右侧「工具预设」面板的文件夹图标 → 命名保存

工具预设比画笔预设更强，因为它能存「用哪个工具 + 什么参数」。比如「云朵笔刷」和「软橡皮」各存一个，一键切换整套配置。

画笔描边路径

让笔刷沿路径自动绘制，避免手抖。流程：

用钢笔画一条路径 → 选好画笔和参数 → 打开路径面板，选中路径 → 点路径面板底部的「用画笔描边路径」按钮

这是做手写签名、装饰线条、沿边缘描线的利器。描边会落到新图层上，随时可以再调整。

性能优化

Adobe 官方给的画笔性能建议，关键三点：

设置 建议 原理
Smoothing 设为 0% 默认值 10% 会降低绘画响应速度
Spacing（间隔） 在不破坏效果的前提下尽量调大 间隔越小，每笔需要计算的笔尖越多。标准圆刷默认 25%
笔刷复杂度 用标准圆刷 + 只开形状动态 复杂笔尖形状和过多设置都会降低响应

另外 Adobe 建议绘画或修图时隐藏标尺和辅助元素：

  • Ctrl+R：隐藏标尺
  • Ctrl+H：切换额外内容显示（网格、参考线、选区边界）
绘画变卡时按这个顺序排查：关掉多余的动态项 → Spacing 调大 → 隐藏参考线 → 检查 GPU 加速 → 检查内存。动态项开太多是最常见的原因。

绘画技巧

软硬过渡

画阴影不要用纯黑或纯灰，画两个相近的颜色，用软笔刷低 Flow 反复叠加，得到的过渡远比直接选灰色自然。这是 PS 绘画最核心的原则。

边缘处理

  • 硬边元素（图标、UI）用硬边笔刷 + 100% Flow
  • 需要柔和边缘时用低硬度笔刷 + 低 Flow 多层叠加
  • 最后用 Shift+Alt+拖拽 平滑突兀的笔触边缘（配合移动工具的「平滑」选项）

像素画

画笔工具选项栏有个「像素画模式」的图标（也可用铅笔工具）。开启后：

  • 自动禁用抗锯齿和动态
  • 笔刷缓存到 100% 时才显示像素网格
  • 适合做像素画或需要精确像素控制的效果

橡皮擦的三种形态

  • 普通橡皮擦：擦成透明
  • 背景色橡皮擦（Shift+E）：只擦到与背景色接近的像素，保护其它颜色——这是精细抠图最有用的工具
  • 混合器橡皮擦：擦除时把底下的颜色带上来，保留质感
背景色橡皮擦配合容差范围（Tolerance）使用效果最好：把背景色设为要保护的区域颜色，容差调到 30 左右，能干净地只擦掉选中区域的边缘而不伤及其它部分。

常见问题排查

画笔「不听话」，感觉有延迟

三个原因：Smoothing 值太高（调到 0）、动态项开太多、Spacing 太小。另外确认是否开着 GPU 加速（有时反而更卡）。

笔迹有颗粒感 / 边缘不干净

Flow 太小导致笔尖印记不叠加均匀。画实心线条时把 Flow 拉到 100%。如果是刻意做效果，那颗粒感来自 Spacing 过大。

硬度滑块灰的不可调

正常现象。硬度只对圆刷有效，导入的自定义笔刷（.abr）硬度已烘焙进笔尖图。要改的话得编辑笔尖原图，或者换成圆刷。

选了笔压动态但没反应

没有连接压感数位笔。PS 面板会显示警告图标。用鼠标的话 Control 只能选「关闭」或「渐隐」。

笔尖形状很怪 / 涂抹不开

检查是不是尺寸相对当前画布分辨率太小。有些笔刷是按特定分辨率制作的，在小画布上会显得过细。检查画布分辨率（图像 → 图像大小）是否和笔刷设计时一致。

颜色动态前后景区分不清

前景色和背景色太接近时看不出变化效果。刻意做出对比（比如前景绿、背景红）才能观察清楚 Jitter 的实际范围。

笔画结束位置有个圆点

笔尖印记的叠加结果，起笔和收笔处流量不同导致。解决：把 Flow 调高，或用「已存储的画笔路径」功能预先设定起收笔的流量渐变（形状动态里勾「渐隐」并设定起点/终点直径）。
