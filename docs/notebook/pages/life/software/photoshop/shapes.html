形状与路径

PS 的矢量能力远不如 Illustrator，但它有两个独占优势：形状图层可以承载图层样式和剪贴蒙版，路径可以任意转换为选区。加上「布尔运算」，PS 里的形状工具其实相当强。

三种绘制模式

直线、形状工具组里的所有工具，选项栏左上角都有一个模式切换按钮，这是最需要先理解的概念：

模式 产出 特点
形状（Shape） 形状图层 矢量 + 填充 + 描边，可缩放、可加样式、可编辑路径节点
路径（Path） 路径（不填充） 纯矢量轮廓，可转选区或填充，没有颜色
像素（Pixels） 直接画到当前图层 普通像素绘制，可设混合模式和不透明度，不抗锯齿参数可控
默认是「形状」模式，这也是最常用的。要画在已有图层上（而不是新建形状图层），就切到「像素」模式。这两个模式的操作习惯完全不同，是新手最常混淆的点。

形状图层

形状图层的优势

相比直接画像素，形状图层有四个实质好处：

  • 无损缩放：任意放大缩小不糊，随时能改回原始尺寸
  • 可承载图层样式：投影、描边、渐变叠加全部可用（详见《图层与蒙版》）
  • 可作为剪贴蒙版：形状层压在上层，下层内容被裁剪成它的形状
  • 可编辑路径：右键 → 建立选图层，或用路径选择工具调节点

Live Shapes（实时形状）

3.0 起形状工具新增了 Live Shapes：在画布上直接显示可拖动的控制手柄，能调整圆角半径、圆环比例等参数，不用进属性面板。

启用方式：选项栏 → 齿轮图标 → 勾选 Live Shapes Controls。

自定义形状

自定义形状工具（U，与矩形工具同组，Shift+U）内置了上百种预设形状：

U 切换到自定义形状工具 → 点击选项栏「形状」下拉框 → 点击面板上的齿轮图标加载形状集（如 Arrows、Flowers） → 选中形状后在画布上拖拽绘制

形状集需要手动加载，默认只显示最近使用的一小批。第一次用要点击形状面板右上角的齿轮（或路径形状右上角的小菜单）加载更多形状集，否则会以为「形状很少」。

形状的绘制约束

按键 效果
Shift 限制为正方形 / 正圆（画多边形时限制为正多边形）
Alt 从中心向对称方向绘制
Shift+Alt 正方形且从中心绘制
方向键 旋转形状（45° 一档）

描边与填充

形状模式的选项

选项 说明
填充颜色 形状内部的颜色
描边颜色 / 宽度 轮廓线的颜色和像素厚度
描边类型 实线 / 虚线 / 点线
对齐 内侧 / 居中 / 外侧——宽度算在形状内还是外
端点 平头 / 圆头 / 方头（直线工具有效）
拐角 拐角形状（直线工具不适用）

也可以用图层样式实现描边：双击形状图层打开样式面板 → 描边。区别是样式描边完全非破坏性且可随时改，而形状自带的描边是矢量属性，改起来要进选项栏。做 UI 设计时图层样式更灵活。

对齐方式选择很关键：内侧描边会让形状的实际尺寸变小，外侧会让它变大。做精确对齐的 UI 元素时，优先用「居中」或用图层样式描边（默认也是居中）。

渐变填充形状

形状图层的填充可以是渐变（点击填充颜色块，选渐变图标）。渐变填充同样非破坏性，双击图层进属性面板可以改渐变类型和颜色。

路径

路径与选区互转

路径最大的价值是可存储、可复用、可精确。四种转换方向：

方向 操作 说明
路径 → 选区 路径面板 → 路径转选区 未闭合路径会自动用直线连接起终点
路径 → 形状图层 路径面板 → 填充路径 / 描边路径 生成形状图层，矢量可编辑
路径 → 填充像素 编辑 → 填充（路径被激活时） 直接填像素
选区 → 路径 路径面板 → 从选区生成工作路径 关键技巧：把栅格化的复杂选区变成可编辑矢量
「从选区生成工作路径」是 PS 里最被低估的功能之一。它能把任何复杂选区转成矢量路径，然后进 Illustrator 编辑，或在 PS 里调整节点。抠图边缘不满意时，这是精修的最佳途径。

路径操作

钢笔或形状工具在路径模式下绘制时，选项栏顶部是路径运算按钮：

运算 效果
添加（+） 与现有路径合并，重叠部分不挖空
减去（−） 从现有路径中挖掉
交叉（×） 只保留重叠区域
排除 挖空重叠部分（合并但不重叠）
形状的布尔运算有快捷键：绘制完成后选中形状图层，按 + 合并形状、− 减去上层、* 交叉、\ 排除。但前提是这些形状在同一图层上。

路径的对齐与分布

在路径模式下，选项栏有路径对齐和路径排列两个下拉菜单：

  • 对齐：选中的多个路径组件按左/中/右等对齐
  • 分布：至少需要三个组件，才能等间距排列
形状在不同图层上时，对齐要改用移动工具（配合Alt 对齐参考线），路径对齐工具只对同一路径内的组件生效。

钢笔工具

钢笔（P）是 PS 的路径主力工具，核心操作是单击打直线锚点，拖动打曲线锚点：

  • 单击：直线锚点
  • 按住拖动：曲线锚点，带两个手柄
  • Alt+拖动锚点：只调整单侧手柄，得到平滑过渡
  • Shift：吸附到水平/垂直/45°
  • Ctrl+Z：删除上一个锚点
  • 鼠标移到起点呈圆形磁铁：点击闭合路径

钢笔的经典用法是先粗略画一圈，再精修：画完转选区看效果，不满意就 Ctrl+Z 退回继续调。比一次画二十个锚点高效得多。

形状与路径的实战

剪贴蒙版

形状图层最大的实战价值。流程：

把图片或内容放在图层下方 → 在上方用形状工具画一个形状图层 → Alt+点击两层之间的编组图标建立剪贴蒙版 → 内容被裁剪进形状

快捷键是 Ctrl+Alt+G。最经典的用法是圆形裁剪头像：照片放下面，画正圆形状层，剪贴。再把形状层用蒙版做羽化，就是柔和的圆形边缘。

描边路径做手绘感线条

用钢笔画一条路径 → 路径面板 → 用画笔描边路径。线条沿路径自动绘制，不会手抖，适合做装饰线、签名、手写效果。

圆角矩形

矩形工具画形状 → 直接拖动圆角半径滑块（Live Shapes 开启时），或进属性面板输入具体数值。做 UI 卡片、按钮的标准做法。

精确形状进 AI 继续编辑

路径面板 → 右键 → 导出为 Illustrator 路径，得到 .ai 文件。复杂形状建议直接用 AI 做，PS 只做简单图形。

常见问题排查

形状工具画不出来 / 画成了像素

检查选项栏左上角的模式是不是切到了「像素」。切回「形状」会新建形状图层，「像素」则画在当前图层上。

形状图层上没有图层样式选项

形状图层本来就应该有。如果没有，检查是否误点了「栅格化图层」。样式只能加在矢量图层上，栅格化后就失去了这个能力。

布尔运算没反应

两个前提：形状必须在同一图层上，且绘制时用的是路径模式。如果形状分散在多个图层上，先合并图层。

自定义形状太少了

形状集需要手动加载。点形状下拉面板右上角的齿轮图标，选择要加载的形状集（如 Arrows、Bubbles、Dice 等），加载后才会出现在列表里。

描边宽度改变了形状大小

检查描边的对齐方式。内侧会让形状实际变小，外侧会变大。需要精确尺寸时用「居中」对齐。

路径转选区后没有闭合区域

路径没闭合。PS 转选区时会自动用直线连接起终点，但如果你已经闭合了却仍然异常，检查是否有多余的子路径（路径选择工具 A 配合 Alt+点击 可以看到每个子路径）。

「从选区生成工作路径」很慢

正常现象，它在逐像素分析边缘。大图上要有耐心，或者先用「简化边缘」把选区收干净再转，路径会干净得多。

形状图层太大导致卡顿

高分辨率下大量矢量形状会占用较多内存。必要时把形状图层栅格化（Ctrl+Shift+Alt+E 或图层右键 → 栅格化），但这会失去可编辑性和样式能力。
