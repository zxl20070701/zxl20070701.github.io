修复与修饰

修图的核心工具都遵循同一个模式：设定一个源，然后把它「搬」或「算」到目标位置。区别在于源怎么选、怎么混合、以及是否破坏原像素。理解这一层，工具选择就很简单了。

修复工具总览

工具 快捷键 需要设定源 适用
污点修复画笔 J 不需要 小瑕疵：雀斑、灰尘、小划痕
修复画笔 同组 不需要 配合采样，保留纹理地修复
修补工具 同组 不需要 用矩形选区指定修复区域
内容感知移动 同组 不需要 移动物体并自动填补原位置
红眼工具 同组 不需要 去红眼
仿制图章 S 需要 精确复制，最强控制力
图案图章 同组 需要 用图案填充，修复纹理
PS 的修复工具都挤在一个分组里，用 Shift+单击 循环切换。它们的共同点是直接改像素、不可撤销到原状态之外——所以每次修复前最好 Ctrl+J 复制图层，修完不满意直接删图层。

仿制图章

最可控的修复工具，逻辑是手动指定源点，把那里的像素复制到目标位置。

基本用法

S 选中仿制图章 → Alt+点击设置源点 → 拖拽涂抹到目标位置

Aligned（对齐）

这是仿制图章最关键的开关：

设置 行为 适用
勾选 Aligned 源点跟随涂抹位置一起移动，复制的是相对区域 连续涂抹不会「拉丝」，大面积修复首选
取消 Aligned 每次都从原始源点重新采样 重复纹理（草皮、砖墙），或需要反复覆盖同一样本
新手最常见的错误就是忘了开 Aligned。不开的话连续涂抹会出现拉丝状的重复纹理，因为每一笔都在复制源点周围同一块内容。开启后源跟着走，纹理自然连续。

取样来源（Sample）

  • 当前图层：只从当前图层取
  • 当前及下方图层：从当前层和它下面的图层取
  • 所有图层：从所有可见图层取
仿制图章不能在调整图层上工作（Adobe 明确说明）。如果当前选中的是调整图层，工具会直接不可用——需要先回到像素图层上操作。

污点修复画笔

最省事的去瑕疵工具：自动分析周围像素并融合，基本不需要调参。

Type 的三种类型

类型 原理 适用
Content-Aware（内容识别） 比较附近图像内容，智能填补并保留阴影、物体边缘等细节 最常用。雀斑、污点、杂线
创建纹理 用周围纹理填充 皮肤、草地等纹理区域
邻近匹配 把边缘一侧的像素搬到另一侧 选区边缘的杂物、画面边缘的多余部分

关键选项

  • Sample All Layers（采样所有图层）：关键的非破坏性开关。勾选后从所有可见图层取样，但修复结果只落在当前图层——这让修图变得可回溯
  • Mode → Replace（替换）：保留噪点、胶片颗粒和边缘纹理。用软边笔刷时效果最好，避免修出来的区域比周围更干净
Sample All Layers + Replace 是 Adobe 官方推荐的非破坏性修图组合。Sample All Layers 让取样更准确（能看到下层的内容），Replace 避免出现「这块皮肤突然特别干净」的违和感。

Adobe 还建议：笔刷尺寸要比瑕疵略大一点，在画笔设置里把 Size 滑块往左调，让笔刷覆盖范围有余量。

内容感知填充

污点修复画笔的「手动版」，适合大块区域或不规则形状的填充。

两种用法

  • 先选区，再编辑 → 填充 → 内容识别：适合已有选区的情况
  • 直接编辑 → 填充 → 内容识别：PS 自动分析选区周围（需先有选区）

关键选项：自适应

填充对话框里有个「自适应」下拉，它决定了算法如何计算填充范围：

自适应设置 采样范围 适用
自定 手动指定宽/高 需要精确控制时
连续 用边缘所有像素 最常用，适合大多数情况
样条 用边缘延伸方向推断 纹理有方向性的区域（木纹、织物）
先前的颜色/背景色 用纯色填充 需要纯净色块时

扩展与其它选项

  • 扩展：填充区域向外扩张的量，用来处理选区边缘残留
  • 颜色容差：颜色差异多大算「相近」
  • 不透明度：填充内容的透明度
  • 从路径面板的路径填充时，会应用路径自身的羽化

修补工具

与污点修复的区别：用选区指定修复区域，而污点修复是用笔刷涂抹。

两种工作方式

方式 操作 适用
源（默认） 框选要替换掉的区域，PS 自动取样周围 小范围精确修复
目标 先框选作为源的区域，再框选要修复的区域 修复大块，源区域需要精确指定
修补工具的选区要用矩形选框且边缘尽量贴紧瑕疵。太宽松会把旁边正常的像素也换掉，容易露馅。

内容感知移动

这个工具解决「想去掉某个物体但填什么」的问题：

选中工具，Mode 选「移动」 → 框选要移动的物体 → 拖到目标位置

两个关键选项

  • 结构：越大越保留原物体的形状和结构
  • 颜色：越大越保留原区域的色调

扩展选项

  • 取样范围：周围多远的像素作为参考
  • 填充：原位置如何填补——内容识别 / 背景色 / 前景色 / 样例
典型用途是「路人甲入镜」：把人框出来移开，原位置自动用周围内容填上。但当背景很复杂时（花纹、密集人群），它填得并不好——这时改用修补工具的「目标」模式手动指定干净区域作为源，效果往往更好。

减淡与加深

选项 作用
减淡（Shift+O） 提亮。曝光不足的区域、眼神光、高光
加深 压暗。需要压暗的区域、阴影加深

三个曝光选项

  • 画笔：传统方式，直接提亮压暗
  • 铅笔：只作用在暗部——用画笔工具的混合模式「变暗」，保护高光不受影响
  • 保护色调：保持色相不变，只改变明度。修肤色时必须勾选，否则容易出现「漂白感」
「保护色调」是减淡/加深里最该勾的选项。不勾选时提亮会同时降低饱和度，肤色区域容易变成不自然的惨白。勾上之后只改明度，色相保持不变。

范围限制

选项栏有「限制范围」下拉，决定影响的是阴影、中间调还是高光：

  • 阴影：只影响暗部，适合加深阴影让层次出来
  • 中间调：默认值
  • 高光：只影响亮部
调整对比度时这个选项很有用：选「阴影」+ 减淡 可以提亮暗部而不动高光，比用曲线更直观。范围 + 减淡/加深的组合，相当于局部明暗调整。

锐化与模糊

局部处理版（全局版见《调色与滤镜》）：

  • 锐化工具（同组内）：锐化细节边缘
  • 模糊工具：柔化区域
  • 涂抹工具：取样周围颜色推抹，用于柔化过渡
  • 减淡/加深：见上文

它们的选项栏都有「保护色调」，原理和减淡加深一致。

涂抹工具的用法

涂抹工具取样笔刷周围的像素并向前推进，最适合做柔和过渡。修图时用来：

  • 柔化生硬的修补边缘
  • 在两个色块之间做渐变过渡
  • 清理选区边缘的锯齿

高低频磨皮

专业人像修图的标准流程，核心思想是把皮肤分成两种频率分别处理：

双曲线磨皮

盖印可见图层 → 打开曲线，用管道工具在高低点各取一个控制点 → 压暗高光提亮暗部 → 再新建一层曲线，反向操作 → 两层曲线分别设「滤色」和「强光」混合模式

高低频磨皮

盖印图层 → 用磨皮 Action（或手动）分离高低频 → 低频层用画笔低流量整体涂抹，去除色斑 → 高频层保留皮肤纹理

PS 自带动作库里有「磨皮」动作：窗口 → 动作 → 图层样式/图像修复 → 磨皮，加载后播放即可完成高频分离。配合《动作与批处理》一篇的方法，可以把它改成自定义参数。

保留质感

磨皮最常见的问题是把皮肤纹理也磨没了，结果脸变成「塑料感」。避免方法：磨皮幅度要克制，宁可分多次少量处理；只磨色斑不磨整体；最后用纹理滤镜或噪点层补回一点质感。

非破坏性修图流程

一个规范的修图工作流，全程可回溯：

Ctrl+J 复制背景图层 → 在新图层上用修复工具处理（勾 Sample All Layers） → 需要大幅调色时盖印或加调整图层 → 满意后 Ctrl+Shift+E 合并

修图前先复制图层，这是 PS 里最容易省掉但后果最严重的步骤。修复工具是直接改像素的，一旦修坏只能靠历史记录回退（而历史记录默认只有 20 步）。

常见问题排查

修复后出现明显的重复纹理

仿制图章没开 Aligned。勾上它，源点会跟着涂抹位置移动。

修复区域比周围更干净 / 有塑料感

污点修复画笔的 Mode 用了默认值。改成 Replace（替换）可以保留噪点和纹理，避免出现「这块皮肤突然特别干净」的违和感。

内容感知填充填得很奇怪

试这几个方向：调整「自适应」范围（连续/样条）、增大扩展值、扩大取样范围。背景复杂时它确实会失败，这时改用修补工具手动指定干净源区域更可靠。

仿制图章不可用

当前选中的是调整图层。仿制图章不能在调整图层上工作（Adobe 明确说明），需要切回像素图层。

减淡后肤色发白不自然

没勾「保护色调」。勾上它只改明度不动色相。另外「范围」建议选「阴影」而不是中间调，避免影响高光。

修复笔刷在图层边缘出现黑边

采样到了图层外的透明区域（透明像素带黑色分量）。修法：先把图层边界扩到与画布一致（图层 → 边界大小 → 图层边界），再执行修复。

磨皮后脸看着假

磨过头了。专业修图本来就保留皮肤纹理。建议：只处理明显的色斑，不要追求「平滑」；磨皮后用杂色/噪点滤镜补回微粒质感；人像磨皮宁保守勿激进。

红眼去除把眼白也弄红了

选区没框准。红眼工具需要精确框选眼睛区域，框小了效果不彻底，框大了会波及眼白和周围皮肤。框好后可以再收缩一点选区。
