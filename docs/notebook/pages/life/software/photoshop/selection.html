选区与抠图

选区是 Photoshop 里最基础也最容易用错的概念。它只定义「接下来操作影响哪些像素」，本身不改变图像。抠图、调整、裁剪、蒙版全都建立在选区之上——90% 的「为什么我操作没效果」都是选区没选对。

选区基础操作

操作 快捷键 说明
全选 Ctrl+A 选中整张画布
取消选择 Shift+Ctrl+A 养成随手取消的习惯，否则后续操作会莫名其妙只作用一部分
反选 Ctrl+I 选区与未选区互换
羽化 Shift+F6 让选区边缘产生过渡，配合羽化半径出柔和边缘
扩大选取 无默认键 在「选择」菜单里，比羽化可控
变换选区 Ctrl+T 旋转/缩放选区本身，不是像素
选区状态下，屏幕上的蚂蚁线可能会让人误以为已经在操作了。用 Q 或 Alt+Ctrl+R 切换「 Quick Mask（快速蒙版）」模式：被选区域会显示红色蒙版，一眼看清选区边界到底在哪。

选区模式：三种叠加关系

图层标题栏下方那四个小图标，决定了「新选区」和「现有选区」如何合并。搞错这四选一，行为会完全相反：

模式 快捷键 行为
新选区 默认 替换掉原来的选区
添加到选区 Shift 并集，区域变大
从选区减去 Alt 差集，用来挖洞
与选区交叉 Shift+Alt 交集，只保留重叠部分
按住 Shift 拖拽任意选区工具，默认变成「添加到选区」，可以不受工具图标限制直接加选。这是加选最快的方式。

快速选择与魔棒

快速选择工具（W）

画笔式圈选，是目前效率最高的通用抠图工具。它靠算法判断边缘（受「对边缘进行探测」和「样例所有图层」两个选项影响）。

选工具栏 W → 用画笔在主体上涂抹 → 调整笔刷硬度 → 检查边缘误选区域 → 按住 Alt 点击误选处减选

两个关键选项：样例所有图层 在主体与背景同层时容易选错，建议关闭；对边缘进行探测 负责识别发丝、半透明材质（纱、玻璃、毛发），遇到边缘选不干净先试它。

魔棒工具（U）

按颜色相似度选区，适合背景纯净或主体颜色单一的场景。核心参数是容差（Tolerance），默认值 32：

  • 容差太小：选区断裂成碎片，需要多次加选
  • 容差太大：连带相近颜色一起选入，主体边缘被吃掉
  • 按住 Shift 点击多区域加选，Alt 点击减选
  • Shift+Alt+点击 启动「取样相邻」选项

色彩范围与通道

选择 → 色彩范围 用取样器逐个指定要保留的颜色，比魔棒直观得多，关键是下方的「消除杂边 / Fuzziness」滑块。杂边是 Photoshop 抠不干净的白色羽化残留，Fuzziness 调高能去掉它，代价是可能吃掉真实细节。

通道（Channel）是选区的另一种形式。本质是按颜色分量拆分的灰度图：RGB 通道就是三张灰度图，Alpha 通道专门存选区。复杂抠图最终几乎都要落到通道里处理——尤其是头发、半透明纱这类快速选择搞不定的情况，把亮度的明暗关系手动画进 Alpha 通道，往往比反复调参数有效得多。

钢笔工具

钢笔工具（P）是唯一能画出精确矢量路径的工具，也是做硬边抠图（产品、logo、UI 元素）的第一选择。核心操作是钢笔点击打点，拖动打曲线：

P 切换到钢笔 → 单击 打直线锚点 → 按住拖动 出弧线锚点（带手柄） → Alt+拖动锚点 单独调整一侧手柄

关键技巧

  • 按住 Alt 拖动已完成的锚点，可以单独调整它一侧的曲线，得到平滑过渡
  • 闭合路径时鼠标变成圆形磁铁，直接点击起点即可封闭
  • 路径未闭合也能建立选区：路径面板 → 路径 → 建立选区，未闭合部分会自动直线连接
  • Shift 按住可吸附到水平/垂直/45°，适合画规整的界面元素
  • Ctrl+Alt+Z 删除上一个锚点
钢笔不用一次画完。正确姿势是先粗略画一圈（锚点越少越好），再 Ctrl+J 转成选区看效果，然后 Ctrl+Alt+Z 退回路径继续调整。反复在路径和选区之间切换，比一次画二十个锚点快得多。

路径与选区的配合

路径最大的价值是可以存储：路径面板里的路径可以命名保存，配合「路径 → 从路径建立选区」随时复用。做产品图、多版本素材时，把每个部件的路径存好，换个背景继续用，比每次重画强。

抠边缘：核心在于边缘处理

决定抠图质量的不是选区本身，而是选区之后的边缘处理。主体与背景之间那 1–2 像素的过渡像素，包含半透明混合信息，处理得好才有自然边缘。

标准流程

大致选出主体 → Shift+F6 羽化 0.5–1px → Alt+点击蒙版按钮（按选区生成） → 黑白画笔在蒙版上修边缘 → Shift+X 交换黑白，切换修亮/修暗

羽化的作用：它让选区边缘变成渐变过渡，参与运算的是过渡像素而不是硬边界，这样抠出来的边缘才有半透明的柔和感。直接硬选 + 硬删除会得到锯齿边。

去黑边

边缘常见的「白边/黑边」来自原始图像里主体和背景的混合像素。方法有三种，按情况选：

方法 操作 适用
图层 → 简化边缘 设半径 + 检查颜色 最通用，半径控制过渡宽度
去边 图层 → 修边 → 去边 边缘只有 1px 时最快
色彩范围去杂边 色彩范围 → 选白色 → Fuzziness 调高 背景纯白、边上有白色残留
「简化边缘」对话框里勾选 智能半径检测，配合 Radius 滑块，PS 会自动判断哪里需要更多过渡——这是目前最省事的边缘优化方式，比手动羽化半径更聪明。

半透明主体

头发、毛绒、纱、玻璃这类边缘是半透明渐变的，硬选必然丢失信息。正确做法是不去除这些像素，而是通过蒙版保留它们：

选到主体主体区域（包含边缘渐变） → Ctrl+点击蒙版按钮生成蒙版 → 用 1–2px 柔边画笔把边缘灰度刷出来

换成背景后边缘发灰、有「脏边」，通常是把半透明像素降成了半灰。修法是在新背景上加 色彩加深 混合模式，复制主体图层放上去，能让半透明边缘重新「吸附」到新背景上。

自动化抠图：命令面板

「选择」菜单最底部有一组以 Adobe 开头 的命令（早期叫 Select and Mask，后期改成菜单里的「选择并蒙版」）：

先随便做出粗略选区 → 选择 → 选择并蒙版 → 在预览里调整「边缘」和「全局调整」 → 输出到「图层蒙版」

三个关键区域

区域 核心参数 作用
视图模式 — 调试时切到「叠加」看清真实边缘
边缘检测 半径、智能半径、细化边缘、对比度 决定选区往哪边收缩；半径越大越向内收缩
全局调整 羽化、对比度、边缘移动 边缘移动往外吃掉背景残留，往内保留主体细节
勾选 智能半径检测 后，半径滑块会自动给发丝区域分配大半径、实心区域小半径。半径以画布像素为单位，换高分辨率素材时记得按比例放大，2000px 图用 1px，6000px 图就要用 3px 左右。

输出到哪里

「选择并蒙版」的输出选项里，图层蒙版 是首选（可继续编辑）；新建图层 会把抠好的主体变成独立图层；新建文档 适合提取单个通道。选蒙版而不是直接确定，能给边缘留出调整余地。

选区扩展实战

一键抠主体换背景

W 快速选择涂抹主体 → 选择并蒙版修边缘 → 输出到图层蒙版 → 双击背景解锁 → 放新背景或纯色填充层

保留阴影抠商品

快速选择只涂商品不涂阴影 → 选择并蒙版调整 → 然后 Shift+点击主体图层再 Shift+Ctrl+E 盖印，得到包含阴影的完整图层。

抠图加阴影（合成技巧）

抠好的主体放在新背景上 → 复制主体层 → Filter → 渲染 → 投影 或图层样式加投影 → 把投影层不透明度降到 30%。比用 PS 的旧版「投影」图层样式更可控，也更接近摄影棚效果。

只抠某个部件

复杂产品图里想单独取出按钮：用钢笔勾出按钮路径 → 建立选区 → Alt+点击蒙版按钮。不要先抠整个产品再局部擦，蒙版只会越来越难收拾。

常见问题排查

操作只作用在一小块区域

选区还残留着。按 Shift+Ctrl+A 取消，或按 Q 打开快速蒙版确认一遍。养成每步操作前 Shift+Ctrl+A 的习惯能避免 90% 的困惑。

抠完边缘有白边

没有去杂边。用「选择并蒙版 → 边缘检测 → 平滑/收缩」，或对边缘做一次「图层 → 简化边缘」。另外确认抠的时候选区没有包含背景像素——白边本质是背景被带进来了。

魔棒选不中想要的区域

背景色不连续或有渐变时，容差需要很大才能覆盖，结果就是主体也被吃掉。换成「色彩范围」逐个取样，或者直接用快速选择。

钢笔画出来是折线

只用单击打点就会得到折线。画曲线需要按住鼠标拖动出手柄；如果某个锚点不需要曲线，选中它按 Shift+Alt 切换为拐点。

蒙版边缘发灰显脏

半透明像素被压成了半灰。修法：新背景上加一层 色彩加深 混合模式，复制主体层放上去，边缘会重新对上背景色。这是从半透明边缘抠图最常见的补救手段。

边缘在不同背景下都「露馅」

抠图只在一个背景上看过。半透明物体需要至少换两种亮度背景验证（深色和浅色），才能确认边缘信息是否完整。发货类素材尤其重要。
