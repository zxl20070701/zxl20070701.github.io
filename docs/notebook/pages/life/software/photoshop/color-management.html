色彩管理

色彩管理是 PS 里看不见但决定成败的一环。它的核心其实只有一个问题：颜色是「设备相关」的，不同设备对同一个数值会产生不同的实际颜色。色彩管理就是一套翻译机制，让颜色在不同设备间保持一致。

为什么颜色会不一致

三个层面的原因叠加在一起：

设备无法再现全部颜色

没有任何设备能再现人眼可见的全部颜色。每个设备都在自己的色域（gamut）范围内工作：显示器有显示器的色域，喷墨打印机有打印机的色域，印刷厂有印刷机的色域。

所以你在屏幕上看到的那种鲜艳的蓝，很可能完全在打印机的色域之外——不是调色调错了，是物理上印不出来。

设备原理不同

  • 显示器用 RGB 磷光或 LED 发光
  • 打印机用 CMYK 油墨吸收光线

发光和吸光的物理机制不同，同一组数值自然产生不同结果。

色彩模型的性质差异

类型 模型 说明
设备无关 CIE Lab 直接对应人类视觉感知，跨设备描述颜色一致
设备相关 RGB、HSL、HSB、CMYK 同一组数值在不同设备上显示不同
一个直观的例子：RGB 的 (255, 0, 0) 在你的显示器上是某种红，在同事的显示器上是略微不同的红，而要印刷出来必须先翻译成 CMYK 数值。数值相同不等于颜色相同，这就是色彩管理存在的原因。

其它干扰因素

  • 显示器之间的制造差异
  • 显示器的使用年限和校准状态
  • 纸张类型和表面处理（哑光纸和光面纸的呈现完全不同）
  • 环境光照
  • 不同软件对色彩数值的解释方式

ICC 配置文件

色彩管理系统的工作方式，是通过 ICC 配置文件——这是描述「某个设备如何处理颜色」的标准化文件。三种类型：

配置文件 描述什么
显示器配置文件 这台显示器如何呈现颜色
打印机配置文件 特定的「打印机 + 墨水 + 纸张」组合能再现哪些颜色
文档配置文件 这个图像文件本身处于什么色彩空间

这些配置文件构成了一套通用语言，让 PS 能在相机、显示器、打印机之间逐级翻译颜色，并处理那些超出目标设备色域的颜色。

三种常用 RGB 工作空间

工作空间 色域 适用场景
sRGB 标准 默认首选。网页、绝大多数数字分发场景
Adobe RGB 较宽 包含较多青绿和橙色，适合印刷、户外广告
ProPhoto RGB 很宽 包含大量高饱和色和 Lab 色域。大幅调色时提供最大余量，但需 16 位

设置工作空间

编辑 → 颜色设置，在「RGB」下拉里选择。这一项决定的是新建文档的默认色彩空间，以及没有配置文件时 PS 如何解释文件。

工作空间不是「越宽越好」。ProPhoto RGB 虽然色域最宽，但它包含很多屏幕根本无法显示的颜色，在 sRGB 屏幕上会显得「发闷、发灰」。日常设计用 sRGB，需要印刷或大幅调色时再用 Adobe RGB / ProPhoto。

分配与转换：最关键的区分

这是色彩管理里最容易出错、后果最严重的一点。PS 提供了两个功能相近但性质完全不同的命令：

命令 做了什么 结果
指定配置文件
（编辑 → 指定配置文件）		 不改变任何像素数值，只改变 PS 如何解释这些数值 颜色可能剧烈变化
转换配置文件
（编辑 → 转换为配置文件）		 真正转换像素值，把颜色映射到新空间 颜色外观基本不变
Adobe 官方明确说了：「指定配置文件」不改变文档的颜色值，只改变 PS 对这些值的解释方式，屏幕上看到的颜色可能因此大幅改变。

实际含义：「指定」是重新贴标签（图像实际颜色变了），「转换」才是真正换算（颜色看起来应该一样）。想保持视觉一致就用「转换」；确实需要强行改变解释（比如文件被错误标记了配置文件）才用「指定」。

指定配置文件

编辑 → 指定配置文件，三个选项：

  • 不对此文档进行色彩管理：移除当前配置文件（危险，会导致颜色完全不可控）
  • 工作 RGB：指定为当前工作空间
  • 配置文件：手动指定某个具体配置文件

转换为配置文件

编辑 → 转换为配置文件，选择目标空间后可配置转换选项：

选项 说明
引擎（Engine） 通常选 Adobe（ACE）
意图（Intent） 转换策略，见下文
使用黑场补偿 一般建议勾选，改善暗部层次的过渡
使用抖动（Dither） 用噪声模拟中间色，减少渐变色带。位深低时必开
预览 实时预览转换效果

渲染意图

超出目标色域的颜色必须被「裁掉」，而不同的裁剪策略（意图）会得到不同结果：

意图 策略 适用
感知（Perceptual） 保持色彩的视觉关系，整体压缩色域 照片首选，尤其是有渐变和细腻过渡的
相对比色（Relative Colorimetric） 尽量精确匹配可呈现的颜色，裁掉超出的 Logo、品牌色等有明确色值要求的
绝对比色 相对方式基础上，同时还原纸张和墨水的绝对色偏 有打样要求的专业印刷
饱和度 优先保留饱和度 一般不用，会导致颜色失真
Adobe 的建议很直接：照片用「感知」，Logo 和图形用「相对比色」。因为照片有柔和过渡，感知意图保住整体关系最重要；而品牌色必须准确，不能因为裁剪而偏移。

位深

位深决定每个通道能记录多少色阶：

位深 每通道色阶 说明
8 位 256 默认。JPG、网页图够用
16 位 65536 大幅调色、渐变、16 位 RAW 后期必用。防止暗部断层
32 位 浮点 合成曝光、HDR 场景
大幅调色前先转 16 位。8 位只有 256 级色阶，一旦暗部被推到接近 0，再也拉不回来——这就是「调完暗部一片死黑」的根本原因。转换是无损的（编辑 → 转换配置文件 → 位深选项），但已经丢掉的色阶找不回来。

软打样

视图 → 校样设置，选择「自定」并指定配置文件，可以让屏幕模拟特定印刷条件的效果。

快捷开关在状态栏右下角的图标上（两个叠放的三角形），点一下切换开/关，右键可以改配置文件、渲染意图、黑场补偿等。

软打样是模拟，不是绝对准确——它无法还原纸张的纹理和墨水的物理堆叠。它能帮你发现明显偏色，但不能替代实物打样。真正要确认效果，必须打印出来看。

嵌入配置文件

文件 → 导出 → 导出为 时，勾选 嵌入颜色配置文件。这样别人打开你的文件时，PS 会正确解释颜色而不是当成 sRGB 猜。

格式 能否嵌入配置文件
PSD / TIFF 可以，这两个是印刷行业标准
JPEG 可以（Adobe RGB 图必须嵌入）
PNG / GIF 可以，但很多软件会忽略
WebP / AVIF 支持 ICC，兼容性需实测
不要用「转换为 sRGB」来解决 Adobe RGB 图在手机上偏色的问题。正确做法是嵌入 Adobe RGB 配置文件并保持空间不变，或者一开始就用 sRGB 工作。强行转换会损失色域信息，是不可逆的。

软打样之外：校准显示器

色彩管理的前提是显示器本身准确。需要校色仪（爱色、Datacolor 等），流程：

显示器预热 30 分钟以上 → 环境光控制为中性灰（专业用 D50 5000K） → 把显示器亮度调到接近正常工作亮度 → 用校色仪生成配置文件 → 在系统或 PS 中选用该配置文件

观察环境同样重要

Adobe 特别强调：不稳定的照明会破坏准确的色彩判断。要点：

  • 太阳光随时间变化（早晨暖、中午冷、傍晚暖），固定时间做色彩关键工作
  • 标准荧光灯偏蓝绿，专业色彩工作考虑 D50（5000K） 照明
  • 墙壁和天花板用中性灰，鲜艳的墙面会把色彩反射到屏幕上
  • 桌面壁纸设为中性灰，不要用彩色照片
  • 看打样时，在最终受众的同等光照下观看——家具画册在暖光下看，办公用品在冷光下看

常见问题排查

图片在 PS 里正常，发给别人就偏色

导出时没有嵌入配置文件。对方按 sRGB 解释你的 Adobe RGB 图，饱和的颜色会明显变淡。修复：导出时勾选嵌入配置文件。

「指定」和「转换」用错了

判断标准：「指定」之后颜色变了，说明你用的是指定——这通常不是你想要的。除非确实要改变解释（比如文件配置文件被错误标记），否则一律用「转换」。

调完暗部变成一片死黑

8 位色阶耗尽。预防：大幅调色前先转 16 位（编辑 → 转换配置文件 → 位深 16 位）。已经丢失的色阶无法恢复。

渐变出现色带（断层）

同样是位深不足。转 16 位，或在 8 位下导出时勾选「使用抖动」用噪声掩盖色带。

打印机打出来的颜色和屏幕差很多

三个可能：打印机未校准（需要打一份校准图生成打印机配置文件）、用的是Adobe RGB 图但转成了普通 CMYK（应转成对应的印刷配置文件）、纸换了但配置文件没换。纸张对结果影响极大，换纸必须重新校准。

选了 ProPhoto RGB 后画面「发灰」

正常现象。ProPhoto 包含大量 sRGB 屏幕无法显示的颜色，你看到的只是被裁剪后的结果。用软打样模拟目标空间，或在导出时转换到 sRGB。

CMYK 图在 PS 里「很暗」

正常现象。CMYK 模式的默认视图会模拟墨水的实际效果，而未分色预览下看到的是原始数值。用视图 → 校样设置切换到相应条件查看，或直接用 RGB 工作空间编辑（PS 允许在 RGB 下编辑 CMYK 图，会自动转换）。

JPEG 打开后偏色

颜色配置文件缺失或被错误指定。用 编辑 → 指定配置文件（不是转换）纠正为正确的配置文件，图像会恢复正常显示。这是「指定」唯一正确的使用场景。
