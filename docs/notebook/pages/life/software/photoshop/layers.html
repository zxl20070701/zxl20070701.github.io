图层与蒙版

图层是 Photoshop 的核心心智模型：一张图由若干个透明胶片叠在一起构成，每张胶片可以单独调整透明度、混合模式和蒙版。绝大多数「怎么做出来的」问题，最后都能归结为图层怎么组织。

图层基础操作

新建图层 Ctrl+Shift+N → 设置名称、颜色标记、模式、不透明度

复制图层 Ctrl+J 是最常用的操作，它在原图层上方直接生成副本。副本命名后缀是 copy，反复按 Ctrl+J 会得到 copy 2、copy 3，图层一多就很难找，所以复制后立刻重命名是个好习惯。

图层面板里几个容易忽略但很实用的操作：

  • Alt+点击图层眼睛：临时只看这一层，再点一次恢复，方便对比修改前后效果
  • Alt+点击图层缩略图：加载该图层的智能对象内容，改动会同步回智能对象
  • 拖拽到其他文档标签：跨文档复制图层
  • Ctrl+点击图层：多选图层，一次调整不透明度或对齐
图层重排有两条捷径：拖拽调整顺序，或者 Ctrl+[ / Ctrl+] 下移上移一层，再用 Shift+Ctrl+[ 移到最底层。层数很多时用快捷键比拖拽更精确。

图层组

图层组（Group）本质是一个装着其它图层的文件夹，可以整体移动、隐藏、改不透明度，也能嵌套。它的价值不只是整洁——组还能承载图层样式，效果会作用到组内所有图层。 

组 A
├── 组 A1
│   ├── 背景
│   └── 装饰线
└── 文字

组的混合模式有个特殊选项 穿透（Pass Through），这是它和「文件夹」的本质区别：

模式 作用范围 典型用途
穿透 组内图层与组下方的图层一起参与混合 整体调色组（见《调色与滤镜》一篇的调整图层）
正常等其它模式 组先合成成一个整体，再和下方图层混合 给某组元素统一加投影、外发光
「穿透」是实现调整图层效果延伸到组外的关键：新建一个组，把调整图层放进组里并设为穿透，组下方所有像素都会跟着受影响。这比逐层套调整图层干净得多。

蒙版基础

蒙版（Mask）是附着在图层上的灰度图：白色=完全显示，黑色=完全隐藏，灰色=半透明。它只控制图层的可见性，不影响像素本身，所以不会破坏原图，随时可以改回来。

灰度记法：0（黑，完全隐藏）→ 128（灰，50% 半透明）→ 255（白，完全显示）。这也是理解所有蒙版参数的换算基础。

三种创建方式

方式 初始状态 适用场景
图层下方白底按钮 全白，全部显示 需要从零开始擦除的场景
添加图层蒙版（Alt+点击） 按当前选区生成 最常用，先选好区域再创建
添加图层蒙版（Ctrl+点击） 全黑，全部隐藏 从零开始画显示区域
记忆规律：Alt+点击 = 当前选区露出来；Ctrl+点击 = 当前选区藏起来，其余全露。

停靠面板与快捷键

图层面板里，Alt+点击蒙版缩略图直接进入蒙版视图，Alt+点击图层缩略图回到图层视图——这个来回切换比在面板里找图标快得多。

  • \（反斜杠）：在图层与蒙版之间切换选中目标
  • Ctrl+I：反相当前蒙版或调整图层，方便临时对比
  • Ctrl+点击蒙版缩略图：停用/启用蒙版（不删除）
  • Shift+点击蒙版缩略图：关闭蒙版显示与链接，继续画像素
  • Ctrl+Delete / Alt+Backspace：在蒙版上填充黑/白，直接得到硬边显隐
想快速得到「只保留人物」的图层：选中人物 → Alt+点击图层下方白底按钮。之后边缘会有明显硬边，别急着抠，交给《选区与抠图》里的方法处理。

智能对象

智能对象（Smart Object）把图层内容变成一个独立的文档实例，嵌入在 PSD 里。它带来三个能力：

  • 无损缩放：随时改变大小和角度，底层始终保留原始分辨率，缩到 400% 也不会糊
  • 可反复编辑：双击进入编辑，改完保存自动更新，无需重新导入
  • 滤镜可回溯：智能对象上的智能滤镜在源文件修改后会重新计算

把一个普通图层转成智能对象：选中后 图层面板菜单 → 转换为智能对象，或直接拖进另一个文档里（自动创建并链接）。

智能对象用多了会让 PSD 体积暴涨（每张原图都嵌一份），存盘和渲染都会变慢。几百 MB 的工程在设计稿里很常见，交付前记得整理。

图层样式

图层样式（Layer Style）是一组非破坏性效果，双击图层缩略图（或 Fx 按钮）打开样式面板。它最关键的一点是：

勾选「图层缩览图」后，面板顶部会显示实时预览；取消勾选则完全停用样式但保留设置。这是在两个样式方案之间对比的唯一方法。
样式 典型用途 关键参数
投影 让元素浮在背景上 角度、大小、距离；Use Global Light 让全图层阴影方向一致
描边 文字可读性、图标分离背景 位置（内/中/外）、填充类型、像素大小
内阴影 / 外发光 内凹质感、霓虹发光 颜色、渐变、混合模式
颜色/渐变/图案叠加 快速给纯色层加质感 叠加混合模式叠加，避免直接替换原色
图层蒙版 样式自带柔化边缘 不透明度、扩展，按住 Alt 点击 只临时启用

样式的复制与清理

把一个图层的样式套到另一个上：长按 Alt 拖动图层即可复制全部样式，比逐项勾选快得多。反向操作（清样式）用 Shift+右键 → 清除图层样式。

样式多起来后，图层 → 图层样式 → 复制图层样式 会弹出一个样式清单，可以批量管理命名过的样式。

调整图层与填充图层

这两类图层不直接改像素，只通过其作用范围影响下方的图层，是非破坏性调色的基础（详见《调色与滤镜》一篇）：

类型 代表 作用方式
调整图层 曲线、色阶、可选色彩、色彩平衡 只影响下方，不含像素
填充图层 纯色、渐变、图案 自带蒙版，本质是一张被蒙版限制的色图

调整图层默认「只影响下方」，双击图层缩略图打开属性面板可勾选 剪贴到图层，把作用范围限制在下方的同组内图层。

调整图层只能影响它下面的图层，所以插错位置是最常见的问题。插好之后按 Ctrl+Alt+G 创建剪贴组，把调整图层和目标图层锁在一起。

剪贴与编组

  • Ctrl+G：编组（Group），建立普通组
  • Ctrl+Alt+G：创建剪贴组（Clipping Mask），下层图层被裁剪进上层
  • Ctrl+Alt+Shift+G：释放剪贴

剪贴的典型用法：用一个纯色/渐变填充层压在图层上方，按 Alt+点击两者之间 建立剪贴，蒙版画在哪里，颜色就作用在哪里——相当于 Photoshop 版的剪贴蒙版。

混合模式速查

混合模式分五大类，日常够用的是前四类：

类别 代表模式 视觉效果
正常/溶解 正常、溶解 不混合；溶解带随机像素颗粒
变暗 变暗、正片叠底、颜色加深 压暗，对比增强，正片叠底是经典加深方式
变亮 变亮、滤色、颜色减淡、线性减淡 提亮；滤色等价于传统正片叠底，GIMP 里叫 Linear Dodge
对比 叠加、柔光、亮光、点光、实色 叠加与柔光最常用，柔光适合快速提亮/压暗
差异 差值、排除 差值可用于对比两图差异（移动图层时）

什么时候该合并图层

图层多了会拖慢一切（PS 内存吃满后界面卡顿几乎都因为图层和智能对象太多）。合并前请确认：

  • 蒙版是否已应用到像素（图层 → 应用图层蒙版），否则合并即永久丢失蒙版
  • 智能对象是否仍需改内容，需要就先栅格化或保留副本
  • 调整图层是否已合并（Ctrl+Shift+E 盖印可见图层为一个带调整的普通图层）
交付前做一次盖印可见图层（Ctrl+Shift+E），它会保留所有调整效果的同时把图层数降到 1，是最常用的「交付瘦身」手段。

常见问题排查

蒙版画了没反应

依次检查：画笔颜色是不是黑/白（画错了等于没改）、蒙版缩略图是否被停用（Ctrl+点击）、图层不透明度是否为 0、蒙版是否链接到了别的图层。用 Alt+点击图层缩略图进入蒙版视图，再 Ctrl+I 反相，能立刻看出蒙版内容是否正确。

图层样式边缘有锯齿

投影、描边这类效果在低分辨率下会出现明显锯齿。在样式面板里把对应效果的「图层蒙版」分块半径调小，或用 效果 → 显示完整图层 检查是否是预览精度问题。真要根治，把源图层做成智能对象或先放大处理。

调整图层影响范围不对

调整图层只看它下面的内容。常见情况是目标图层被移到了调整图层上方，解决办法是 Ctrl+Alt+G 建立剪贴组，而不是反复插层。另一个坑：剪贴组会受下方不透明像素影响，效果不如裸调整图层可控。

智能对象里的滤镜没更新

源文件内容改变后，智能滤镜不会自动重算。点开智能对象查看，或在智能滤镜上 Alt+点击 暂时停用再启用，强制刷新。

PSD 突然变得很卡

先看内存占用（编辑 → 首选项 → 内存），再检查智能对象数量和图层总数。日常编辑阶段保持 8–16G 占用是正常水位，超过就该考虑整理：盖印可见图层、把隐藏的智能对象图层删掉而不是留着。
