调色与滤镜

调色的核心不是记住滤镜参数，而是建立顺序。顺序错了，后面每一步都会把前一步的成果破坏掉。这篇先讲顺序，再讲每个环节的工具。

调色顺序

下面这个顺序是从摄影底片逻辑推出来的，适用于绝大多数照片和素材处理场景： 

① 显示器校色        → 没有准确的颜色，后面全白搭
② 曝光 / 白平衡      → 定基调
③ 曲线                → 定明暗关系
④ 色阶 / 可选色彩     → 定局部色调
⑤ HSL / 色彩平衡      → 定颜色倾向
⑥ 锐化                → 放最后，会放大噪点
⑦ 输出                → 转 CMYK 或导出
锐化永远放最后。它会把前面所有的噪点和 JPEG 压缩瑕疵一起放大，先锐化再调色，等于把脏东西一起强化了。

调整图层的两种用法

每个调色工具都有对应的调整图层。它们和直接用菜单命令的本质区别是：调整图层不改变像素，可以随时改参数，也可以随时关掉对比。

图层面板底部圆形半黑半白图标 → 选择需要的调整类型 → 在属性面板调参数

想快速对比调整前后效果，按住 Alt 点击调整图层眼睛，或者在属性面板勾选右下角的「小眼睛」预览开关。

一次性调多个图层

选中多个图层（Ctrl+点击），然后创建一个调整图层，它会同时作用于所有选中的图层，并自动建立剪贴组。这是修图（比如统一调肤色）里最省时间的一招。

曝光与白平衡

色阶（Levels）

Ctrl+L 打开。它直接作用在图像的直方图上，最直观的用途是修正欠曝/过曝：

  • 拖动黑场滑块：把最暗处提到 0，图像变反差更大
  • 拖动白场滑块：把最亮点拉到 255，图像变亮
  • 拖动灰场滑块：改变整体明暗，不动黑白场
自动颜色 按钮一键完成黑白场修正，是最快的「看起来不灰」的手段。但它会同时改变色相，人像慎用——肤色会被拉偏。

曲线（Curves）

Ctrl+M 打开。曲线是色阶的升级版，核心优势是只影响你动的那一段。默认是 RGB 混合通道，左上角通道列表还有红、绿、蓝单独通道：

  • 中间点上下移动：控制整体明暗（曝光）
  • S 形曲线：加强对比
  • 暗部左下角往上提：提亮阴影，是「胶片感」的来源
  • 亮部右上角往下压：压暗高光，保护高光不过曝
  • 选择红/绿/蓝通道调 S 形：分别控制三原色的对比，等效于分离色调
曲线里拖不动？按住 Ctrl 点击曲线会自动添加控制点。想让某段更陡，把相邻两点拉开；想微调单侧，用 Alt+点击 添加点后单独调整。

曝光度（Exposure）

和曲线中点等价，区别在于它只做整体明暗且以 2 的幂次计算，更接近真实曝光。适合需要大幅提亮而不动反差时使用。

HSL 与色彩平衡

色相/饱和度/明度（HSL）

按颜色范围分别调整，人像和风景的通用武器：

属性面板点调整图层图标 → HSL 下拉切到「红色」（肤色） → 色相往橙推、明度略提 → 切到「黄色」降饱和

常见调整逻辑：

颜色 调整方向 效果
红色（肤色） 色相 +5~+10，饱和度 -5，明度 +5 肤色自然、有血色，不过于发橙
黄色 饱和度 -10~-20 去黄，皮肤和建筑都受益
绿色 色相往蓝推一点，饱和度 -5 去除草木的荧光感
蓝色 色相往青推 让天空/海水更冷冽通透

自然饱和度 vs 饱和度

自然饱和度 会智能保护已经饱和的颜色，只提升接近灰色的部分；饱和度 则是无脑拉高所有颜色。风景用自然饱和度 +10~20 通常比饱和度 +20 更耐看，人像更是几乎只用自然饱和度。

色彩平衡（Color Balance）

按阴影/中间调/高光三个色调区间分别加冷暖。用途非常明确：

  • 阴影加蓝/青，画面通透（风光大片常用）
  • 高光加黄，模拟日出日落的暖调
  • 中间调加一点红，人物皮肤更立体
调色别忘了最后一步：滤镜 → 摄影滤镜 → 滤镜库里的胶片预设（VSCO 风格）能快速给一个色彩基调，然后在此基础上微调，比从零开始快得多。但预设容易过度，第一张图别用它。

可选色彩与通道

可选色彩（Selective Color）

它按颜色分量做加/减，比 HSL 更精细，可以单独「把红色里的黄抽掉」而不影响蓝色。对齐色：

  • 人像：肤色选项里减洋红、加黄，是最经典的操作
  • 风景：蓝色减洋红能让天空更蓝更深
  • 整体统一色偏：全色选项里统一调一个方向

通道混合器（Channel Mixer）

调整 RGB 三个通道之间的混合比例，可以做出单色调效果：把红通道的红色降到 0，只保留蓝通道，就得到蓝调照片。这是黑白之外的第二种「去色」方式，比转灰度更有味道。

黑白转换

Image → Adjustments → BlackAndWhite（黑白调整图层）比直接去色强得多，因为它可以分别控制六个颜色范围的明暗：

  • 红色调亮 → 皮肤变白（最常用）
  • 绿色调暗 → 树叶突出
  • 蓝色调亮 → 天空天空云层次
黑白不是「去饱和」。它本质是调整颜色到灰度曲线的映射，带色彩信息调出来的黑白，比直接转灰度有层次得多。这是黑白摄影最值得掌握的一个工具。

滤镜

滤镜分两类，用途完全不同：

类别 特点 是否破坏像素
滤镜库（渐变、纹理、风格化） 直接改变像素，不可撤销（只能撤销历史那一步） 是
智能滤镜（相机.raw、液化、模糊、锐化、噪点） 作为滤镜堆栈挂在图层的下方，可反复开关 否

智能滤镜的正确用法

把图层转成智能对象后再加智能滤镜，可以获得两个额外能力：

  • 滤镜随智能对象源文件更新而重新计算
  • 滤镜可蒙版：右键滤镜 → 添加蒙版，只让部分区域受滤镜影响

每个智能滤镜右侧的 眼睛图标和Fx 蒙版图标是核心控制点，蒙版上用黑笔刷即可关掉滤镜效果。

「滤镜库」的破坏是真实的：一旦应用，无法再修改参数，只能 Ctrl+Z。养成习惯——先 Ctrl+J 复制图层再试滤镜，不满意直接删图层，比撤销历史干净。

高斯模糊与景深

滤镜 → 模糊 → 高斯模糊 是几乎所有设计的依赖——卡片投影、光晕、背景虚化都靠它。

  • 把它加在图层下方，用纯色层盖住原图，形成柔和投影
  • 给一个图层加高斯模糊+渐变蒙版，就能做出景深效果
  • 滤镜库 → 风格化 → 动态模糊做运动感

液化与相机变形

滤镜 → 液化（智能滤镜）用于瘦身、拉伸，是修图里高频工具。它默认作用于当前图层，所以记得先把图层转智能对象，液化不会毁掉原图。

锐化

锐化放最后。三个常用命令：

命令 作用 适用
USM 锐化 数量 / 半径 / 阈值 最通用。阈值是关键，调高避免噪点被锐化
智能锐化 自动判断细节 边缘不产生白边，人像安全
高反差保留 边缘锐化更强 建筑、风景、极简设计
锐化的阈值参数是防噪核心。它决定「多大的边缘差异才算需要锐化」，设为 3~5 可以避开 JPEG 压缩产生的色块边缘。数值设 0 会把噪点全部放大。

输出

调色完了才输出，格式和色彩空间的选择同样影响最终效果：

用途 格式 色彩空间 注意
网络图片 JPEG sRGB 质量 70–85 足够，不要用「最大」
印刷 TIFF / PSD CMYK 先转 CMYK 再检查，RGB 转 CMYK 会掉色
需透明 PNG / WebP sRGB PNG 无损但大，WebP 更优
继续编辑 PSD — 唯一能保留图层/调整图层的格式

转 CMYK 的正确位置：在调色全部完成后，用 编辑 → 转换配置 → 转换为CMYK。转完再调色就是在 CMYK 的约束下挣扎，很多鲜艳的蓝绿做不到。

常见问题排查

调色没有生效

检查调整图层是否在目标图层上方——调整图层只影响下方。或者被剪贴限制在组内了，双击图层看属性面板的「剪贴到图层」勾选状态。

颜色在不同设备上不一样

没有校色显示器是根本原因，其次是色彩空间不统一。确保：文档用 sRGB、显示器校色过、导出的图也是 sRGB。这三处任一不一致都会偏色。

人像肤色发灰发绿

通常是被 色彩平衡或HSL 的绿色误伤了。修法顺序：先在 HSL 里把红色（肤色）拉回橙色方向，再用色彩平衡 → 阴影加一点红。切记「自然饱和度优先，饱和度最后」。

用了滤镜库想改参数

改不了，只能撤销。所以滤镜库的正确流程是：Ctrl+J 复制图层 → 在副本上试 → 满意后降低副本不透明度 → 合并。

直方图上「剪切」了

高光或暗部像素已经到 255/0，信息已经丢失，任何操作都救不回来。这正是曲线要「压暗高光、提亮阴影」的原因：S 形曲线比直线更能保留两端信息。

画面看着「褪色」

直方图数据集中在中间（对比不足）。修法是曲线上拉 S 形，或色阶里把黑白场拉开。这通常不是「加饱和度」能解决的，饱和度只会让颜色变艳，不会恢复对比。
