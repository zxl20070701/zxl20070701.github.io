文字与排版

Photoshop 的文字本质是带排版参数的图层，不是像素。这点和 GIMP 有本质区别，也是它做排版更省心的原因——只要不栅格化，文字随时可以改。

文字工具基础

T 切换到文字工具 → 在画布上点击 （生成一个点文字，字号自动适应）
→ 拖拽出文本框 （生成一个段落文字，自动换行）

两者的区别很重要：点文字不会自动换行，适合标题；段落文字在编辑时会在行尾显示一个弯箭头（↵），手动回车才换行。段落文字导出时才能正确折行。

字符面板参数

文字图层的字符选项卡里，参数分为几组，按重要性排序：

组 关键参数 作用
字体 字型、字号、行距 字号决定视觉层级，不是越大越醒目
基本字符 粗细、斜体、大小写、上下划线 找字体家族的真实字重，不要用「加粗」硬凑
高级 字距、字距调整、基线偏移 中文标题必调项，见下文
外观 消除锯齿、字形替换、OpenType OpenType 可以启用花体、真实小写、序数等特性
颜色 填充、描边 可以用渐变做填充

消除锯齿

「消除锯齿」下拉里的选项直接影响最终清晰度：

  • 锐利/犀利/犀利/浑厚：像素边缘锐利，适合大字号标题
  • 优化/平滑/柔和/自然：带灰度过渡，适合小字号正文
小字用「锐利」会显得毛躁且有明显锯齿，正文一定用「平滑」类。字号越小，越应该选带灰度过渡的模式。

段落面板

段落排版的核心在这一栏，四个对齐按钮 + 一排缩进控制：

  • 左/中/右/两端对齐：两端对齐会拉伸单词间距，中文长段落慎用
  • 左缩进/右缩进：整体段落缩进
  • 首行缩进：中文排版常用 2 字符
  • 段前/段后间距：段落间距比行距更能影响可读性

Alt+点击某个段落样式图标，可以只把该属性应用到当前选中段落（而不是整个文字图层）。

中文排版要点

中文字体的默认西文间距往往不协调，调整参数是中文设计的必修课：

字距（Tracking）

字距控制字符间空隙的整体宽度。中文大字号标题通常需要收紧字距： 

大字号标题（48px+）：字距 -20 ~ -50
正文（14-16px）：字距 0
小字号标签：字距 +10 ~ +50  （字太小会显拥挤）
中文字距的判断标准：大标题字距收紧会让文字更「整块」，是专业排版的标志。西文标题相反，通常要略微放大字距。

避免标点挤压

中文排版里 GB2312 或 Adobe 大陆标准 字符集能正确处理中文标点占位，比如句号后自动空出一格。默认的「无」会导致中英混排时标点位置不对。

在 文字 → 段落设置 → 中文和日文 里可以指定「文本智能选项」，另外 文字工具选项 → 选定文本 → 沿路径 附近有个「每行居中/左右对齐」可以微调标点对齐。

中英混排

  • 中英文之间加空格是最保险的做法
  • 数字使用「等宽数字」，避免多行文字时数字宽度跳动
  • 全角标点在一行末尾应该允许悬挂（文字面板勾选「允许标点溢出边界」），否则行尾会出现大空隙

变形文字

选中文字图层 → 编辑 → 变换 → 变形，或 Ctrl+T 切换到变形模式。可以做：

变形类型 参数 典型用途
缩放 垂直/水平、定义比例 横向拉宽做标题字
倾斜 水平/垂直倾斜量 斜切效果
扭曲 上下弯曲 弧形排列
旋转 旋转角度 整体倾斜排版
自定义 网格 + 贝塞尔手柄 跟随曲线的异形排版
想做「文字沿弧线排列」：先用钢笔画出弧线路径 → 选中文字图层 → 文字工具选项 → 勾选「沿路径」 → 选中该路径。改文字不用重排，路径随时能调。

变形 + 栅格化的取舍

变形在栅格化之前是可逆的，栅格化后变形信息就丢失了（编辑菜单里的变形会变灰）。所以顺序永远是：先把文字参数和变形调到位，最后再栅格化。

图层样式做标题

双击文字图层打开样式面板，可以给文字加投影、描边、外发光等。这些效果是非破坏性的，改文字内容不会丢失。

立体标题的标准配方

  • 投影：距离 5px，角度 120°，大小 10px，不透明度 50%，颜色纯黑
  • 描边：位置「外」，1px，颜色比填充深一档
  • 渐变叠加：给填充加渐变，注意混合模式选「叠加」保留原文字形状
文字图层的描边不会破坏文字的抗锯齿，这是它比「给文字图层加个描边形状」优越的地方。如果描边让文字变糊，检查描边颜色是否和背景太接近导致视觉粘连。

渐变文字

最干净的做法是样式 → 渐变叠加，混合模式选「正常」，用图层蒙版控制渐变范围。直接在文字填充里选渐变也行，但渐变是沿文字框方向铺的，不是沿字形。

栅格化与排版交付

什么时候需要栅格化

文字 → 栅格化文字图层 会把文字变成普通像素图层。需求这些情况才做：

  • 需要在别的软件里继续用（对方没装字体）
  • 需要用滤镜直接作用于文字（滤镜不能作用于文字图层）
  • 需要做变形 + 像素级效果（如置换贴图）
栅格化是不可逆的，且会按当前渲染精度固化，之后放大必然模糊。交付前最后一步才做，并且先 Ctrl+J 备份一份文字图层。

导出给其它软件

方式 适用 注意
保留 PSD 对方用 PS 继续编辑 唯一能保留图层结构的格式
转曲（文字 → 路径） 转 AI / 导出 SVG 保留矢量轮廓，但失去文字属性
转形状（Ctrl+Alt+Shift+O） 需要单独给形状加渐变/描边 文字变成路径，可编辑节点

转曲 vs 转形状：转形状保留完整的矢量路径（能编辑节点、能加样式），转曲会按当前外观生成轮廓（字形更复杂，节点更多）。优先转形状。

常见问题排查

换电脑字体变了

PSD 里的字体是按名字引用的，没装就替换。要么打包字体，要么把文字栅格化。交付给别人前应该先做字体打包：文件 → 打包 → 打包所有，会生成 PDF 形式的字体包。

文字边缘发虚

三个可能：字号太小（小于 12px 的字在屏幕上必然发虚）、消除锯齿模式选了平滑、图层被缩放或做了变形。用「锐利」模式，或把字放大处理后缩小图层。

字距调了没反应

检查是否选中了整个文字图层还是只选了一部分。另外「字距调整」和「字距」是两个参数：前者是百分比（用于整体光学调整），后者是绝对像素值。

两端对齐导致字距不均

中文段落用两端对齐会拉伸字符间隙，因为中文没有词间距的概念。改用左对齐 + 手动换行，或用段落面板的「中文和日文 → 首尾对齐」功能。

变形后想改文字内容

必须先 Ctrl+Shift+Z 撤销变形，或者在未栅格化时用 编辑 → 变换 → 变形 直接改。变形是「当前状态的渲染」，一旦栅格化就只能重做。

图层样式里的渐变文字显示不对

检查渐变叠加的混合模式。「叠加」「柔光」会受底下的文字填充影响，看起来和预期不同。要完全控制颜色，用「正常」模式然后调整渐变本身。
