界面与快捷键

PS 的快捷键体系分两层：工具快捷键默认不带快捷键（因为字母被占用太多），需要按住 Shift 连按两次工具才能临时切换。这点和 GIMP 差别很大，是新手最不习惯的地方。

工具切换

PS 工具箱里的工具带分组（一个位置下藏着多个同类工具）。切换方式：

操作 效果
单击工具图标 选中当前显示的那个工具
Shift+单击工具图标 在组内循环切换到下一个工具
双击工具图标 展开该工具的设置弹窗（如画笔的选笔预设面板）
长按右键画布 弹出上下文菜单，可临时换工具不改当前设置
长按右键（空格键）是最被低估的功能：比如正在用画笔时，按住右键不放可以临时切到吸管、抓手、缩放，松手自动切回画笔。不用去工具箱翻找。

为常用工具设置快捷键

编辑 → 键盘快捷键（Alt+Shift+Ctrl+K），下拉选择「工具」分类，点「添加快捷键」列直接按组合键。

推荐给这几个工具单独设快捷键：抓手（H）、缩放（Z）、吸管（I）、画笔（B）、修补工具（J）。这五个是频率最高但默认无快捷键的，分配后效率提升立竿见影。

隐藏/显示面板

  • Tab：隐藏/显示所有面板（和 GIMP 相同）
  • Shift+Tab：隐藏/显示除工具栏外的所有面板
  • Ctrl+H：隐藏/显示选区边界（不是面板，是「边界」选项）

隐藏辅助线提升性能

Adobe 官方给的性能建议：绘画或修图时隐藏标尺和参考线类辅助元素，能提升响应速度。

  • Ctrl+R：标尺
  • Ctrl+H：显示额外内容（包括网格、参考线、选区边界）
Ctrl+H 有双重身份：在面板外按是切换额外内容显示，在图层/蒙版缩略图上按是停用该蒙版。位置不同功能不同，很容易记混。

颜色面板

前景色和背景色的几个操作：

  • D：重置为黑白
  • X：交换
  • Alt+点击前景色块：打开拾色器（旧版）
  • 点击颜色块：打开颜色面板取色器
  • Shift+拖拽颜色块：直接在颜色面板上调色
  • 颜色面板里的HSB / RGB / Lab 切换：Lab 在做色彩匹配时最准
PS 拾色器的 HSB 模式有一个「仅 Web 颜色」勾选项，勾上后只能选 Web 安全色（216 色）。除非明确在做兼容性极老的网页，否则永远不要勾，它会大幅限制可选范围。

自定义快捷键

编辑 → 键盘快捷键，打开「键盘快捷键和菜单」对话框。这里能改的不只是工具：

  • 下拉选择应用程序菜单 / 面板菜单 / 工具分别配置
  • 搜索框定位命令，点「快捷键」列改成 New accelerator，直接按键
  • 按 Backspace 清除某个快捷键
  • 冲突时 PS 会提示该组合已分配给谁，可以覆盖或取消

值得改的快捷键

命令 建议键 理由
抓手工具 H 最高频却无快捷键
缩放工具 Z 同上
吸管工具 I 同上（注意不与其它冲突时）
修补工具 J 修图高频
涂抹工具 W 磨皮常用
减淡/加深 O 同上
分配前先在搜索框查一下这个键是否已被占用（PS 会直接提示冲突并给出已分配的命令），比事后发现按了没反应再排查快。

常见问题排查

数字键不生效

输入数字只改变不透明度（如果当前工具支持），它不会切换工具。如果想切换工具得用 Shift+单击或自定义快捷键。

「为什么我的操作没有效果」

第一个要查的是是否处于选区状态。Ctrl+Shift+A 取消选区再试。其次检查图层不透明度是否为 0、图层是否隐藏、是否在错误的图层上。

按住右键不弹出菜单

右键弹出的内容取决于当前工具。想看到完整的上下文菜单，可以先按 Ctrl+Shift+F5 切换右键行为（在首选项 → 鼠标按键和控制里改）。另外如果正在用抓手/缩放这类工具，右键行为会不同。

历史记录步数不够用

改首选项里的撤销步数。但更根本的做法是定期保存 PSD 版本——历史记录在关闭文档后就消失，无法恢复。

找不到某个工具

PS 的工具箱有滚动条和折叠，有些工具藏在分组里。搜索功能：编辑 → 首选项 → 界面 → 工具里可以确认显示方式。另外快速蒙版、退场工具在「…」溢出菜单里。

数字/大小写切换导致快捷键失效

检查输入法状态。中文输入法下某些 PS 快捷键会被输入法拦截，尤其是 Ctrl+空格 这类切换输入法的组合。可在首选项里改输入法快捷键，或改用单键无组合的方案（如把撤销改成 Caps Lock + Z）。
