安装与入门

Photoshop 是目前图像编辑的事实标准，功能强大但代价是订阅制、体积大、启动慢。这篇先讲怎么装、怎么配置首选项、以及第一个文档该怎么做。

购买与安装

Photoshop 是 Adobe Creative Cloud 的核心应用，订阅方式主要有三类（具体价格随地区和促销频繁变化，以官网为准）：

方式 包含内容 适合
单应用订阅 只含 Photoshop + 云存储 只用 PS 的人首选，比全家桶便宜不少
Photography 计划 PS + Lightroom 照片后期为主
Creative Cloud Pro 全家桶 20+ 款应用 需要 AE / PR / AI 等其他工具

另外还有面向学生和教师的教育版（凭资质审核，通常五折左右），以及单月/单年一次性买断的选项（部分地区提供）。所有付费订阅都包含7 天免费试用。

价格和套餐结构 Adobe 调整得很频繁，不要按文章里的数字做决策，直接看官网 plans 页面。另外注意区分「国区版」和海外版，功能基本一致，但账号体系要对应。

安装注意事项

  • Windows 系统盘建议留30GB 以上空间，PS 本身加缓存会占不少
  • 安装时如果选了「安装 Photoshop 试用版」，试用到期后需登录订阅账号
  • 不要把 PS 装在 OneDrive 同步目录里，同步会拖垮性能甚至造成文件损坏
  • Apple Silicon Mac 建议用 Creative Cloud 桌面版安装原生 arm64 版本

首次配置首选项

PS 出厂默认值不一定适合你的机器和工作流。装完第一件事是改首选项：编辑 → 首选项。

性能：内存与缓存盘

设置项 建议 说明
内存使用 70%~80% 留一部分给系统。太高会卡死，太低会频繁用硬盘当虚拟内存
暂存磁盘 SSD 且剩余空间大 不要用 C 盘（系统盘），大图操作时缓存读写非常频繁
GPU 设置 「图形处理器」勾选 + 显存调到最大 界面缩放、视图渲染都靠它，见下文说明
暂存盘和内存是最值得优先调的两项。内存不足的典型症状是「存储暂存磁盘已满」，出现这个提示说明该清理暂存盘了。

性能：GPU 加速

PS 的界面渲染（缩放、平移、旋转视图）依赖显卡。设置路径：编辑 → 首选项 → 性能 → 图形处理器。

  • 勾选「使用图形处理器」
  • 显存设置为最大（通常是 2GB~4GB，依显存而定）
  • 点击「检测」确认可用
GPU 加速确实能提升体验，但存在兼容性 bug：某些老显卡驱动在开启后会出现界面闪烁、缩放卡顿、色彩异常。如果遇到这类问题，第一反应是关掉 GPU 加速试试。

其它值得改的

  • 界面 → 启动时：取消勾选不需要的面板，打开速度明显变快
  • 界面 → 工具：勾选「在停靠工具栏中显示图标的标签」，工具箱显示全称更直观
  • 增效工具 → 首选项：关掉用不到的旧版插件，能加快启动
  • 文件 → 首选项 → 自动保存：把自动保存间隔调到 5 分钟（默认 10 分钟）
  • 增效工具 → 预设 → 迁移预设：从旧版本 PS 迁移画笔、样式等预设

HDR 与色彩空间默认值

新建文档时的色彩空间设置很关键，详见《色彩管理》一篇。这里只记住一句：

新文档默认用 sRGB / 8 位，这是最通用的选择。印刷或需要后期大幅调色时，才考虑 Adobe RGB 或 ProPhoto RGB + 16 位。

文件格式

格式 用途 关键说明
PSD 原生工程文件 唯一能保存全部图层、蒙版、智能对象、调整图层的格式。可能很大
PSB 大画布 PSD 支持最高 30 万像素边长，用于巨幅印刷品
TIFF 印刷 / 归档 无损，可嵌入色彩配置文件和 IPTC 信息
JPEG 网络图片 有损，不支持透明，质量建议 70-85
PNG 需透明 / 无损 体积大；WebP 是更好的替代
WebP 现代网页 比 JPEG 小、比 PNG 支持透明，现在应当作为首选
AVIF 下一代网页 压缩率更高，但兼容性还不如 WebP

保存（Ctrl+S）存 PSD，导出（Ctrl+Alt+Shift+S）出图片。这两个动作是独立的，参见 GIMP 那篇的详细说明——PS 在这一点上逻辑相同但更不容易混淆，因为它有明确的「导出为」菜单项。

打开 RAW

PS 自带 Camera Raw（不是 Lightroom 的 ACR，是 PS 内的独立模块），双击 RAW 文件即进入。

工作流程选择

Camera Raw 打开时会问「合并到新图层」还是「在 Camera Raw 中打开」：

选项 效果 适用
Camera Raw 默认 修改直接烙进像素 普通修图
合并到新图层 修改作为智能滤镜挂在图层下方 推荐，可反复回调 Camera Raw 调参数
转换为智能对象 同上是智能滤镜 同上，措辞不同
养成习惯：打开 RAW 时总是选「合并到新图层」。这样 Camera Raw 参数变成可回溯的智能滤镜，随时能双击回去改——这是 PS 里最容易被忽略的便利功能。

工作流程预设

在 编辑 → 首选项 → 文件处理 → Camera Raw 首选项 里可以设默认工作流程。默认是「默认设置」（通常是 ACR 10.x）。如果习惯 Lightroom 的流程，可以改成「Adobe Camera Settings」并指定版本。工作流程决定了解码算法，RAW 处理是有损的，所以同一个 RAW 用不同流程打开会有画质差异。

关键设置

  • 空间（Space）：设为 ProPhoto RGB 时，RAW 导入后再转 sRGB 会有额外余量
  • 深度（Depth）：16 位，避免大幅调色时出现色阶断层
  • 相机配置文件：Adobe Color 是通用预设，Camera Matching 贴近原相机色彩

界面初见

PS 默认的工作区布局：

区域 快捷键打开 用途
工具栏 — 左侧长条，双击工具名可切换到该工具的设置弹窗
选项栏 — 紧贴工具栏下方，显示当前工具的所有参数
工具预设 — 选项栏右侧的小面板，保存常用工具参数组合
颜色 / 样式 — 前景色背景色、色板、样式和历史记录
调整图层 / 图层样式 — 调整图层图标、样式和蒙版快捷入口
图层 Ctrl+Shift+Alt+G 核心面板
历史记录 Ctrl+Shift+Y PS 的历史记录板有步数上限，详见下文
历史记录面板默认只有 20 步，这是 PS 最反直觉的限制。改成 编辑 → 首选项 → 性能 → 撤消步数（建议 50-100）。不过真正可靠的做法是多存 PSD 版本，因为历史记录在关闭文档后就彻底没了。

工作区布局

  • 窗口 → 工作区：切换预设布局（摄影、绘画、排版规则等）
  • 窗口 → 排列 → 存储工作区：把当前布局存成自己的预设
  • 面板右上角三横菜单 → 「面板列表」：所有面板都能从这里找回来
  • 拖动面板时按住 Alt 可直接复制到浮动窗口
PS 没有「重置界面」的官方命令。布局乱了最快的办法是关掉 PS、删除工作区配置目录下的 Adobe Photoshop 版本号/KnownFoldersSettings.xml（改名备份即可），重开会恢复默认布局。

新建文档

Ctrl+N 打开新建对话框，几个必填项：

选项 建议 说明
名称 写清楚用途 如「首页-主视觉-v3」，后期找文件救命
宽度/高度 按输出定 网页 1920×1080；印刷按 300dpi 反推
分辨率 72 / 96（屏幕），印刷 300 只影响打印输出尺寸，不影响屏幕显示
背景内容 看用途 做设计一般选「透明」，改起来更灵活
色彩模式 RGB 颜色 / 8 位 见《色彩管理》

常见问题排查

试用期到期后打不开

PS 会要求登录 Adobe 账号并确认订阅。没有订阅时只能购买或换用其它工具。此时文件格式是个问题：PSD 需要兼容软件才能打开，可迁移到 GIMP（详见 GIMP 那篇的 XCF 说明），或用 Affinity Photo、Photopea（网页版）应急。

打开很慢 / 卡顿

按优先级排查：关掉 GPU 加速试试 → 清空暂存盘 → 调高内存占比 → 关掉不需要的增效工具 → 检查是否装在机械硬盘上。

界面显示错乱 / 文字重叠

显卡驱动与 GPU 加速的兼容问题。优先更新显卡驱动，仍然异常就关闭 GPU 加速。

「存储暂存磁盘已满」

内存不够 PS 把数据写到硬盘了。处理：编辑 → 首选项 → 性能，确认暂存盘指向 SSD 且空间充足，把内存使用调到 70% 左右。临时救急可以用编辑 → 首选项 → 性能 → 清除剪切板释放内存。

画布变成灰色剪贴板状

内存耗尽的表现。关闭部分文档、盖印可见图层把图层数降到 1、必要时转 8 位模式。养成每阶段存档并关闭文档的习惯。

找不到某个面板

窗口菜单里找，或面板右上角三横 → 面板列表。PS 所有面板都集中在这里，重启 PS 会恢复默认可见性。

PS 占用过高导致其它软件卡

PS 会尽量吃满内存。内存较小的机器上，把 PS 的内存使用限制调到 60%~70%，给系统留出余量。
