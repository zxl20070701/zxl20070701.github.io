导入订阅与节点选择

上一篇把软件装好了，但里面一个节点都没有。这篇解决三件事：怎么把订阅装进去、怎么挑一个能用的节点、怎么让它真正跑起来。

订阅链接从哪来

订阅链接就是你买的服务商（俗称「机场」）给你的那一串地址，通常长这样： 

https://example.com/link/xxxxxxxx?token=abcdefg

一般在服务商的用户中心 → 订阅设置 / 一键订阅页面能找到，部分服务商也提供二维码。

订阅链接等同于你的账号密码，不要发给别人，也不要贴到任何公开的地方（截图、聊天记录、在线文档）。泄露了别人就能用你的流量额度。

导入订阅

第一步：复制链接

在服务商页面复制订阅地址。

第二步：粘贴到 Clash Verge

左侧点卡片图标（订阅），在「订阅」页面右上角找到「新建」按钮：

字段 填什么
名称 随便起，比如「我的机场」，只是给自己看的标签
订阅地址（URL） 粘贴刚才复制的链接
更新间隔 保持默认（1440 分钟 = 每天一次）即可

点「保存」，软件会自动去拉取配置，页面上就会多出一张订阅卡片。成功后节点列表就出现了。

服务商页面一般有「一键导入」入口，会直接唤起 Clash Verge，帮你把链接填好：在机场网页上找「导入到 Clash Verge Rev」的选项，点一下它，比手动复制更省事。

上图就是机场的订阅页面，「复制订阅链接」就在右上角的下拉菜单里。

第三步：点卡片上的「更新」

订阅卡片上有一个刷新图标，点一下是手动更新。机场改了节点、加了新线路、涨价换线路后，都靠它同步。

正常情况下软件每天会自动更新一次订阅。但如果你发现节点突然全没了、或者节点名一直不变，多半是自动更新失败了，手动点一下刷新看看。

订阅导入失败怎么办

报错 原因 解决
401 / 订阅已过期 链接失效或套餐到期 去服务商后台重新复制链接；确认套餐没过期
invalid peer certificate: UnknownIssuer 订阅服务器证书校验失败 编辑该订阅，勾选「允许无效证书（危险）」
更新了但内容没变 缓存住了旧配置 设置页 → 配置目录 → 全删 → 重启软件
「允许无效证书」这一项确实有风险——它关掉了对订阅服务器身份的校验。如果这个订阅链接来自你信任的服务商，开着方便；如果链接来源不明，宁可换一家。

挑节点：看延迟就够

回到代理页面，会看到一列「代理组」（就是订阅里定义的一堆节点分类，比如「自动选择」「故障转移」「ChatGPT」）。

每个节点后面的数字就是延迟（毫秒），越小越快。第一次用直接选「自动选择」这个组，它会自动挑延迟最低的节点，省事。

三种代理组的区别

组类型 行为 适合谁
Selector（手动） 你自己指定用哪个节点 知道哪个节点好的人
URLTest（自动选择） 定期测速，自动选最快的 大多数人用这个就够了
Fallback（故障转移） 主节点挂了自动切备用 想要稳定、省心的场景
节点右侧的 UDP 标签表示这个节点支持 UDP 转发（打游戏、语音通话需要）。没有 UDP 的节点不适合打游戏，看视频没问题。

手动挑节点的几个经验

  • 看延迟不看标签：名字里写「香港 IEPL 专线」的不一定快，实测延迟才是真的
  • 延迟在 200ms 以内 体感就不错，超过 300ms 看视频会卡
  • 延迟显示 timeout 说明这个节点连不上，换一个
  • 点节点名前面的小图钉 📌 可以把节点锁定，锁定后自动选择组会优先用它（红色=锁定且可用，灰色=锁定但当前不可用）

测延迟

左侧靶心图标（测试）页面可以手动测所有节点的延迟。节点很多时测一轮要等一会儿，测的时候别切节点，等它跑完。

测延迟提示「超时」但网站其实能正常访问，通常是杀毒软件（火绒等）的 HTTPS 扫描加密在捣乱。关掉它的 Web 扫描功能，或者把软件目录加进信任名单。

三种模式：规则 / 全局 / 直连

代理页面右上角有三个按钮切换模式，这是 Clash 最核心的概念之一：

模式 行为
规则 按规则分流：国内网站直连、国外网站走代理。国内日常用这个，速度快
全局 所有流量都走你选的节点。等价于「无脑翻墙」
直连 所有流量都不走代理，等于关掉代理

图里标得很清楚：规则按订阅下发的配置文件自动分流，全局把全部流量走你选的节点，直连则完全不经过节点。

日常就用「规则」模式。全局模式下国内网站也绕一圈，速度会慢、流量消耗翻倍。只有在排查「某个网站到底是不是被代理影响了」时，才临时切全局对比一下。

最后一步：打开系统代理

节点选好了，别忘了打开系统代理开关，否则浏览器根本不会来找 Clash：

左下角齿轮 → 设置 → 左侧「系统设置」区域 → 打开「系统代理」。

红框标的就是「系统代理」开关，打开它，浏览器立刻就能用。

开关旁边那个小齿轮是详细设置（指定代理地址、绕过地址、是否开机自动开等），一般不用动。如果你的网络是「公司内网 + 外网」这种复杂环境，可以把内网网段加进 bypass 列表，避免内网流量也走代理。

验证成功

打开浏览器访问 ip.sb 或 ipinfo.io，如果显示的是境外 IP，说明成功了。

更直接的验证方式是看连接页面：正常情况下会实时刷出「哪个程序 → 哪个域名 → 走了哪个节点」的记录。如果这里什么都没有，说明流量根本没进到 Clash，八成是系统代理开关没打开。

上手检查清单

  • 订阅已导入，节点列表不为空
  • 在「自动选择」组里选了一个可用节点
  • 模式保持在「规则」
  • 系统代理开关已打开
  • 浏览器访问 ip.sb 显示的是境外 IP
  • 「连接」页面能看到实时流量记录
