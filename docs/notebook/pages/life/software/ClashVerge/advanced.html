进阶配置：TUN、备份与内核

前三篇覆盖了日常使用。这篇讲几个用得少但很关键的功能：TUN 模式到底要不要开、配置怎么备份同步、内核怎么管理、以及一些提效小技巧。

TUN 模式：什么时候才需要

先搞清楚两个模式的区别，这是理解 TUN 的前提：

模式 原理 接管范围
系统代理 修改操作系统的代理设置，应用主动读系统代理设置才会走 Clash 浏览器、部分遵循系统代理的 GUI 应用
TUN 在系统里装一张虚拟网卡，把所有 IP 流量从网络层接管过来 全部流量：游戏、命令行、命令行工具、UWP 应用

判断你要不要开

按这个顺序自查，有一条满足才考虑开 TUN：

  • 游戏 / Steam / Epic 商店不走代理
  • 命令行工具（git、npm、docker pull）不走代理
  • 某些桌面应用（Electron、Java 程序）不走代理
  • 你接了公司 VPN，两边冲突
能用系统代理解决的，就别开 TUN。TUN 需要管理员权限、会装虚拟网卡、和公司 VPN/安全软件更容易冲突，出问题时排查成本也高得多。

怎么开

设置页 → 左侧「系统设置」→ 打开 Tun（虚拟网卡）模式，旁边的齿轮进详细设置。

配置项 说明
stack 虚拟网卡栈。一般用默认的 system 或 gvisor；gvisor 兼容性最好但更吃 CPU
auto-route 自动接管路由，保持开启，不然很多流量抓不到
dns-hijack 劫持 DNS 请求，解决 DNS 污染。保持开启
mtu 默认 1500。网络卡顿、某些网站加载一半断掉时调到 1400 或 1280 试试
strict-route 严格路由，会拦截更多流量，也更容易和别的软件冲突
TUN 模式下的这些字段由应用接管，你在扩展配置里写了也会被丢弃并弹提示。要改就去设置页的 TUN 对话框里改。

常见 TUN 问题

现象 解决
开 TUN 后完全没网 多半是路由冲突。先关掉 TUN 确认代理本身正常；公司网络加 route-exclude-address 排除内网段
TUN 下比系统代理卡 换 stack；关掉 strict-route；调小 mtu
提示找不到内核 / 服务相关报错 Windows 下去安装目录找 uninstall-service.exe，以管理员身份执行后重装

配置备份与同步

订阅链接、扩展配置、规则设置全在本地，换电脑或重装系统就没了。Clash Verge 支持 WebDav 备份同步。

开启 WebDav 同步

  1. 准备一个 支持 WebDav 的网盘（坚果云、NextCloud、自建等）
  2. 在网盘里新建一个目录，记下它的 WebDav 地址和账号密码
  3. Clash Verge 设置页 → 找到 WebDav 相关设置，填入地址、用户名、密码
  4. 点击「备份」 / 「同步」
坚果云有免费额度且自建 WebDav 友好，是最省事的选择。注意网盘里存的就是你的订阅链接，等于密码也存在网盘里，选可信的服务。

手动备份

不想折腾 WebDav 的话，最简单可靠的方式就是直接复制配置目录：

系统 路径
Windows %APPDATA%\io.github.clash-verge-rev.clash-verge-rev\
macOS ~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev/
Linux ~/.local/share/io.github.clash-verge-rev.clash-verge-rev/

设置页右下角的「配置目录」按钮可以直接打开这个位置。

内核管理

Clash Verge 内置了 Mihomo（Clash.Meta） 内核，也支持切换 Alpha 版内核。

内核 特点
Meta（正式版） 日常用这个，稳定、兼容性好，新特性会慢慢合入
Alpha 抢先体验新特性，可能有 bug
内核出问题时，第一反应是切回正式版内核，或者在设置里手动下载一个指定版本。很多「莫名其妙的连不上」都是内核版本和订阅配置不匹配造成的。

自己下载内核

设置页的内核管理区域可以手动选择本地内核文件。内核文件可以从 MetaCubeX/mihomo 的 Release 下载，对应平台的文件名一般是： 

mihomo-darwin-amd64      # macOS Intel
mihomo-darwin-arm64     # macOS M 芯片
mihomo-linux-amd64      # Linux x64
mihomo-windows-amd64.exe # Windows x64

放到软件安装目录下的 resources 目录并命名为 verge-mihomo（macOS 是 verge-mihomo，注意没有扩展名）即可。

先备份原来的内核文件，替换失败还能退回去。macOS 用户如果是因为系统版本太老（11 以下）用不了新版，可以自己换带 go124 标签的 mihomo 内核。

提效小技巧

托盘图标右键菜单

右下角托盘图标右键，菜单里有一堆常用操作，不用打开主窗口：

  • 快速切换系统代理 / TUN 开关
  • 快速切换规则 / 全局 / 直连 模式
  • 切换最近使用的节点
  • 复制环境变量（给命令行用）
  • 退出（真正停止代理）
关主窗口 ≠ 退出程序。关掉窗口后它还在托盘里跑着，代理依然生效。要彻底关掉，右键托盘图标选「退出」。

静默启动

设置页打开「开机自启」和「静默启动」，开机就自动运行且不弹窗口。

如果静默启动偶尔失效（开机还是弹窗），多半是任务管理器里存在两个启动项。用管理员权限启动软件后开关一次「开机自启」，多余的那个启动项会被清掉。

代理组改名与图标

订阅里的代理组名字带一堆 emoji（🚀 节点选择、📹 YouTube），看久了容易乱。可以在订阅的扩展脚本里批量改名： 

function main(config) {
  if (config["proxy-groups"]) {
    for (const group of config["proxy-groups"]) {
      group.name = group.name.replace(/^[^\u4e00-\u9fa5A-Za-z]+/, "");
    }
  }
  return config;
}

启动页面

设置页的「启动页面」可以选打开软件时停在哪个页。选「代理」最省事，选「订阅」适合管理多份订阅的人。

日志等级

等级 什么时候用
silent / error 日常推荐，省磁盘
warn 想看主要警告时
info / debug 排错时临时开，查完立刻调回去

主题与 CSS 注入

设置页可以自定义主题色、托盘图标，还支持 CSS Injection——写一段 CSS 改界面样式，比如把字体调大、把某块区域隐藏掉。

CSS 注入对版本敏感，升级后样式可能失效。别写太复杂的规则，否则界面可能显示异常。

安全与合规

  • Clash Verge Rev 不收集任何用户数据，配置和日志都只留在本机
  • 订阅链接等同于账号凭证，不要外传
  • 「允许无效证书（危险）」只在信任订阅来源时开启
  • 公司设备上使用前先了解公司的网络使用规定
