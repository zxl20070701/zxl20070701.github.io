下载安装与界面入门

Clash Verge Rev 是一款基于 Tauri + Mihomo（Clash.Meta） 内核的桌面代理客户端，支持 Windows / macOS / Linux。 对纯小白来说，它的价值就一句话：一个图形界面，把「订阅、节点、分流」这些原本要手写 YAML 的事情点几下就能用。

这篇是零基础篇。看完你会知道去哪儿下载、该下哪个文件、装完之后软件长什么样、每个按钮是干什么的。看完直接跳到《导入订阅》那篇。

它到底是什么

先建立几个概念，后面所有操作都围绕这三个词转：

名词 说人话
内核（Mihomo） 真正干活的那个程序，负责接收你的网络请求、判断该走哪条线路。Clash Verge 只是一个套在它外面的壳，内核坏了软件就没用
订阅（Profile） 一份配置文件，机场给你的一串链接，里面写满了节点、代理组和规则
节点 一台位于境外的服务器。订阅里通常有几十个，可以自己挑一个用
认准Clash Verge Rev这个项目（GitHub：clash-verge-rev/clash-verge-rev）。老版的 clash-verge、Clash for Windows 都已停止维护，CFW 的作者还删库跑路了，千万别装。

下载：去哪儿拿

官方只通过 GitHub Release 发布，官网 www.clashverge.dev 只是文档站，下载页也是跳转到 GitHub： 

https://github.com/clash-verge-rev/clash-verge-rev/releases

打开后展开最新的 Release（写作时为 v2.5.8），在 Assets 列表里找对应你系统的文件。不要下载 Source code (zip)，那是源码包，装不了。

下哪个：认准架构

这是小白最容易踩的坑。文件名的 x64 / arm64 指的是 CPU 架构，下错了会直接提示「此应用无法在你的电脑上运行」。

你的电脑 Windows macOS Linux
绝大多数人 x64-setup.exe Intel 选 x64.dmg，M 芯片选 aarch64.dmg amd64.deb / x86_64.rpm
少数新型设备 arm64-setup.exe Apple M 芯片（2020 年后） arm64.deb / aarch64.rpm
不确定自己是什么架构？一律选 x64，这是目前绝大多数 Windows 电脑和 Intel Mac 的配置，选错的概率极低。
文件名里带 fixed_webview2 的版本体积更大，它把 WebView2 运行环境（Clash Verge 的界面就是靠它渲染的）打包进去了。系统里没装 WebView2、装不上的时候才用这个，正常情况别下。

三个平台的安装方式

Windows：双击 -setup.exe 一路下一步。装完建议右键图标「以管理员身份运行」一次，让它把服务模式装上。

macOS：拖进「应用程序」文件夹即可。首次打开如果提示「无法验证开发者」，去系统设置 → 隐私与安全性点「仍要打开」，或者终端执行： 

sudo xattr -d com.apple.quarantine /Applications/Clash\ Verge.app

Linux（Debian/Ubuntu 系）： 

sudo apt install -y ./Clash.Verge_2.5.8_amd64.deb

Linux（CentOS/Fedora 系）： 

sudo dnf install ./Clash.Verge-2.5.8-1.x86_64.rpm
Ubuntu 20.04 装不上（缺 libwebkit2gtk 依赖）？官方建议直接升级系统，别去硬凑依赖。另外这个软件是 GUI 程序，纯命令行服务器上用不了，那种场景请直接用 Mihomo 内核。

装完先做一件事：确认内核能跑

打开软件，左下角有个齿轮图标（设置），进去以后能直接看到「内核版本」。如果这里显示错误、或者代理页面一片空白，说明内核文件没加载成功。

遇到这种情况，去设置页右下角找到「配置目录」，把里面所有文件删掉再重启软件，让它重新下载一份干净的内核。杀毒软件误删内核文件也是常见原因，记得把安装目录加白名单。

界面速览

左侧竖着一排图标就是全部功能了，从上到下依次是：

图标 页面 干什么用
信号格 代理 最常用的一页。选节点、看延迟、切换模式（规则/全局/直连）都在这
卡片 订阅 管理你的订阅链接，新增、删除、更新
地球 连接 实时显示当前有哪些程序在联网、走了哪个节点，排查「哪个软件在偷偷走代理」用
分叉箭头 规则 看分流规则命中情况，也能可视化加规则
列表 日志 出问题时看这里，是排错的第一现场
靶心 测试 测各节点的延迟和连通性
齿轮 设置 系统代理、TUN 模式、端口、界面主题都在这

浅色主题长这样：

默认主题在设置页的「主题模式」里切换：浅色 / 深色 / 系统。软件启动后常驻在系统托盘（右下角小图标），关掉主窗口不等于退出，要真正停止代理得右键托盘图标选「退出」。

三个必看的设置项

第一次用，先去设置页把这三件事确认好，后面所有操作都依赖它们：

设置项 说明
系统代理 最核心的开关。打开后系统会把浏览器的代理指向本机，浏览器才能走代理。绝大部分日常需求只开它就够了
Tun（虚拟网卡）模式 接管系统所有流量，游戏、命令行、某些不认系统代理的软件需要它。开启会装虚拟网卡，权限要求更高，建议先用系统代理，用不够再开
开机自启 + 静默启动 开机自动运行，且不弹主窗口只留托盘图标。配合使用体验最顺
三个开关的官方位置就是左下角齿轮 → 设置，截图里红框标注的就是「系统代理」开关：打开它，浏览器立刻就能用。

上手检查清单

  • 软件能正常打开，代理页能看到界面（不是空白）
  • 设置页里内核版本正常显示
  • 已导入订阅（下一篇讲）
  • 已选好一个节点
  • 已打开系统代理开关
