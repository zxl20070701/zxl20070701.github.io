弱电与网络布线

强电把电送到用电器，弱电把 信号 送到设备：网络、电视、电话、监控、门禁、音响。弱电一旦封在墙里，后期几乎无法补救，所以装修阶段就要一次布好。

弱电布线的核心原则只有一条： 星型拓扑，从弱电箱向每个房间单独拉线 。不要串联、不要分叉、不要中途接头。

弱电箱

弱电箱是所有弱电线路的汇聚点，相当于弱电系统的“总配电箱”：

  • 位置选在入户处、干燥、通风、可打开检修的墙面，避免卫生间背墙和厨房灶台附近。
  • 尺寸至少 400×300mm ，能放下光猫、路由器、交换机、电源插座。
  • 箱内必须有 独立电源插座 ，不要从照明回路取电，否则关灯就断网。
  • 箱内预留 风扇或散热孔 ，光猫和路由器长期运行会积热。
  • 弱电箱 不要与强电箱共用 ，信号线靠近强电会引入干扰。

网线选型

类型 理论带宽 适用场景 建议
超五类（Cat5e） 1Gbps / 100m 百兆宽带、普通家用 已属最低配置
六类（Cat6） 1Gbps / 100m，10Gbps 短距离 千兆宽带、AP、NAS 家用首选
超六类（Cat6a） 10Gbps / 100m 万兆内网、长期不换线 预算充足可上
七类及以上 10Gbps 以上 机房、专业场景 家用性价比低，接口难匹配
网线是 一次埋、用十年 的东西，别在线上省钱。同一套房子里尽量统一规格，避免超五类和六类混用导致链路降速。

买线时怎么辨别

  • 外皮印有 Cat6、UTP、4P 等标识，正规产品还会印米数刻度。
  • 剥开看线芯： 无氧铜呈紫红色 ，铝线或铜包铝偏白、偏脆。
  • 线芯直径：六类线单芯约 0.57mm（23AWG） ，明显偏细的便宜线多为铜包铝。
  • 家用选 非屏蔽（UTP） 即可；屏蔽线（FTP）需要全程良好接地，否则屏蔽层反而变成天线。

布线方式 

弱电箱（光猫 / 主路由）
   ├── 客厅（主路由 / AP / 电视）
   ├── 主卧（AP / 电视）
   ├── 次卧（AP / 电视）
   ├── 书房（电脑 / NAS）
   ├── 厨房（预留）
   └── 卫生间（预留，弱电箱内不接入）
  • 每个房间至少 1 条网线到弱电箱 ，电视墙建议 2 条（一条上网、一条备用/IPTV）。
  • 网线 不能串联 ：不能从客厅的网口再跳到卧室，必须各自单独回到弱电箱。
  • 网线 禁止中途接头 ，也禁止打结、用钉子固定压扁；弯折半径不小于线径的 4 倍。
  • 弱电与强电平行距离保持 30cm 以上 ；必须交叉时 直角交叉 ，并尽量缩短交叉段。
  • 穿线管用 PVC 弱电管 ，管径按线数预留，保证以后能抽换。

无线覆盖：AP 还是 Mesh

方案 原理 优点 限制
单台无线路由 一台设备覆盖全屋 便宜、简单 大户型远端信号弱
Mesh 组网 多台节点无线/有线互联 可后期加节点 无线回程会掉速
AC + AP 面板 每个房间一个面板 AP 信号均匀、无缝漫游 需 提前布网线 ，成本高
吸顶 AP 吊顶内安装 覆盖广、更美观 需预留 吊顶位置与网线
想装面板 AP 或吸顶 AP，装修时就必须把网线布到对应位置，并预留 86 底盒或吊顶开孔 。事后想装，只能走明线。

POE 供电

  • POE（以太网供电） 让网线同时传数据和供电，面板 AP、摄像头、门禁都不需要单独拉电源。
  • 需要一台 POE 交换机 ，标准为 802.3af（15.4W）/ 802.3at（30W）。
  • POE 设备必须 确认供电标准一致 ，握手不成功时设备不亮，容易误判为线路故障。

其它弱电线路

线路 是否还必要 布线要点
电视同轴 逐渐被 IPTV / 网络电视取代 如仍使用有线电视，电视墙预留 1 条至弱电箱
电话线 基本不需要 可用网线替代，不必单独布放
HDMI / 光纤 HDMI 需要（预埋投影/电视到机柜） 必须预埋穿线管 ，且管径要够接头通过
监控摄像头 需要 优先 POE + 网线；户外需防水盒
门禁 / 可视对讲 需要 按厂家要求预留电源与信号线
背景音乐 / 音响 可选 吸顶喇叭需预留 音频线与电源
HDMI 线接头体积大， 穿线管要选 25mm 以上 ，或改用可拆卸接头的光纤 HDMI。很多人预埋了 20mm 管，最后线头根本穿不过去。

验收方法

  • 用 网线测线仪 逐个端口测：8 芯全通、线序正确（T568B）、无短路。
  • 有条件用 网线认证测试仪 测长度、衰减、串扰，长距离链路尤其重要。
  • 网线两端 打标签 ，标注“房间 + 用途”，否则后期在弱电箱里只能靠猜。
  • 确认弱电箱内插座通电、光猫可放置、箱门可正常开合。
