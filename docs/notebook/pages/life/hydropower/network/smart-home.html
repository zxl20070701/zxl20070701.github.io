智能家居布线

智能家居的坑几乎都埋在 装修阶段 ：开关盒里少一根零线、窗帘盒里没有电源、弱电箱没有插座，后期再想加设备只能走明线或放弃。

智能家居布线的核心不是“现在买什么设备”，而是 把电和网提前留够 。设备三年一换，线路二十年不动。

先定协议，再定布线

协议 特点 对布线的要求 适用
WiFi 无需网关，接入简单 依赖 无线覆盖 ，设备多了挤占信道 摄像头、大家电
Zigbee 低功耗、自组网、设备多 需要 网关 + 常供电节点 传感器、灯具、开关
蓝牙 Mesh 手机直连、成本低 需要网关做远程 灯具、小设备
Thread / Matter 新标准、跨品牌互通 需要 边界路由器 （常为常供电设备） 新装修建议关注
有线总线（KNX/RS485） 极稳定、抗干扰 必须预埋专用总线 ，成本高 大宅、别墅
不要把全屋押在单一协议上。 照明用 Zigbee/蓝牙，摄像头用 WiFi/POE，空调窗帘用红外或总线 ，按设备特性选，而不是按品牌选。

开关盒：零线是底线

传统开关盒里通常只有 火线和灯控线 ，没有零线。而绝大多数智能开关需要零火线供电：

方案 是否需要零线 稳定性 建议
零火线智能开关 需要 最稳定，可带任意功率灯具 装修首选
单火线智能开关 不需要 靠漏电流取电，易闪烁、带不动低功率灯 老房补救方案
智能灯泡 不需要 依赖常供电，物理开关一关就失联 局部使用
  • 装修时把 每个开关盒都引入零线 ，是成本极低、收益极高的一步。
  • 零线要从 同回路的照明零线 引入，不能从插座回路借，否则漏保会误动作。
  • 开关盒深度建议 不小于 50mm ，智能开关模块较厚，浅盒装不进去。
  • 多联开关位置要 预留中性线并联 ，避免后期加装时互相干扰。

必须预留电源的位置

位置 预留内容 说明
窗帘盒 电源插座 （距顶 20～30cm） 电动窗帘电机，单轨/双轨都要留
吊顶内 零火线 + 网线 吸顶 AP、人体存在传感器、新风
弱电箱 2～3 个插座 + 散热 光猫、主路由、网关、交换机
入户门 电源 + 网线 智能门锁备用供电、可视对讲
卫生间 电源 + 防溅盒 智能马桶、镜前灯、浴霸
厨房 台面插座 + 水槽下电源 净水器、垃圾处理器、洗碗机
阳台 电源 + 地漏 电动晾衣架、洗衣机
床头 双控 + 零线 智能开关、无线场景面板
电动窗帘是最容易被忽略的一项： 窗帘盒里没有电源，就只能明装插座或换手动 。做吊顶前一定确认。

网络是智能家居的地基

  • 智能设备数量多， 主路由 + AP 组网 比单台路由器稳定得多。
  • 网关建议放在 房屋中心位置 ，不要塞在金属弱电箱里——金属箱会屏蔽信号。
  • 弱电箱若是金属门，建议 换成塑料门或常开 ，或把网关移到箱外。
  • 摄像头、NAS、电视等固定设备尽量 走网线 ，把无线带宽留给移动设备。
  • 给智能设备单独划分 IoT 频段或 VLAN ，避免与手机电脑抢占。

传感器与联动

传感器 安装位置 作用
人体存在传感器 吊顶或墙角，避开直射 人来灯亮、人走灯灭
门窗磁 门框与门扇对齐 开门提醒、安防布防
水浸传感器 厨房水槽下、卫生间、热水器旁 漏水报警，联动关阀
烟雾 / 燃气报警 厨房顶部（燃气按气种定高度） 报警并推送
温湿度 各房间 联动空调、地暖、新风
光照 靠窗位置 日照强时自动关帘

常见坑

  • 单火线开关带 LED 灯闪烁：漏电流给灯充电，换零火线或加泄放电容。
  • 智能开关额定功率不够：多盏灯共用一个开关时，核对总功率与灯的类型（LED 有启动冲击）。
  • 断网即失控：优先选支持 本地执行 的网关，关键照明保留物理开关。
  • 网关数量不足：Zigbee 设备过多或距离过远会掉线，按面积增加网关或常供电节点。
  • 插座被智能设备占满：弱电箱、窗帘盒、吊顶都要留够位数。

验收清单

  • 所有开关盒 零线到位、盒深足够 。
  • 窗帘盒、吊顶、弱电箱、入户门 电源与网线预留完成 。
  • 无线覆盖实测： 每个房间信号强度与漫游切换正常 。
  • 网关位置无金属遮挡，弱电箱散热良好。
  • 关键照明保留 物理开关 ，断网也能用。
