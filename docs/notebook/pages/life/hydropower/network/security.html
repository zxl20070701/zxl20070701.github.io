安防监控与门禁

安防系统的价值不在于设备多，而在于 关键位置有画面、异常能报警、断电不断记录 。布点错了，装十个摄像头也拍不到门口。

优先级排序： 入户门 > 庭院/楼道 > 客厅 > 阳台/车库 。室内摄像头涉及隐私，非必要不装。

摄像头选型

类型 供电/传输 优点 限制
POE 网络摄像头 一根网线供电+数据 稳定、可集中管理、无电池焦虑 需 提前布网线
WiFi 摄像头 插座供电 + 无线 安装灵活 依赖无线覆盖，易被干扰
电池摄像头 电池 + 无线 无需布线 需定期充电，录像不连续
4G 摄像头 流量卡 无网络环境可用 有流量成本

关键参数

  • 分辨率：门口、庭院建议 400 万像素以上 ，看清人脸需要足够细节。
  • 夜视：优先 全彩夜视或红外 ，纯白光补光会扰邻。
  • 宽动态：逆光位置（门口朝外）必须支持， 否则白天一片白 。
  • 防护等级：室外 IP66 以上 ，且接头朝下防水。
  • 存储：本地 NVR + 存储卡 + 云存储三选二，避免单点失效。

布点原则

位置 安装高度 要点
入户门 2.2～2.5m，向下俯拍 能看清人脸与快递，避免逆光
庭院 / 车位 2.5～3m 覆盖进出路径，不留死角
客厅 2.2～2.5m 朝向入口，不拍邻窗
阳台 2.2m 防高空坠物、看晾晒
楼道 / 电梯厅 2.5m 需物业同意，注意公共区域规定
摄像头 不得拍到邻居门窗、公共走廊内部 ，否则可能涉及侵犯隐私。安装前最好与物业、邻居沟通。

录像与存储

  • NVR：集中录像，支持多路摄像头，需放在 弱电箱或机房 ，预留电源与网口。
  • 硬盘容量：按“路数 × 码率 × 天数”估算，4 路 400 万像素存 30 天约需 2～4TB 。
  • 建议使用 监控专用硬盘 ，普通硬盘 7×24 写入易损坏。
  • 重要位置开启 移动侦测录像 ，兼顾容量与关键画面。
  • 录像机 接入 UPS 或至少独立回路 ，断电时仍能记录一段时间。

门禁与可视对讲

设备 布线需求 注意
可视对讲室内机 电源 + 网线/专用线 按厂家要求预埋，位置靠近入户门
智能门锁 电池供电为主 可预留 应急供电接口
电磁锁 / 电插锁 12V 电源 + 控制线 需 门禁电源 + 出门按钮
人脸/指纹门禁 电源 + 网线 室外需防水，避免阳光直射屏幕

报警设备

  • 门磁：入户门、窗户，布防后开门即报警。
  • 红外探测器：覆盖主要通道，避免对着热源与宠物。
  • 水浸传感器：厨房水槽下、热水器旁、卫生间，漏水立即推送。
  • 烟感 / 燃气报警：厨房必备，燃气报警按气种定安装高度。
  • 报警建议 声光 + 手机推送 + 联动摄像头 三重，只响不推送等于没有。

施工与验收

  • 摄像头位置 提前布网线 ，并预留 86 底盒或接线盒，接头不裸露。
  • 室外线路 穿管、接头朝下 ，穿墙孔打胶密封，防止雨水渗入。
  • 弱电箱内为 NVR、交换机预留 插座与散热空间 。
  • 验收时逐路查看 白天、夜间、逆光 三种画面，确认可辨识人脸。
  • 确认断电后录像机与摄像头 恢复供电能自动重连 。
  • 修改所有设备的 默认密码 ，关闭不必要的远程访问端口。
