开关插座与照明

开关和插座是用电器接入电路的“终端”，也是装修里最容易出错的环节：轻则跳闸、重则触电。这一篇按 接线规则 → 常见器件 → 安装规范 的顺序整理，并接上 多开关控制灯泡 那篇的进阶内容。

最基础的三条接线规则

开关接 火线 ，灯位接 零线 ，金属外壳接 地线 ——这三条是家庭电路最核心的安全原则。 
错误：火线 ── 开关 ── 灯泡 ── 零线
      （换灯泡时手会碰到火线）

正确：火线 ── 开关 ── 灯泡
零线 ──────────── 灯泡
地线 ──────────── 金属外壳

灯位的零线要 就近直取 ，不要绕远去开关盒里借零线，否则零线断开时灯体会带电。

插座接线

两孔与三孔

类型 接线方式 适用 要求
两孔（无接地） 左零右火 两极电器、绝缘良好的台灯 必须保证 左零右火
三孔（带接地） 左零右火上接地 三极电器、金属外壳电器 地线 必须接实 ，不能悬空
五孔（三孔+两孔） 同上，地线共用 最常用的组合 两孔部分也要左零右火
带开关插座 开关串在火线上 床头、沙发旁、厨台 仍需单独具备可断开的 接地
很多两孔插座出厂时是 反接的 （左火右零）。装之前一定要用 插座测试器 校验，别默认“插上去能用就是对的”。

三相插座（16A 大功率）

  • 外形是 斜三孔 或品字形，三相四线制下为 三相 + 零线 + 地线 。
  • 必须 单独走 4mm² 及以上专线 ，与其它插座共用回路容易发热。
  • 三相电的相序接错会导致 电动机反转 ，但一般不影响照明。
  • 空调、热水器、微波炉、烤箱、洗碗机建议各自 独立回路 + 独立空开 。

常见开关类型

类型 控制方式 接线要点 适用场景
单控 一个开关控一盏灯 火线进开关，出线接灯 最基础
双控（两地控制） 两个开关控一盏灯 两个开关各接 4 根线 （同色 2 根 + 交叉 2 根） 床头双控、走廊两端
三控 / 多控 三个及以上开关 两端仍用双控，中间用 双路切换开关 楼梯、复式、别墅
五孔带开关 开关独立控插座 开关接火线，不用切零线 床头、书桌
人体感应 / 声光 自动感应 需预留 零线 与安装高度，误装率很高 走廊、玄关、卫生间
智能面板 零火 / 单火无线 需确认是否 需要零线 全屋智能

双控与多控的具体接线方法，详见 多开关控制灯泡 那篇，本篇只补充选型与施工要点。

开关安装要点

  • 开关盒底离地 1.3m～1.4m ，玄关处 不要超过 1.4m ，进门抬手即可。
  • 开关面板周围 不要紧贴潮湿墙面 ，否则底盒内容易进水引起漏电跳闸。
  • 面板螺丝要拧紧，底盒内导线 不得顶住面板 ，否则装不平。
  • 开关盒内 不得有接头 ，需要分线时另设底盒或走上方接线。

插座安装规范

位置 建议高度 要点
开关 1.3m～1.4m 进门、床上顺手可及
床头插座 0.6m～0.8m 双侧各一组，带 USB 更实用
沙发 / 电视墙 0.3m～0.5m 记得留网口、HDMI
厨房台面 1.1m～1.3m 远离水槽，且不 直接 放在灶台正后方
卫生间 1.3m～1.6m 必须带防溅盒 + 接地 ，与浴缸淋浴保持距离
洗衣机 / 烘干机 1.0m～1.2m 独立回路，旁边预留防溅
空调 1.8m～2.2m 高度按机型厂家要求
冰箱 0.4m～0.6m 独立回路，避免其它电器跳闸时被断电
地面插座 与地砖齐平 阳台、餐桌旁，需 防水盖板

照明布置

常见灯具类型

类型 特点 注意
LED 灯板 / 灯带 低功耗、寿命长 需预留驱动盒位置，注意散热
筒灯 / 射灯 重点照明、层次感 开孔尺寸要与灯具匹配，先定灯具再开孔
主灯 / 吸顶灯 基础照明 客厅层高低时慎用，易压空间
无主灯设计 只做局部照明，靠灯带+射灯 回路更多，预算和施工要求更高
磁吸轨道灯 可后期调整布局 需要预埋轨道与电源位
落地灯 / 台灯 补充照明，不占回路 预留插座位置

色温与显色指数

  • 色温：3000K 暖黄（卧室、客厅）、4000K 自然白（书房）、6000K 冷白（厨房、卫生间）。全屋尽量统一，不要混搭过多。
  • 显色指数 CRI：大于 80 基本够用，食品、化妆、绘画场景建议 Ra90 以上 。
  • 调光：需要提前确认是 调光型驱动器 还是仅调亮度，普通灯带调光容易闪烁。
装修阶段最容易返工的一点：先确定灯具，再定开孔位置和底盒 。底盒尺寸有 86 型、118 型，开孔偏小就只能改面板，位置偏一个灯位都很麻烦。

施工与验收清单

  • 逐个插座用 测试器 验： 左零右火、接地通、无反接 。
  • 逐个开关确认： 控制的是灯不是零线 ，且断开时灯体不带电。
  • 卫生间接地线、局部等电位联结是否到位。
  • 插座与水管的 水平距离不小于 30cm ，且插孔不在水管正下方。
  • 大功率电器 各有独立回路与空开 ，插座不被普通回路过载牵连。
