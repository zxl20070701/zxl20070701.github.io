配电与用电安全

电路装得好不好，看的不是插座好不好看，而是 配电箱分得对不对、保护配得全不全 。这一篇整理总配电箱的结构、回路分配原则、常见保护装置，以及跳闸、漏电、触电的排查方法。

家庭电路的组成

户内电路从进户开始，路径是固定的： 

进户线 → 总开关（总配电箱） → 分路断路器 → 室内配线 → 开关 / 插座 → 用电器

总配电箱 是整个家庭电路的“中控室”，改造时它决定了以后用电的稳定性。

常见保护装置

装置 作用 判断依据 典型参数
空气开关（断路器） 过载 + 短路保护 电流超过整定值就 自动跳闸 10A / 16A / 20A / 25A / 32A / 40A / 63A
漏电保护器（RCD/RLEB） 检测剩余电流，人触电或绝缘破损时跳闸 剩余电流超过 30mA 且持续 0.1 秒内动作 30mA 高灵敏 ，时间为 0.1s
漏电保护插排 / 转换器 末端精细保护，局部断电 同上，但只保护下游 家用 30mA
保险丝 / 保险电阻 老式短路保护 电流过大熔断，需更换 已较少使用
空开跳 闸 说明过流保护动作，漏保跳 闸 说明剩余电流超限。两种跳闸的原因完全不同，排查思路也不同。

总配电箱的回路分配

一个 100㎡ 左右的户型，通常按下面方式分回路：

回路 空开规格 导线 覆盖范围
照明 16A 2.5mm² 或 1.5mm² 全屋灯具，不含大功率电器
普通插座 20A 2.5mm² 客厅、卧室常规插座
厨房 20A 4mm² 厨房操作台电器
卫生间 20A 4mm² 洗手台、马桶、花洒等 需防水
空调 25A 4mm² 单台挂机或小柜机
大功率（电热水器、烘干机） 32A 4mm² 或 6mm² 单台电器专用回路
洗衣机 / 烘干机 20A 4mm² 洗衣区专用
备用 16A 2.5mm² 为未来设备留出
回路不是越多越好。回路过少，一个空开跳闸全屋都受影响；回路过多， 配电箱空间和成本 都会紧张，还会拉长走线。照明 + 插座 + 空调 + 若干大功率专线，是最常见的组合。

接地与等电位

保护接地线（PE，黄绿双色） 把设备外壳的漏电流导入大地，是防止触电的最后一道防线。

  • 插座的 三孔 / 三极 必须可靠接地，热水器、洗衣机、空调、金属灯具外壳都要接。
  • 卫生间需要做 局部等电位联结 ：把卫生间内所有可触及金属（管道、淋浴器、插座金属面板）用 2.5mm² 或 4mm² 线连成等电位体，再单 独 接到配电箱 PE 母排。
  • 绝对禁止：把零线当接地线用。零线上流过的是工作电流，接地一旦漏电跳闸，电器就无法工作，甚至造成触电。
  • 接地线不能用 开关控制 ，不能装开关或保险，必须一路贯通到配电箱 PE 母排。

跳闸排查

空开跳闸（过载或短路）

  1. 全部断开 下游电器，再逐个插上，找到引发跳闸的那台设备。
  2. 检查是否 多台大功率电器同时使用 ，导致回路总功率超限。
  3. 检查线路或电器是否 短路 ，尤其是新装的电器、插座和接线盒内裸露的铜线。
  4. 若断开所有电器仍跳闸，基本可判断为 线路短路或空开本身损坏 ，必须断总闸请电工排查。

漏保跳闸（剩余电流超限）

  1. 先看漏保上的按钮 ：「T」或「试验」按钮按下去应当 立刻跳闸 。不跳说明漏保自身已失效，必须更换。
  2. 逐回路断开，定位问题回路。
  3. 在问题回路里逐个排除：关掉灯具和插座，按 「电学基础与线材选型」 中的接线自查方法逐点测通断。常见原因包括：潮湿进水进线盒、PE 线误接零线、电器绝缘老化。
  4. 偶发跳闸之后没再复发，可能是 受潮 的暂时性漏电，处理前先将相关线盒、插座 干燥并密封 。

一般过热、烧焦、异味

检查优先顺序：配电箱内空开、插座面板、接线盒。重点找 发黑、变黄、熔化、滋滋声 的部位。发现后：

  1. 立刻断总闸 ，不要试图“再撑一撑”。
  2. 该回路电器全部停止使用，线路或面板 必须更换 ，不可复用。
  3. 记得再检查上游空开是否被“烧坏”，一并据实据量更换。

用电量与空开整定

空开额定电流要 小于线路允许载流量 ，同时 大于回路实际工作电流 ，留 1.2～1.5 倍余量： 

回路工作电流 = 回路内电器总功率 / 220V

20A 空开 → 约 4400W
32A 空开 → 约 7000W
40A 空开 → 约 8800W
空开额定电流必须 小于 线径对应 的载流量——这条防线是“线先于开关烧”的关键。

常见误区

  • “装大空开就不跳闸了”：换大空开等于放弃过载保护，线会先过热熔化，火灾风险剧增。
  • “零线能当地线”：见上文，属于严重违规接线。
  • “漏保越灵敏越好”：30mA 是 人身保护 值，过于灵敏会导致正常漏电（如电容性漏电）频繁误跳，需按规范选型而非越小越好。
  • “插排可以接大功率”：普通插排额定电流通常只有 10A，不要串接大功率电器。
