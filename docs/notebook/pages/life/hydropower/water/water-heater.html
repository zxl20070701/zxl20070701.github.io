热水器安装与热水管路

热水器是家庭里 功率最大、水路最复杂、安全风险最高 的设备之一。选型、专线、水管、排气、安装高度，每一项出问题都可能直接危及人身安全。

无论哪种热水器，都必须做到三点： 独立回路 、可靠接地 、进水口装角阀便于检修 。

类型对比

类型 功率 / 容量 优点 限制
储水式电热水器 1.5～3kW，40～80L 水压稳定、可多点供水 体积大、需提前加热、有保温损耗
即热式电热水器 6～8.5kW 即开即热、体积小 必须 6mm² 以上专线 ，老房常无法承载
燃气热水器 10～16L/min 持续热水、成本低 必须 强排至室外 ，严禁装卫生间内
空气能热水器 主机 + 水箱 省电、容量大 占地、需室外机位、初装贵
太阳能热水器 集热器 + 水箱 运行成本极低 受天气影响，需楼顶或阳台

电热水器：电路要求

专线与空开

功率 工作电流（220V） 导线 空开
1.5kW 约 7A 2.5mm² 16A
2kW 约 9A 2.5mm² 16A
3kW 约 14A 4mm² 20A
6kW（即热式） 约 27A 6mm² 32A
8.5kW（即热式） 约 39A 10mm² 40A
即热式热水器是家庭电路的 最大负载 。装之前务必核对进户线容量，很多老房进户线只有 6mm²，装上后频繁跳闸，甚至线缆过热。

安全装置

  • 漏电保护插头或漏保空开 ：储水式必须配 30mA 漏保，且每月按一次“试验”按钮确认有效。
  • 防电墙 / 隔电墙 ：不是万能，只是增加水路电阻，仍需配合可靠接地。
  • 超温保护、防干烧 ：正规产品自带，安装前确认未拆卸。
  • 热水器 必须单独接地 ，不能借用其它插座的地线，更不能接零线。

水路连接 

冷水进 → 角阀 → 泄压阀 → 热水器进水口
热水器出水口 → 角阀 → 混水阀 / 花洒
（储水式必须装泄压阀，且泄压口不得封堵）
  • 冷热水管 左热右冷 ，管口间距通常 150mm ，中心高一致。
  • 储水式热水器的 泄压阀 必须装在冷水进水口，泄压管接到地漏或排水处， 严禁堵死 ——堵住后水箱内压升高可能爆裂。
  • 进水口装 角阀 ，方便日后更换热水器时关水。
  • 热水管尽量 短、少弯 ，并做保温，减少等待热水的浪费。
  • 热水管 不能用普通 PVC 管 ，必须用 PPR 热水管或不锈钢波纹管。

燃气热水器：排气是生命线

燃气热水器 严禁安装在浴室、卫生间、卧室内 。燃烧产生的一氧化碳无色无味，在密闭空间内可致命。
  • 必须安装在 通风良好的厨房、阳台或专用设备间 ，且与可燃物保持距离。
  • 必须是 强排式或平衡式 ，烟管 直接排到室外 ，不能排进公共烟道（部分老规范允许，需按当地要求）。
  • 烟管 不得过长、过多弯头 ，接口要密封，伸出外墙要有防雨帽。
  • 燃气管道 严禁私自改动 ，改管必须由燃气公司或有资质单位施工。
  • 建议安装 一氧化碳报警器 ，位置靠近热水器但不在其正上方。

燃气管路识别

管材 用途 注意
镀锌钢管 户内燃气主支管 丝接，需专用密封材料
不锈钢波纹管 灶具、热水器连接软管 寿命长，推荐 ，注意不要过度弯折
橡胶软管 老式连接 易老化 ，建议更换为波纹管

安装高度与位置

设备 安装高度 位置要求
储水式电热水器 底部距地 1.5～2.0m 承重墙，必须用膨胀螺栓固定
即热式电热水器 距地 1.4～1.6m 靠近总配电箱，缩短大电流线路
燃气热水器 距地 1.4～1.6m 外墙或阳台，烟管尽量短
混水阀 / 花洒 距地 1.0～1.2m 冷热管口水平、间距一致
储水式热水器注满水重达 100kg 以上 ，挂墙必须固定在承重墙或加固过的墙体上。空心砖墙必须加装支架落地或穿墙固定。

使用与维护

  • 储水式每 半年到一年清洗内胆与更换镁棒 ，水质硬的地区周期更短。
  • 长期不用时 断电并排空 ，避免内胆腐蚀。
  • 燃气热水器每年检查 烟管密封、燃气接口是否漏气 （用肥皂水涂接口观察气泡）。
  • 发现 水温不稳、异味、报警 ，立即停用并报修，不要自行拆解。
  • 橡胶软管使用超过 2 年 建议更换，出现硬化、裂纹立即换。
