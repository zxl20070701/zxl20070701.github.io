充电桩布线

家用充电桩是 持续大功率负载 ：7kW 的桩连续工作几小时，相当于全天开着三台空调。布线和保护做错，轻则频繁跳闸，重则线缆过热。

充电桩必须 独立专线、独立空开、独立漏保 ，不得与家中任何其它回路共用，也不得从普通插座引出。

先确认三件事

确认项 怎么确认 不满足时
车位是否固定产权 / 长租 产权证或租赁合同 无法申请报装
物业是否同意施工 提交施工方案，取得书面同意 先沟通再开工，避免返工
电表容量是否够 看进户线径、总空开、已有负载 向供电公司申请 增容或新装电表
正规流程是： 物业同意 → 供电公司报装 → 电表安装 → 施工布线 → 验收通电 。跳过报装私接，可能被要求拆除，也存在安全隐患。

功率与线径

桩功率 供电方式 电流 导线 空开
3.5kW 单相 220V 16A 4mm² 20A
7kW 单相 220V 32A 6mm² 40A
11kW 三相 380V 16A 5×6mm² 三相 20A
21kW 三相 380V 32A 5×10mm² 三相 40A
线径要按 实际敷设长度 校核：超过 30m 时建议放大一档，超过 50m 建议按厂家要求计算压降。长距离用细线，末端电压会明显下降，桩会报欠压。

保护配置

保护 作用 要求
专用空开 过载、短路 按上表选取，独立安装
漏电保护 防触电 Type A 或 Type B ，含直流分量检测
过压 / 欠压保护 电压异常时断电 多数桩内置，确认已开启
防雷 / 浪涌保护 雷击、电网浪涌 室外或独立电表建议加装 SPD
接地保护 外壳漏电导流 必须可靠接地 ，阻值一般不大于 4Ω
急停 / 漏保测试 紧急断电 安装位置便于操作
电动汽车充电时可能产生 直流剩余电流 ，普通 AC 型漏保可能被“蒙住”而不动作。应选 Type B 或带 DC 6mA 检测的 Type A 漏保。

电缆敷设

  • 线缆必须 穿管或走桥架 ，明敷段用金属管或阻燃 PVC 管，不得裸露。
  • 室外段要 防水、防晒、防碾压 ，穿越车道时需加钢套管或过路盒。
  • 电缆 不得与燃气管同沟 ，与水管同沟时保持间距并做隔离。
  • 地下敷设要有足够埋深并铺砂盖砖，或直接走地下管廊。
  • 线缆两端 打标签 ，标注回路编号与用途。

充电桩安装

  • 安装高度一般 距地 1.2～1.4m ，便于插拔和查看指示灯。
  • 防护等级至少 IP54 ，室外建议 IP65。
  • 桩体前方 加装防撞柱或挡车器 ，避免车辆撞坏。
  • 充电枪线缆要 悬挂收纳 ，不要拖地，防止碾压破损。
  • 桩体附近 不得堆放易燃物 ，保持通风。

常见问题

现象 可能原因 处理
充电中途跳闸 线径不足、空开偏小、接头过热 核对线径与空开，检查端子压接
桩报“接地故障” 接地不良或未接 测接地电阻，补做接地极
充电功率达不到标称 车辆限制、电压偏低、桩限流设置 查车载充电机功率与桩设置
漏保频繁误跳 选型为 AC 型、线路受潮 更换 Type B/A+DC6mA，检查接线盒密封
无法启动充电 未刷卡/未授权、通讯故障 按桩说明书重置，联系售后

安全使用

  • 严禁“飞线”充电 ：从楼上窗口拉排插给车充电，线径和防护都不达标。
  • 雷雨、积水时 暂停充电 ，尤其室外桩。
  • 插拔枪头前先 停止充电 ，不要带电硬拔。
  • 定期检查枪头 有无烧蚀、变形、进水 ，异常立即停用。
  • 长期不用时断开桩前空开。
