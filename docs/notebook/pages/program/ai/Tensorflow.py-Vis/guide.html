入门简介

Python TensorFlow 常用的可视化工具包括 TensorBoard、Matplotlib、Seaborn 和 scikit-learn 的评估工具。其中 TensorBoard 最适合观察训练过程，Matplotlib 和 Seaborn 适合自定义图表。

安装 

pip install tensorboard matplotlib seaborn scikit-learn

常见可视化内容

内容 工具 用途
训练曲线 TensorBoard / Matplotlib 观察 loss、accuracy、val_loss
模型结构 model.summary / plot_model 检查层顺序和输出 shape
混淆矩阵 Seaborn / scikit-learn 分析分类错误
权重和分布 TensorBoard Histograms 观察参数和激活值变化

推荐学习路线

  1. 先学习用 Matplotlib 画 Keras History 曲线。
  2. 再学习 TensorBoard 回调和启动方式。
  3. 然后学习模型结构可视化。
  4. 最后用混淆矩阵分析分类任务。
