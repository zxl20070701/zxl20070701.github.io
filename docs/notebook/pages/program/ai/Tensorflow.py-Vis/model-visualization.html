模型结构可视化

模型结构可视化可以帮助检查层顺序、输出 shape 和参数数量。最常用的是 model.summary，也可以导出结构图。

model.summary 

model.summary()

summary 中重点看三列：Layer、Output Shape、Param #。

导出模型结构图 

tf.keras.utils.plot_model(
    model,
    to_file="model.png",
    show_shapes=True,
    show_layer_names=True
)

如果 plot_model 报缺少依赖，通常需要安装 pydot 和 graphviz。 

pip install pydot graphviz

检查每层输出 shape 

for layer in model.layers:
    print(layer.name, layer.output_shape)

判断建议

  • Dense 第一层前需要明确输入 shape。
  • Conv2D 输入通常是 (height, width, channels)。
  • Flatten 后参数量可能突然变大，需要特别注意。
  • 分类模型最后一层 units 应该等于类别数。
