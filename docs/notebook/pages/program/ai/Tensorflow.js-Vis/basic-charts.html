基础图表

tfjs-vis 可以快速画出散点图、折线图、柱状图等，非常适合观察数据分布和训练过程。

Surface 容器

大多数可视化都需要一个 surface，可以理解为图表显示的位置。 

const surface = {
    name: "训练数据",
    tab: "数据分析"
};

散点图

const data = {
    values: [
        { x: 1, y: 2 },
        { x: 2, y: 4 },
        { x: 3, y: 6 }
    ],
    series: ["样本"]
};

tfvis.render.scatterplot(
    { name: "x 与 y 的关系", tab: "数据分析" },
    data,
    {
        xLabel: "x",
        yLabel: "y",
        height: 300
    }
);

折线图

tfvis.render.linechart(
    { name: "loss 曲线", tab: "训练过程" },
    {
        values: [
            { x: 1, y: 0.8 },
            { x: 2, y: 0.5 },
            { x: 3, y: 0.3 }
        ],
        series: ["loss"]
    },
    {
        xLabel: "epoch",
        yLabel: "loss"
    }
);

柱状图

tfvis.render.barchart(
    { name: "类别数量", tab: "数据分析" },
    [
        { index: "猫", value: 120 },
        { index: "狗", value: 100 },
        { index: "鸟", value: 80 }
    ],
    {
        xLabel: "类别",
        yLabel: "数量"
    }
);

使用场景

  • 训练前先画散点图，观察特征和标签是否有关系。
  • 分类任务先画柱状图，检查类别是否严重不均衡。
  • 训练时画 loss 曲线，判断是否收敛。
