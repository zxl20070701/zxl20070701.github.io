入门简介

和Tensorflow.js配套的可视化库。

官方中文地址：https://js.tensorflow.org/api_vis/latest/?hl=zh-cn。

安装&引入

NPM 

npm install --save @tensorflow/tfjs-vis

然后引入即可： 

import * as tfvis from '@tensorflow/tfjs-vis';

CDN 

<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs-vis"></script>

核心用途

  • 训练前观察数据分布，例如散点图、柱状图。
  • 训练中观察 loss、accuracy、val_loss、val_acc 等曲线。
  • 训练后展示混淆矩阵，分析分类模型具体错在哪里。
  • 检查模型结构、输出 shape 和参数量。

常用能力

能力 API 适合场景
基础图表 tfvis.render.scatterplot、linechart、barchart 看数据分布和指标变化
模型摘要 tfvis.show.modelSummary 检查层结构和参数量
训练回调 tfvis.show.fitCallbacks 接入 model.fit 观察训练过程
评估图表 tfvis.metrics.confusionMatrix、tfvis.render.confusionMatrix 分析分类效果

推荐学习路线

  1. 先学会创建 surface 和绘制基础图表。
  2. 再用 modelSummary 检查模型结构。
  3. 然后把 fitCallbacks 接入训练流程。
  4. 最后用混淆矩阵分析模型分类效果。
