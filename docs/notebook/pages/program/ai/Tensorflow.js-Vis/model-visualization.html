模型结构可视化

tfjs-vis 可以把模型结构和每一层参数展示出来，适合检查层顺序、输出 shape 和参数数量。

显示模型摘要 

const model = tf.sequential();

model.add(tf.layers.dense({
    inputShape: [2],
    units: 8,
    activation: "relu"
}));

model.add(tf.layers.dense({
    units: 1
}));

tfvis.show.modelSummary(
    { name: "模型摘要", tab: "模型" },
    model
);

重点看什么

  • Layer Name：层名称和层顺序是否符合预期。
  • Output Shape：每一层输出 shape 是否正确。
  • Param #：参数数量是否过大，避免小数据训练大模型。

查看每层信息 

model.layers.forEach((layer, index) => {
    console.log(index, layer.name, layer.outputShape);
});

常见判断

  • Dense 第一层需要 inputShape。
  • 卷积模型 flatten 之前一般保持四维数据。
  • 分类模型最后一层 units 应该等于类别数。
  • 参数量远大于样本量时，更容易过拟合。
