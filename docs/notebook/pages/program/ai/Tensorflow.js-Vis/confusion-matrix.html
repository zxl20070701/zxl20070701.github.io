分类评估与混淆矩阵

准确率只能说明总体对了多少，混淆矩阵可以看到每个类别具体被错分成了什么。

生成预测类别 

const preds = model.predict(testXs);
const predLabels = preds.argMax(-1);
const trueLabels = testYs.argMax(-1);

const predArray = Array.from(await predLabels.data());
const trueArray = Array.from(await trueLabels.data());

绘制混淆矩阵 

const classNames = ["猫", "狗", "鸟"];

const values = await tfvis.metrics.confusionMatrix(
    trueArray,
    predArray
);

tfvis.render.confusionMatrix(
    { name: "混淆矩阵", tab: "评估" },
    {
        values,
        tickLabels: classNames
    }
);

如何分析

  • 对角线数值越大，说明该类别预测越准确。
  • 某一行大量分散，说明该真实类别容易被误判。
  • 某两类互相混淆，可能需要更多样本或更清晰的特征。

释放 Tensor 

preds.dispose();
predLabels.dispose();
