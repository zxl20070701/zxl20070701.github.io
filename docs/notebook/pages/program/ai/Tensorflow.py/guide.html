入门简介

TensorFlow 是一个开源机器学习框架，常用于深度学习模型的训练、推理和部署。Python 版本生态最完整，适合系统学习神经网络、计算机视觉、自然语言处理和生产部署。

官方文档地址：https://www.tensorflow.org/?hl=zh-cn。

安装 

pip install tensorflow

验证安装： 

import tensorflow as tf

print(tf.__version__)
print(tf.config.list_physical_devices("GPU"))

TensorFlow 2 的特点

  • 默认使用 Eager Execution，代码会立即执行，调试方式更接近普通 Python。
  • 推荐使用 Keras API 搭建和训练模型，写法简洁。
  • 支持 tf.data 构建高性能数据流水线。
  • 支持 TensorBoard 可视化训练过程。
  • 可以导出 SavedModel，用于部署到服务器、移动端或浏览器。

常用模块

模块 作用 常见 API
tf.Tensor 表示多维数组 tf.constant、tf.Variable、tf.reshape
tf.keras 搭建和训练模型 Sequential、Model、layers、fit
tf.data 构建数据输入流水线 Dataset、map、batch、prefetch
tf.GradientTape 自动求导 tape.gradient
tf.saved_model 模型保存和部署 model.save、tf.keras.models.load_model

推荐学习路线

  1. 先学习 Tensor 与 Shape，理解数据如何表示。
  2. 再学习 Keras 模型搭建方式：Sequential、Functional、Subclassing。
  3. 然后学习 model.compile、model.fit 和训练流程。
  4. 接着学习 tf.data，把数据加载、清洗、打乱、batch 拆清楚。
  5. 最后学习模型保存、TensorBoard 可视化和一个 CNN 图像分类实战。

学 TensorFlow 时最重要的调试习惯是：打印 Tensor 的 shape，观察训练曲线，并确认训练、验证、推理使用同样的数据预处理流程。
