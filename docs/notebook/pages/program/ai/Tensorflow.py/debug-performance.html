调试与性能优化

TensorFlow 调试时要同时关注模型逻辑、数据流水线和硬件使用情况。很多训练问题都来自 shape、dtype、预处理或设备配置。

查看设备 

import tensorflow as tf

print(tf.config.list_physical_devices())
print(tf.config.list_physical_devices("GPU"))

打印 shape 

for x_batch, y_batch in train_ds.take(1):
    print(x_batch.shape)
    print(y_batch.shape)

检查数值 

print(tf.reduce_min(x_batch).numpy())
print(tf.reduce_max(x_batch).numpy())
print(tf.reduce_mean(x_batch).numpy())

图像模型通常希望像素范围是 0 到 1，或者经过标准化后的稳定范围。

性能建议

  • tf.data 中使用 map(..., num_parallel_calls=tf.data.AUTOTUNE)。
  • 数据流水线最后使用 prefetch(tf.data.AUTOTUNE)。
  • 图片数据可以根据任务适当降低分辨率。
  • 先用小数据跑通，再扩大数据集和模型规模。

常见问题定位

  • loss 为 nan：检查学习率、输入异常值、除以 0。
  • 训练很慢：检查是否使用 GPU、数据读取是否成为瓶颈。
  • 验证指标异常：检查训练集和验证集是否预处理一致。
  • 显存不足：减小 batch_size、图片尺寸或模型规模。
