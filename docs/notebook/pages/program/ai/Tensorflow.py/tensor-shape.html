Tensor 与 Shape

Tensor 是 TensorFlow 中最基础的数据结构，可以理解为带有 dtype 和 shape 的多维数组。

创建 Tensor 

import tensorflow as tf

x = tf.constant([[1, 2, 3], [4, 5, 6]])

print(x.shape) # (2, 3)
print(x.dtype) # int32
print(x.ndim)  # 2

常见创建方式 

tf.constant([1, 2, 3])
tf.zeros((2, 3))
tf.ones((2, 3))
tf.random.normal((2, 3))
tf.random.uniform((2, 3))

Variable

Tensor 通常不可变，模型参数需要用 tf.Variable 表示，这样训练时才能更新。 

w = tf.Variable([1.0, 2.0, 3.0])
w.assign([3.0, 2.0, 1.0])
print(w)

reshape 

x = tf.constant([1, 2, 3, 4, 5, 6])
y = tf.reshape(x, (2, 3))

print(y)

reshape 只改变观察数据的维度方式，不改变元素总数。

广播机制 

x = tf.constant([[1, 2, 3], [4, 5, 6]])
b = tf.constant([10, 20, 30])

print(x + b)

b 的 shape 是 (3,)，会自动扩展到每一行，相当于给每一列加一个偏置。

调试建议

  • 图像常见 shape 是 (batch, height, width, channels)。
  • 文本序列常见 shape 是 (batch, sequence_length)。
  • Dense 层输入通常是二维：(batch, features)。
  • 遇到 shape mismatch，优先打印输入、输出、标签的 shape。
