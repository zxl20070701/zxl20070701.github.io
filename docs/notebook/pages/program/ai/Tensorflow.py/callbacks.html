Callback 回调

Callback 可以在训练过程的关键节点执行额外逻辑，例如保存最优模型、提前停止、调整学习率、写入 TensorBoard 日志。

EarlyStopping 

early_stop = tf.keras.callbacks.EarlyStopping(
    monitor="val_loss",
    patience=5,
    restore_best_weights=True
)

当验证集 loss 连续多个 epoch 没有改善时停止训练，避免过拟合和浪费时间。

ModelCheckpoint 

checkpoint = tf.keras.callbacks.ModelCheckpoint(
    "best_model.keras",
    monitor="val_accuracy",
    save_best_only=True,
    mode="max"
)

ReduceLROnPlateau 

reduce_lr = tf.keras.callbacks.ReduceLROnPlateau(
    monitor="val_loss",
    factor=0.5,
    patience=3,
    min_lr=1e-6
)

TensorBoard 

tensorboard = tf.keras.callbacks.TensorBoard(
    log_dir="logs/exp01",
    histogram_freq=1
)

组合使用 

model.fit(
    train_ds,
    validation_data=val_ds,
    epochs=50,
    callbacks=[
        early_stop,
        checkpoint,
        reduce_lr,
        tensorboard
    ]
)

常用建议

  • 正式训练时至少使用 ModelCheckpoint。
  • 验证集指标开始变差时，用 EarlyStopping 控制过拟合。
  • loss 平台期可以用 ReduceLROnPlateau 降低学习率。
  • 需要分析训练过程时，加入 TensorBoard。
