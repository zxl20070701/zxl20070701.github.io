短期记忆

首先隐藏层会把上一时刻的状态，传递给当前时刻，就像一个 “记忆传送带”，实现 “记忆”。其次所有时间步的 RNN 单元，共享同一套权重参数，可以适配任意长度序列。

但原始 RNN 有个硬伤：在处理长序列（比如长篇文章、长对话）时，早期的信息会被 “冲淡”，梯度在反向传播时会指数级消失或爆炸，导致模型无法学习到长期依赖关系。

比如隐藏层中的h₁大致流程是这样的（简化了一下）： 

h₁_第一次值 = input1 + 记忆权重 * 0
h₁_第二次值 = input2 + 记忆权重 * h₁_第一次值
h₁_第三次值 = input3 + 记忆权重 * h₁_第二次值
h₁_第四次值 = input4 + 记忆权重 * h₁_第三次值
......

比如，对于第四次而言，展开是这样的： 

h₁_第四次值
= input4 + 记忆权重 * h₁_第三次值
= input4 + 记忆权重 * (input3 + 记忆权重 * h₁_第二次值)
= input4 + 记忆权重 * (input3 + 记忆权重 * (input2 + 记忆权重 * h₁_第一次值))
= input4 + 记忆权重 * (input3 + 记忆权重 * (input2 + 记忆权重 * (input1 + 记忆权重 * 0)))

最后一个等式变形一下： 

h₁_第四次值 =
input4 +
记忆权重 * input3 +
记忆权重 * 记忆权重 * input2 +
记忆权重 * 记忆权重 * 记忆权重 * input1

如果“记忆权重”小于1，那么可以看出来，前置的输入input3、input2、input1对本此运算的影响呈指级别的下降。

简单的说就是：只能进行有限次数的循环，超过一定次序后内容就会被丢弃或者说衰减的几乎消失，这个特征就称为短期记忆。

可能有人说，那“记忆权重”取1，这样会无限放大历史记忆的影响，可以靠近 1，但不能直接等于 1。

为了解决这些问题，就出现了GRU、LSTM等，专门解决原始 RNN 记不住长期信息、梯度消失的问题。
