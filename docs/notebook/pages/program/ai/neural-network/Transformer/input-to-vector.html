输入如何转成向量数据？

和大模型对话的时候，你的输入如何转成AI可以理解的向量数据？本文讲清楚 Transformer 输入数据转为向量完整流程。

整体流程

原始文本 → 子词切分 (Tokens) → Token Embedding (词嵌入) → + Positional Encoding (位置编码逐维相加) → Transformer Encoder/Decoder

Positional Encoding (位置编码逐维相加)

最终输入给大模型的输入向量 = Token嵌入向量 + 位置编码向量：

不是 "拼接"，是逐元素相加，嵌入向量和位置编码维度完全相同，直接对应维度数值相加，而非左右拼接扩容维度。

所以最终的输入向量只需要再求出位置编码向量就可以了。你可能好奇，为什么需要位置编码向量？

举例子，有两个句子：“我喜欢吃苹果” 和 “我喜欢吃苹果”，完全不是一个意思。所以Transformer需要知道"我"、"喜欢"、"吃"、"苹果"他们在句子中的位置，也就需要位置编码向量。

那位置编码向量如何来的，标准的Transformer采用正弦位置编码（出自《Attention Is All You Need》原始论文）。
