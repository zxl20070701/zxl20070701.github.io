Q、K、V从哪里来？

比如我们有个句子：”猫喜欢吃鱼“。中文是没办法参与数学运算的，所以我们假设进行了如下编码： 

猫=>[1, 0, 0, 0]
喜欢=>[2, 0, 0, 0]
吃=>[3, 0, 0, 0]
鱼=>[4, 0, 0, 0]

现在，提前准备好了另外三个矩阵（这里大小是4*4）：W_Q、W_K和W_V，让input分别和他们相乘： 

Q=input * W_Q
K=input * W_K
V=input * W_V

你可能好奇，W_Q、W_K、W_V哪里来的？这个就类似单个神经元里面的权重W，先猜，然后训练出来的。

那另一个问题，包括Q、K、V，它们是干什么的，能不能解释一下？

拿Q举例子，input * W_Q后得到了Q，写开了，就是：

Q依旧是一个4*4的矩阵，或者说是四行行向量，分别对应“Q_猫”、“Q_喜欢”、“Q_吃”和“Q_鱼”，比如“Q_猫”的意思就是“猫”这个Token想问什么。

所以Q是一个矩阵，就分别表示“猫”、“喜欢”、“吃”和“鱼”这四个token分别想问什么；同样的，K和V分别表示这四个token各自能回答什么问题和自己是什么。

先来看看Q乘上K的转置值是什么？拿第一行举例子，第一行是一个行向量，应该等于： 

(
    Q第一行 * K第一行 ,
    Q第一行 * K第二行 ,
    Q第一行 * K第三行 ,
    Q第一行 * K第四行
)

翻译一下就是： 

(
    “猫”想问的 * “猫”可以回答的,
    “猫”想问的 * “喜欢”可以回答的,
    “猫”想问的 * “吃”可以回答的,
    “猫”想问的 * “鱼”可以回答的
)

看出来了吧，上面这个行向量就分别表示“猫”想问的问题，它们分别可以回答多少。

所以综合一下，Q乘上K的转置值就表示“猫”、“喜欢”、“吃”和“鱼”这四个token分别想问的问题，它们分别可以回答多少。

那，已经到这里了，最后乘上V应该就不难理解了吧。可以回答的就多回答一点，大概这个意思。

总结

输入input是一个矩阵，最后得到的Attention(Q,K,V)也是一个矩阵，他们的区别就是，后者不再是单纯的输入，而是加上了句子上下文语义的新输入（重复一遍：实际还有位置信息等，方便理解我们都先简化，下同），也就自我攻略了，或者说完成了自注意力。
