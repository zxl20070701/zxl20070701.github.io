GNN层的理解

一个实际问题

比如我们现在有5个人：甲、乙、丙、丁、戊，现在的问题是这样的：

乙经济条件正常、丙小康、丁比较穷、戊很有钱，那么，希望你猜一下甲的经济情况。

乙经济条件正常、丙小康、丁比较穷、戊很有钱，那么，希望你猜一下甲的经济情况。

情况一：

甲和乙、丁不认识，甲和丙是普通朋友、甲和戊是夫妻，那么，你大概率认为甲是有钱人

情况二：

甲和丙、戊不认识，甲和乙是普通朋友、甲和丁是夫妻，那么，你大概率认为甲比较穷

你是怎么思考的？根据甲与其他人的关系，以及其他人的经济情况。

GNN层“思考”过程

上面那个问题的思考过程，其实就可以理解成GNN网络中的GNN层的思考过程，下面来简述一下这个计算过程。

对于甲、乙、丙、丁、戊以及他们的关系，可以用下面这样一个图来描述：

图中每个节点表示他们的自身数据（这里就是经济情况，比如0表示很穷，1表示很有钱等），连线表示他们的关系（比如连线值如果是0表示陌生人，连线如果是1表示很亲密比如夫妻等）

一个GNN层的操作步骤就是：聚合、更新、循环。

1、消息生成

对于图中的每个节点，我们首先需要收集其所有相邻节点的信息（即"消息"）。

这通常是通过将相邻节点的嵌入（或特征）通过一个函数 g（例如一个线性变换或一个神经网络）来生成消息。

比如节点甲，会根据其和乙、丙、丁、戊的关系，以及乙、丙、丁、戊的值，生成来自乙、丙、丁、戊的数据： 

来自乙的消息 = g(乙的值 * 甲和乙的关系值)
来自丙的消息 = g(丙的值 * 甲和丙的关系值)
来自丁的消息 = g(丁的值 * 甲和丁的关系值)
来自戊的消息 = g(戊的值 * 甲和戊的关系值)

2、消息聚合

将中心节点收到的所有消息聚合起来。

这通常是通过一个聚合函数（如求和、平均、最大池化等）来完成的。聚合函数的目的是将多个消息合并成一个单一的向量，这个向量将代表中心节点的邻域信息。

还是用甲举例子，比如用求和： 

甲邻居信息 = 来自乙的消息 + 来自丙的消息 + 来自丁的消息 + 来自戊的消息

3、节点更新

使用聚合后的消息来更新节点特征。

通常是通过将聚合后的消息通过一个更新函数σ（如一个神经网络）来实现的。更新函数的作用是结合中心节点当前的特征和邻域信息，以产生一个新的、更丰富的特征。

依旧是用甲举例子： 

甲的新值 = σ（甲的旧值 + 甲邻居信息）

整个图中所有节点（这里就是甲、乙、丙、丁、戊），全部按照甲上面描述的1、2、3操作一遍，就完成了一次更新（我们可以认为这是GNN层的第一层）。

为什么会需要多个GNN层？

比如对于甲乙而言，由于他和丁没有关系（就是没有乙到丁的边），而由于第一次更新后，甲里面携带了丁的消息，那么第二次更新的时候，乙就借助和甲的关系更新到了丁的消息。

对于乙而言，关于丁的消息来自甲的传递，所以对乙的影响会低于甲，这样对于乙而言，既满足了包括丁相关消息，又不会太受丁的影响。

想一下，比如这里，我们不知道乙和丁什么关系，所以没有连线，现实中也很常见，可是这不代表他们真没有关系，多层GNN层就可以解决这个问题。
