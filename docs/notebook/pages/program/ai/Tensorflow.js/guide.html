入门简介

一个用于机器智能的开源基于WebGL加速的JavaScript库，说的简单点：就是一个帮助你进行数值计算的库，尤其是为AI相关运算提供了便利。

官方中文地址：https://tensorflow.google.cn/js?hl=zh-cn。

安装&引入

NPM 

npm install --save @tensorflow/tfjs

然后引入即可： 

import * as tf from '@tensorflow/tfjs';

CDN 

<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs"></script>

适合做什么

  • 在浏览器里运行已经训练好的模型，例如图片分类、姿态检测、文本分类。
  • 直接在浏览器里训练小模型，适合教学、交互式实验和轻量应用。
  • 在 Node.js 中训练或推理，并和 JavaScript 工程体系整合。
  • 把机器学习能力嵌入前端页面，不一定需要单独部署 Python 服务。

基本概念

张量：tensors

也就是一个值的序列，比如零阶张量叫标量（Scalar）也就是一个数字、一阶叫向量、二阶叫矩阵等

变量：variables

因为张量不可变，那就可以定义一个变量，给这个变量赋值一个张量或修改，主要是用于在模型训练时，进行数据的保存和更新。

操作：operations

一些操作数据等方法，就类似矩阵的加法、数量乘法等。

温馨提示：由于张量是不可改变的，所以 operations 操作并不会改变 tensors 的值，而是返回新的张量。

模型和层

简单的理解就是一个带有可训练参数的函数，有一个输入和输出，函数里面定义运算规则（当然，还有稍微复杂一点的神经网络模型等也是）。

内存管理

由于使用了GPU加速数学运算，在使用张量和变量时，管理GPU的内存是必不可少的，其提供了dispose和tf.tidy两个函数来帮助处理内存：

dispose

比如你定义了一个张量或变量，可以用此方法来清除和释放它的GPU内存： 

var b = tf.tensor([[1.0, 2.0, 3.0], [10.0, 20.0, 30.0]]);
b.dispose();

tf.tidy

如果我们定义了很多的张量或变量，使用dispose会很麻烦，你可以这样： 

var myFun = tf.tidy(()=>{
    // 函数体内
});
myFun();

所有myFun定义的函数体内，创建的中间张量，都会被清除和释放它的GPU内存，除了函数需要返回的值。

常用模块

模块 作用 常见 API
Tensor 保存和计算多维数据 tf.tensor、tf.reshape、tf.add
Layers 搭建神经网络模型 tf.sequential、tf.layers.dense、tf.layers.conv2d
Training 配置训练过程 model.compile、model.fit、tf.train.adam
IO 保存和加载模型 model.save、tf.loadLayersModel
Browser 处理浏览器输入 tf.browser.fromPixels、tf.nextFrame

推荐学习路线

  1. 先学习 Tensor 与 Shape，理解数据如何表示。
  2. 再学习常见运算、广播机制和内存管理。
  3. 然后学习 tf.sequential、layers、compile、fit。
  4. 接着学习数据准备、归一化、训练集和验证集。
  5. 最后完成一个浏览器推理或 CNN 图像分类小项目。

学 TensorFlow.js 时最重要的调试习惯是：打印 shape、观察 loss 曲线、检查 Tensor 是否释放。前端项目里，模型正确只是第一步，页面不卡、内存不涨也同样重要。
