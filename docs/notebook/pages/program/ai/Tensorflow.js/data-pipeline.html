数据准备与 tf.data

训练模型前，数据通常需要经历加载、清洗、打乱、归一化、切分训练集和验证集等步骤。TensorFlow.js 可以直接使用 Tensor，也可以使用 tf.data 构建数据流水线。

直接使用 Tensor

小数据集可以直接转成 Tensor，然后传给 model.fit。 

const xs = tf.tensor2d([
    20, 60,
    25, 70,
    30, 80
], [3, 2]);

const ys = tf.tensor2d([0, 1, 1], [3, 1]);

数据归一化

神经网络更喜欢范围相对稳定的数据。常见做法是把数据缩放到 0 到 1，或转成均值接近 0 的分布。 

const min = xs.min();
const max = xs.max();
const normalizedXs = xs.sub(min).div(max.sub(min));
用训练集计算出来的 min、max、mean、std 要保存下来，预测新数据时继续用同一套参数。

使用 tf.data.array

数据量较大，或者需要边加载边训练时，可以用 Dataset。 

const rawData = [
    { x: [20, 60], y: [0] },
    { x: [25, 70], y: [1] },
    { x: [30, 80], y: [1] }
];

const ds = tf.data.array(rawData)
    .shuffle(rawData.length)
    .map(item => ({
        xs: item.x,
        ys: item.y
    }))
    .batch(2);

await model.fitDataset(ds, {
    epochs: 10
});

训练集与验证集

验证集用来观察模型是否真的学到了规律，而不是只记住训练样本。数据较少时可以使用 validationSplit，数据较多时建议自己提前切分。 

await model.fit(xs, ys, {
    epochs: 30,
    batchSize: 32,
    validationSplit: 0.2,
    shuffle: true
});

数据准备检查清单

  • 输入特征是否都转成数字。
  • 训练和预测是否使用同一种归一化方式。
  • 分类标签是否和 loss 函数匹配。
  • 训练集和验证集是否存在数据泄漏。
  • xs.shape[0] 是否等于 ys.shape[0]。
