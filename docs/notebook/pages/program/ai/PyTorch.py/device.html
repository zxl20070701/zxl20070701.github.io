设备管理 CPU / CUDA / MPS

PyTorch Tensor 和模型都运行在某个设备上，例如 CPU、NVIDIA CUDA GPU、Apple Silicon 的 MPS。模型和输入数据必须在同一个设备上，否则会报错。

选择设备 

import torch

if torch.cuda.is_available():
    device = torch.device("cuda")
elif torch.backends.mps.is_available():
    device = torch.device("mps")
else:
    device = torch.device("cpu")

print(device)

移动模型和数据 

model = SimpleNet().to(device)

for x, y in loader:
    x = x.to(device)
    y = y.to(device)
    pred = model(x)
x.to(device) 会返回新 Tensor，不会原地修改 x，所以要写成 x = x.to(device)。

常见设备错误

如果看到类似“Expected all tensors to be on the same device”的错误，通常说明模型在 GPU，但输入或标签还在 CPU，或者反过来。

显存不足怎么办？

  • 减小 batch_size。
  • 减小输入图片尺寸。
  • 使用更小的模型。
  • 验证和推理时加 torch.no_grad()。
  • 删除不再使用的大 Tensor，必要时清理缓存。
del loss
torch.cuda.empty_cache()

CPU、CUDA、MPS 的取舍

设备 特点 适合场景
CPU 兼容性最好，速度较慢 小模型、调试、部署简单任务
CUDA NVIDIA GPU 加速，生态成熟 深度学习训练和大规模推理
MPS Apple Silicon 加速 Mac 本地实验和中小模型训练
