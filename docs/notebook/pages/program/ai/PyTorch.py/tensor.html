Tensor 张量基础

Tensor 是 PyTorch 中最基础的数据结构，可以理解为支持自动求导和硬件加速的多维数组。标量是 0 维 Tensor，向量是 1 维 Tensor，矩阵是 2 维 Tensor，图像和批量数据通常会变成更高维的 Tensor。

创建 Tensor 

#!/usr/bin/python3

import torch

# 从 Python 列表创建
x = torch.tensor([[1, 2], [3, 4]])

# 全 0、全 1、随机数
zeros = torch.zeros(2, 3)
ones = torch.ones(2, 3)
rand = torch.rand(2, 3)

print(x)
print(x.shape)
print(x.dtype)

shape 的理解

shape 表示每个维度的长度。例如图片分类里常见的输入形状是 [batch, channel, height, width]，也就是一批图片、每张图片的通道数、高度和宽度。 

images = torch.rand(32, 3, 224, 224)

print(images.shape)      # torch.Size([32, 3, 224, 224])
print(images.shape[0])   # batch size: 32

常用变形操作 

x = torch.arange(12)

# 改变形状
y = x.reshape(3, 4)

# 增加一个维度
z = y.unsqueeze(0)

# 去掉长度为 1 的维度
w = z.squeeze(0)

print(y.shape)  # [3, 4]
print(z.shape)  # [1, 3, 4]
print(w.shape)  # [3, 4]

广播机制

当两个 Tensor 形状不完全相同但可以兼容时，PyTorch 会自动扩展较小的维度，这叫广播。广播能让代码更简洁，但也容易造成 shape 错误。 

x = torch.ones(3, 4)
bias = torch.tensor([1, 2, 3, 4])

print(x + bias)

与 NumPy 转换 

import numpy as np
import torch

arr = np.array([1, 2, 3])
t = torch.from_numpy(arr)

arr2 = t.numpy()
Tensor 和 NumPy 数组在 CPU 上可能共享内存，修改其中一个可能影响另一个。需要彻底复制时，可以使用 clone() 或 copy()。

学习重点

  • 熟悉 Tensor 的 shape、dtype、device。
  • 理解 reshape、unsqueeze、squeeze、permute 的作用。
  • 训练模型时重点关注 batch 维度是否存在。
  • 报错里出现 size mismatch 时，优先打印每一步的 shape。
