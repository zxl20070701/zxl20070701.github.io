Dataset 与 DataLoader

数据处理代码如果和训练循环写在一起，很快会变乱。PyTorch 用 Dataset 表示“数据怎么取”，用 DataLoader 表示“数据怎么批量加载”。

Dataset 的职责

一个 Dataset 至少需要实现两个方法：__len__ 返回样本数量，__getitem__ 根据索引返回一个样本。 

#!/usr/bin/python3

from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, samples):
        self.samples = samples

    def __len__(self):
        return len(self.samples)

    def __getitem__(self, index):
        x, y = self.samples[index]
        return x, y

DataLoader 的职责

DataLoader 会把 Dataset 包装成可迭代对象，负责 batch、shuffle、多进程加载等工作。 

from torch.utils.data import DataLoader

dataset = MyDataset(samples)
loader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True,
)

for x, y in loader:
    print(x.shape, y.shape)

图像分类目录结构

图像分类任务可以用 torchvision 的 ImageFolder，它要求目录按类别组织： 

data/
  train/
    cat/
      001.jpg
      002.jpg
    dog/
      001.jpg
  val/
    cat/
    dog/

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
])

train_dataset = datasets.ImageFolder("data/train", transform=transform)
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

Transform

Transform 用于把原始数据处理成模型需要的形式，例如图片缩放、裁剪、转 Tensor、归一化、数据增强等。 

transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225],
    ),
])

实践建议

  • 先打印一个 batch 的 shape，确认输入是否符合模型要求。
  • 训练集可以 shuffle，验证集一般不需要 shuffle。
  • 数据增强只用于训练集，验证集保持稳定。
  • 自定义 Dataset 里不要做太慢的操作，必要时提前预处理。
