nn.Module 构建模型

PyTorch 中的神经网络通常继承 torch.nn.Module。在 __init__ 中定义层，在 forward 中定义数据如何流过这些层。

一个最小模型 

#!/usr/bin/python3

import torch
from torch import nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        return self.net(x)

model = SimpleNet()
print(model)

forward 做什么？

forward 描述前向传播逻辑。调用 model(x) 时，PyTorch 实际会执行 forward。一般不要直接调用 model.forward(x)。

查看参数 

for name, param in model.named_parameters():
    print(name, param.shape, param.requires_grad)

常用层

层 作用
nn.Linear 全连接层，常用于分类头或普通表格数据
nn.Conv2d 二维卷积层，常用于图像特征提取
nn.ReLU 非线性激活函数
nn.Dropout 训练时随机丢弃部分神经元，缓解过拟合
nn.BatchNorm2d 批归一化，常用于 CNN

train 与 eval

model.train() 表示训练模式，Dropout、BatchNorm 等层会按训练方式工作；model.eval() 表示评估模式，这些层会切到推理行为。 

model.train()
# 训练

model.eval()
# 验证或推理
eval() 不会自动关闭梯度计算，推理时通常还要配合 torch.no_grad()。
