快速开始

Gin是什么

Gin是一个使用Go语言编写的Web框架，提供路由、中间件和请求绑定等功能。下面从一个最小的HTTP服务开始。

创建项目并安装Gin

为项目创建目录并初始化Go模块，然后添加Gin依赖： 

mkdir gin-hello
cd gin-hello
go mod init example.com/gin-hello
go get github.com/gin-gonic/gin

在项目根目录创建 main.go： 

package main

import (
    "log"

    "github.com/gin-gonic/gin"
)

func main() {
    router := gin.Default()
    router.GET("/", func(c *gin.Context) {
        c.JSON(200, gin.H{"message": "Hello, Gin!"})
    })

    if err := router.Run(":8080"); err != nil {
        log.Fatal(err)
    }
}

运行服务

在项目目录执行 go run .，再访问 http://localhost:8080/。gin.Default()创建包含日志记录和崩溃恢复中间件的路由器，Run启动HTTP服务。
