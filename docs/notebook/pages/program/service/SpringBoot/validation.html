Spring Boot 参数校验与异常处理

@Valid 校验

在 DTO 字段上写校验规则，Controller 参数加 @Valid 触发： 

public class UserCreateRequest {
    @NotBlank(message = "name 不能为空")
    @Size(min = 2, max = 20, message = "name 长度 2-20")
    private String name;

    @NotBlank(message = "email 不能为空")
    @Email(message = "email 格式不正确")
    private String email;

    @NotNull(message = "age 不能为空")
    @Min(value = 0, message = "age 不能小于 0")
    @Max(value = 150, message = "age 不能大于 150")
    private Integer age;
}

@PostMapping
public Result create(@RequestBody @Valid UserCreateRequest req) {
    return Result.ok(userService.create(req));
}

常用校验注解

  • @NotBlank：字符串必填，不能纯空格
  • @NotNull：不能为 null（字符串可以是空串）
  • @Size(min, max)：长度范围
  • @Min / @Max：数字范围
  • @Email：邮箱格式
  • @Pattern(regexp)：自定义正则

全局异常处理

用 @RestControllerAdvice 统一捕获所有异常，返回统一格式： 

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Map<String, String>> handleValidation(MethodArgumentNotValidException e) {
        Map<String, String> errors = new HashMap<>();
        for (FieldError error : e.getBindingResult().getFieldErrors()) {
            errors.put(error.getField(), error.getDefaultMessage());
        }
        return Result.fail(400, "参数校验失败", errors);
    }

    @ExceptionHandler(BusinessException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Void> handleBusiness(BusinessException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }
}

业务异常

Service 里抛业务异常，Controller 不用 try-catch： 

public User getById(Long id) {
    return userRepository.findById(id)
        .orElseThrow(() -> new BusinessException(1001, "用户不存在"));
}
