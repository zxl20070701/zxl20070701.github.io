Spring Data JPA

只写接口不写实现

Spring Data JPA 最神奇的特性：你只定义接口，Spring 自动生成动态代理实现。 

@Repository
public interface UserRepository extends JpaRepository<User, Long> {
    Optional<User> findByEmail(String email);
    boolean existsByEmail(String email);
}

定义 Entity 

@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String name;

    @Column(nullable = false, unique = true, length = 191)
    private String email;

    private Integer age;
}

方法名推导 SQL

Spring 根据方法名自动生成查询：

  • findByEmail → WHERE email = ?
  • findByNameContaining → WHERE name LIKE %?%
  • findByAgeGreaterThanEqual → WHERE age >= ?
  • existsByEmail → SELECT COUNT(*) > 0

复杂查询用 @Query 写 JPQL： 

@Query("SELECT u FROM User u WHERE u.age >= :minAge ORDER BY u.createdAt DESC")
List<User> findOldUsers(@Param("minAge") int minAge);

事务

Service 写方法加 @Transactional，异常自动回滚： 

@Transactional
public User createWithProfile(User user, Profile profile) {
    userRepository.save(user);
    profile.setUser(user);
    profileRepository.save(profile);
    return user;
}
