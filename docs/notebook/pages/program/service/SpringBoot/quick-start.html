快速开始

Spring Boot是什么

Spring Boot基于Spring框架，提供自动配置和内嵌服务器，适合快速构建独立运行的Java应用。本文以Spring Boot 3.x和Java 17为例。

创建项目

使用Spring Initializr创建项目，选择Maven、Java、Spring Boot 3.x，并添加Spring Web依赖。生成并解压项目后，用IDE打开项目根目录。

Spring Web提供构建Web应用和REST接口所需的Spring MVC组件。Initializr会生成依赖配置和Maven Wrapper。

项目入口

默认生成的主类通常位于src/main/java下。它负责启动Spring容器，并通过组件扫描发现同包及其子包中的控制器和其他组件。 

package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

保留Initializr生成的主类和包名即可。新增类应放在主类所在包或其子包中，以便被自动扫描。

添加Web依赖

如果没有通过Initializr选择Spring Web，可在Maven项目的pom.xml中添加以下依赖；Spring Boot parent会管理依赖版本，无需单独指定。 

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
