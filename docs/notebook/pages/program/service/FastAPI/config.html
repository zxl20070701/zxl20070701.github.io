配置管理

配置外置

数据库密码、API 密钥不能写死在代码里，dev 和 prod 不一样。用 pydantic-settings 管理配置。 

pip install pydantic-settings

定义配置类 

from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env")

    app_name: str = "Demo API"
    debug: bool = False
    database_url: str = "sqlite:///./dev.db"
    jwt_secret: str = "change-me"
    jwt_expire_hours: int = 24

settings = Settings()

使用 

from app.config import settings
print(settings.database_url)

环境变量覆盖

优先级：环境变量 > .env 文件 > 默认值。密码不进 git，部署时注入： 

DATABASE_URL=postgresql://user:pass@host/db JWT_SECRET=real uvicorn app.main:app

多环境

按环境分文件，启动时指定： 

ENVIRONMENT=production uvicorn app.main:app

import os
env = os.getenv("ENVIRONMENT", "development")
settings = Settings(_env_file=f".env.{env}")

配置项启动时自动校验类型，类型错了直接报错，不会带病运行。
