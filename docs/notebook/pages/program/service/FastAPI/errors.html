错误处理与API文档

声明响应模型

使用 response_model 指定响应结构。FastAPI会校验并按模型整理返回数据，也会将该结构展示在API文档中。 

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    price: float


@app.get("/items/{item_id}", response_model=Item)
def read_item(item_id: int):
    return {"name": "Notebook", "price": 12.5, "internal_note": "not returned"}

响应中只包含Item声明的字段，internal_note不会出现在客户端响应中。

返回HTTP错误

对于业务上无法处理的请求，可以抛出 HTTPException，并设置合适的状态码和错误说明： 

from fastapi import FastAPI, HTTPException

app = FastAPI()


@app.get("/items/{item_id}")
def read_item(item_id: int):
    if item_id < 1:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item_id": item_id}

调用 GET /items/0 会得到404响应，其JSON内容包含 detail 字段。
