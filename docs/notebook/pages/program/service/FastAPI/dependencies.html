依赖注入

依赖注入是什么

FastAPI 最有特色的功能。你声明需要什么，FastAPI 自动注入。 

@app.get("/users")
def list_users(db: Session = Depends(get_db)):
    return db.query(User).all()

Depends(get_db)告诉 FastAPI：执行这个路由前先调用 get_db()，把返回值注入 db 参数。

常见用法

数据库会话：每个请求拿一个会话，结束自动关。

分页参数：把重复的 skip/limit 抽成依赖类：

class Pagination:
    def __init__(self, skip: int = 0, limit: int = 10):
        self.skip = skip
        self.limit = limit

@app.get("/users")
def list_users(p: Pagination = Depends()):
    return {"skip": p.skip, "limit": p.limit}

当前登录用户：解 token 查用户，受保护路由直接注入：

@app.get("/me")
def read_me(user: User = Depends(get_current_user)):
    return user

依赖可以嵌套

get_current_user 自己也依赖 get_db 和 oauth2_scheme，FastAPI 自动递归解析，不用手动传。

路由级和全局依赖 

# 整个路由组需要登录
router = APIRouter(prefix="/users", dependencies=[Depends(get_current_user)])

# 全局所有请求都经过
app = FastAPI(dependencies=[Depends(log_request)])

为什么用依赖注入

  • 复用：数据库会话、当前用户逻辑写一次到处用
  • 可测试：单测时替换成假依赖
  • 清晰：函数签名直接声明需要什么
