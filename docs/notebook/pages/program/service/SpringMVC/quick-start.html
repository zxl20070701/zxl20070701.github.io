从零搭一个原生项目

Spring MVC 是什么

Spring MVC 是 Spring 的 Web 层模块：一个 Servlet（DispatcherServlet）加上一整套处理请求的组件。它本身不含自动配置、不含内嵌服务器，需要你自己写 web.xml、自己部署到 Servlet 容器（Tomcat 10+）。Spring Boot 的 spring-boot-starter-web 底层用的就是它。

依赖与打包方式

关键点有两个：packaging 必须是 war；Servlet API 由 Tomcat 提供，所以 scope 是 provided，不打进 war。 

<packaging>war</packaging>

<properties>
    <java.version>21</java.version>
    <spring-framework.version>6.2.7</spring-framework.version>
</properties>

<dependencies>
    <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-webmvc</artifactId>
        <version>${spring-framework.version}</version>
    </dependency>
    <dependency>
        <groupId>jakarta.servlet</groupId>
        <artifactId>jakarta.servlet-api</artifactId>
        <version>6.0.0</version>
        <scope>provided</scope>
    </dependency>
</dependencies>

注意是 jakarta.servlet 而不是 javax.servlet。Spring 6 只认 Jakarta 命名空间，对应的容器是 Tomcat 10 及以上，Tomcat 9 会直接启动失败。

目录结构 

SpringMVC6.x-project
├── pom.xml
└── src/main
    ├── java/.../controller/HelloController.java
    ├── java/.../service/HelloService.java
    ├── resources/springmvc.xml          # 容器配置
    └── webapp/WEB-INF/web.xml           # 注册 DispatcherServlet

springmvc.xml：容器里放什么 

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:context="http://www.springframework.org/schema/context"
       xmlns:mvc="http://www.springframework.org/schema/mvc"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="... ">

    <context:component-scan base-package="io.github.zxl20070701.springmvc"/>

    <!-- 注册 HandlerMapping、HandlerAdapter、消息转换器等核心组件 -->
    <mvc:annotation-driven/>

</beans>

没有 <mvc:annotation-driven/> 时，@RequestMapping 仍然能识别（较老版本靠默认策略），但参数绑定、JSON 转换会缺失。加上它是最省心的写法，等价于 Spring Boot 的 WebMvcAutoConfiguration。

web.xml：Boot 里不存在的那份文件 

<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
         version="6.0">

    <servlet>
        <servlet-name>springmvc</servlet-name>
        <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class>
        <init-param>
            <param-name>contextConfigLocation</param-name>
            <param-value>classpath:springmvc.xml</param-value>
        </init-param>
        <load-on-startup>1</load-on-startup>
    </servlet>

    <servlet-mapping>
        <servlet-name>springmvc</servlet-name>
        <url-pattern>/</url-pattern>
    </servlet-mapping>
</web-app>

三个细节：contextConfigLocation 不写会去找 /WEB-INF/springmvc-servlet.xml；load-on-startup 为 1 表示容器启动时就初始化，而不是等第一个请求；url-pattern 用 / 而不是 /*，写成 /* 会把 JSP 也拦进 DispatcherServlet。

控制器与业务类 

@RestController
public class HelloController {

    private final HelloService helloService;

    // 单构造器不用写 @Autowired，容器自己注入
    public HelloController(HelloService helloService) {
        this.helloService = helloService;
    }

    @GetMapping(value = "/hello", produces = "text/plain;charset=UTF-8")
    public String hello(@RequestParam(value = "name", required = false) String name) {
        return helloService.greet(name);
    }
}

之所以要写 value = "name" 和 charset，是因为原生项目没有 Boot 帮忙，这两处后面各有一篇专门讲。

跑起来

不想自己装 Tomcat 时，借 cargo 临时拉一个 Tomcat 10 部署 war，context 就是 finalName： 

<build>
    <finalName>springmvc6</finalName>
    <plugins>
        <plugin>
            <groupId>org.codehaus.cargo</groupId>
            <artifactId>cargo-maven3-plugin</artifactId>
            <version>1.10.15</version>
            <configuration>
                <container>
                    <containerId>tomcat10x</containerId>
                    <artifactInstaller>
                        <groupId>org.apache.tomcat</groupId>
                        <artifactId>tomcat</artifactId>
                        <version>10.1.34</version>
                    </artifactInstaller>
                </container>
            </configuration>
        </plugin>
    </plugins>
</build>

mvn package cargo:run -Dcargo.servlet.port=8090 -Dcargo.rmi.port=8215

curl -s "http://localhost:8090/springmvc6/hello?name=world"
# Hello, world! （来自纯 Spring MVC 6.x，无 Spring Boot）

换端口是为了避开本机可能已被占用的 8080。传统做法则是 mvn package 之后把 target/springmvc6.war 丢进 Tomcat 10 的 webapps 目录。
