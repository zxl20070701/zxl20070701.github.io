官方规范详解

根据 agentskills.io 官方规范，一个 Skill 本质上就是一个文件夹，最少只要包含一个 SKILL.md 文件。

目录结构大致如下：

SKILL.md 文件结构

SKILL.md 采用 YAML frontmatter + Markdown 正文 的格式： 

---
name: skill-name
description: 技能用途及使用时机，Claude 根据它判断是否自动应用
---
# Skill Title
## Instructions
清晰、可操作的规则...
## Examples
- 示例1
- 示例2
## Guidelines
- 指南1
- 指南2

YAML 字段说明

SKILL.md 开头的 YAML 块包含以下字段：

字段 必填 说明
name 否 Skill 显示名称，默认使用目录名。仅支持小写字母、数字和短横线（最长64字符）
description 推荐 技能用途及使用场景，Claude 根据它判断是否自动应用（最长1024字符）
argument-hint 否 自动补全时显示的参数提示，如 [issue-number]
disable-model-invocation 否 设为 true 禁止 AI 自动触发，仅能手动 /name 调用（默认 false）
user-invocable 否 设为 false 从 / 菜单隐藏，作为后台增强能力使用（默认 true）
allowed-tools 否 Skill 激活时 AI 可无授权使用的工具列表
model 否 Skill 激活时使用的模型
context 否 设为 fork 时在子代理上下文中运行
agent 否 子代理类型（配合 context: fork 使用）
hooks 否 技能生命周期钩子配置

支持的变量

Skills 支持在内容中插入动态变量：

变量 说明
$ARGUMENTS 调用 Skill 时传入的所有参数
$ARGUMENTS[N] 按索引访问参数，如 $ARGUMENTS[0]
$N 简写方式，如 $0 表示第一个参数
${CLAUDE_SESSION_ID} 当前会话 ID，用于日志、临时文件、关联输出

如何在 Skills 中使用 Scripts

什么是 Scripts？

Scripts 是 Skills 中的可执行脚本，它们不会被直接加载到 AI 的上下文窗口中，而是通过工具调用的方式按需执行。这种方式避免了上下文溢出，同时提供了强大的扩展能力。

设计理念：Scripts 遵循渐进式披露原则，只在需要时加载和执行，而不是一开始就占用宝贵的上下文空间。

如何编写 Scripts?

Scripts 目录中的脚本可以是 Python、Shell、JavaScript 等任何可执行文件。以下是编写 Scripts 的关键要点：

脚本命名规范

  • 使用有意义的文件名，如 analyze-code.py、generate-report.sh
  • 保持文件名简洁，避免特殊字符
  • 使用正确的文件扩展名（.py、.sh、.js 等）

脚本输入输出

  • 脚本通过命令行参数接收输入：$0、$1 等
  • 脚本输出（stdout）会被捕获并返回给 AI
  • 错误信息（stderr）也会被捕获，用于调试
  • 脚本退出码决定执行是否成功（0 表示成功）

如何在 SKILL.md 中调用 Scripts

在 SKILL.md 中，你可以通过特定的标记来调用 scripts 目录中的脚本：

例子一 

## 代码分析
python scripts/analyze-code.py $0

完整示例

以下是一个完整的示例，展示了如何结合使用 SKILL.md 和 scripts。

整体目录结构 

AgentSkill-Demo/
├─ SKILL.md
└─ scripts/
    └─ run_task.py

scripts/run_task.py 脚本文件 

# /// script
# requires-python = ">=3.9"
# dependencies = []
# ///
import sysdef main():
    # 获取传入参数
    args = sys.argv[1:]
    print("智能体脚本执行成功")
    print("接收参数：", args)
    # 自定义业务逻辑写这里
    result = {"status": "success", "data": "Agent Skills 调用Scripts完成"}
    print(result)
if __name__ == "__main__":
    main()
说明：python3脚本正常运行到底，没有报错、没有主动 exit→ 默认退出码 = 0（成功），所以上面可以不加sys.exit(0)

SKILL.md 技能主文件 

---
name: AgentSkills-ScriptUse
title: 智能体技能调用内置脚本
description: 在Agent Skills中直接调用scripts目录自定义脚本
tags: 智能体,Agent,Skills,Scripts
---

## 可用内置脚本

- scripts/run_task.py 通用业务执行脚本

## 执行流程

调用本地自定义Scripts脚本完成智能体任务处理

```bash
python scripts/run_task.py $0
```
