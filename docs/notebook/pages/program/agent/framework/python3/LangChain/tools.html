工具与运行时

只靠模型自身的知识，智能体能做的事情很有限。通过给 Agent 挂载工具（Tool），模型就可以在对话过程中自主决定调用哪些外部能力（查天气、读文件、请求接口等），拿到结果后再继续推理。

定义工具

使用 @tool 装饰器把一个普通的 Python 函数变成工具。函数的参数类型注解会作为入参结构，文档字符串（docstring）则作为工具的描述交给模型理解。比如下面给 Agent 挂一个"查询天气"的工具： 

#!/usr/bin/python3

from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.tools import tool

llm = ChatOpenAI(
    model="qwen3.5", api_key="ollama", base_url="http://localhost:11434/v1"
)

@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气。"""
    return f"{city}总是阳光明媚！"


agent = create_agent(
    model=llm,
    tools=[get_weather],
    system_prompt="",
)

# 运行代理
result = agent.invoke({"messages": [{"role": "user", "content": "南京的天气怎么样?"}]})

print(result["messages"][-1].content_blocks)

提问"南京的天气怎么样？"时，模型会识别出需要使用 get_weather 工具，自动生成入参 city="南京"，框架执行函数并把结果回传给模型，模型再基于工具结果组织最终回复。

docstring 写清楚非常关键——模型就是靠它来判断"什么时候该用这个工具、参数该怎么填"的。

访问运行时信息

有时候工具内部需要感知当前的对话上下文，比如查看之前的消息。这时可以给工具函数声明一个 ToolRuntime 类型的参数，框架会自动注入运行时对象： 

#!/usr/bin/python3

from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.tools import tool, ToolRuntime

llm = ChatOpenAI(
    model="qwen3.5", api_key="ollama", base_url="http://localhost:11434/v1"
)


@tool
def get_weather(city: str, runtime: ToolRuntime) -> str:
    """获取指定城市的天气。"""

    # 访问运行时信息
    messages = runtime.state["messages"]
    print(messages)

    return f"{city}总是阳光明媚！"


agent = create_agent(
    model=llm,
    tools=[get_weather],
    system_prompt="",
)

# 运行代理
result = agent.invoke({"messages": [{"role": "user", "content": "南京的天气怎么样?"}]})

print(result["messages"][-1].content_blocks)

runtime 参数不需要模型来填，框架在执行工具时会自动注入。通过 runtime.state 可以拿到当前的状态快照，比如完整的消息列表。
