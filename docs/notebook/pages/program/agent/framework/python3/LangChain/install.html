快速入门

LangChain 是一个开源的 Python AI 应用开发框架，提供了模型调用、消息管理、Agent 构建、工具定义等核心能力。从 1.0 版本开始，它统一了 Agent 的创建方式，用 create_agent 一个入口就可以搭建智能体。

安装

安装核心包和 OpenAI 协议的模型接入包： 

    pip3 install langchain langchain-openai
本文的所有示例都使用本地 Ollama 服务提供的模型，需要提前启动 Ollama 并拉取好模型（默认使用 qwen3.5）。如果你使用其他模型提供商，只需要修改 ChatOpenAI 的配置即可。

直接调用模型

在搭建 Agent 之前，先看一下最基础的模型调用。使用 ChatOpenAI 初始化模型（Ollama 提供了 OpenAI 兼容接口，所以可以直接用），把消息组织成列表后调用 invoke： 

#!/usr/bin/python3

from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

# 初始化模型
llm = ChatOpenAI(
    model="qwen3.5", api_key="ollama", base_url="http://localhost:11434/v1"
)

# 发送消息
messages = [
    SystemMessage(content=""),
    HumanMessage(content="你是谁?"),
]

response = llm.invoke(messages)
print(response.content)

其中，SystemMessage 是系统消息，相当于角色设定；HumanMessage 是用户消息。模型的回复在 response.content 中。

创建第一个 Agent

用 create_agent 创建智能体，传入模型、工具列表和系统提示词，然后调用 invoke 进行对话： 

#!/usr/bin/python3

from langchain_openai import ChatOpenAI
from langchain.agents import create_agent

llm = ChatOpenAI(
    model="qwen3.5", api_key="ollama", base_url="http://localhost:11434/v1"
)

agent = create_agent(
    model=llm,
    tools=[],
    system_prompt="",
)

# 运行代理
result = agent.invoke({"messages": [{"role": "user", "content": "你是谁？"}]})

print(result["messages"][-1].content_blocks)

入参使用 {"messages": [...]} 的字典结构，返回值的 result["messages"] 里保存了完整的对话过程，取最后一条消息的 content_blocks 就是模型的最终回复。
