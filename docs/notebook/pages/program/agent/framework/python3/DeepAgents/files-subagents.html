文件任务与子智能体

Python 版 DeepAgents 的定位和 TypeScript 版类似：在 LangChain / LangGraph 之上封装更高层的深度任务能力。它适合需要规划、文件沉淀和子任务协作的场景。

为什么文件能力重要？

模型上下文有限，长任务不能只靠聊天历史。把计划、资料、草稿和结论写入文件，可以让 Agent 像人一样留下工作痕迹，也方便后续检查。

推荐工作区结构 

workspace/
  plan.md
  evidence/
  drafts/
  final.md

子任务设计

  • 调研子任务：只负责收集资料和来源。
  • 分析子任务：只负责比较、归纳和判断。
  • 写作子任务：只负责组织表达。
  • 审核子任务：只负责检查错误、遗漏和风险。

实践提醒

DeepAgents 已经提供了较高层抽象，但工程上仍然要关注权限、成本和验收。尤其是文件写入和外部工具调用，最好限制在当前任务工作区内。

  • 不要让多个子任务同时写同一个文件。
  • 每个子任务输出要有固定格式，方便主 Agent 汇总。
  • 最终结论要能追溯到中间资料。
  • 失败时保留中间文件，方便从断点恢复。
