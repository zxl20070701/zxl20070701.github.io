快速入门

Mastra 是一个开源的 TypeScript AI Agent 框架，提供了构建智能体所需的核心能力：Agent 定义、工具调用、对话记忆、工作流编排、技能（Skill）加载等，各个模块可以按需组合。

安装

在一个 Node.js 项目中安装核心包和 zod（用于定义各种数据结构）： 

    npm install @mastra/core zod
本文的所有示例都使用本地 Ollama 服务提供的模型，需要提前启动 Ollama 并拉取好模型（默认使用 qwen3.5）。如果你使用其他模型提供商，只需要修改 model 配置即可。

创建第一个 Agent

通过 Agent 类创建一个智能体实例，配置智能体的基本信息，然后直接调用 generate 方法进行对话： 

import { Agent } from "@mastra/core/agent";

// 创建 Agent 实例，配置智能体的基本信息
const myAgent = new Agent({
    id: "simple-agent", // 智能体的唯一标识符
    name: "Simple Agent", // 智能体的显示名称
    instructions: ``, // 智能体的系统指令（可为空或填入提示词）
    model: {
        providerId: "ollama", // 模型提供商 ID
        modelId: "qwen3.5", // 模型标识符
        apiKey: "ollama", // API 密钥（Ollama 本地服务不需要）
        url: "http://127.0.0.1:11434/v1", // Ollama API 地址
    }
});

// 调用智能体进行对话
myAgent.generate("你是谁？").then(function (res) {
    // 输出智能体的回复文本
    console.log(res.text);
});

其中，instructions 是智能体的系统指令，相当于角色设定，比如可以在这里告诉它"你的名字是小花"。

注册到 Mastra 实例

除了直接使用 Agent 实例，还可以把 Agent 注册到 Mastra 实例中。Mastra 是整个应用的顶层容器，可以统一登记 agents、workflows、storage 等资源，后续通过名称取用： 

import { Agent } from "@mastra/core/agent";
import { Mastra } from "@mastra/core";

const myAgent = new Agent({
    id: "simple-agent",
    name: "Simple Agent",
    instructions: ``,
    model: {
        providerId: "ollama",
        modelId: "qwen3.5",
        apiKey: "ollama",
        url: "http://127.0.0.1:11434/v1",
    }
});

const mastra = new Mastra({
    agents: { myAgent },
});

mastra.getAgent("myAgent").generate("你是谁？").then(function (res) {
    console.log(res.text);
});

单独使用 Agent 还是注册到 Mastra，取决于应用的复杂度：只有一个智能体的小脚本可以直接用 Agent；当应用里有多个 Agent、工作流和持久化存储时，用 Mastra 统一管理会更方便。
