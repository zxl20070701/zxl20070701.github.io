文件任务与子智能体

DeepAgents 适合处理需要长时间推进的复杂任务，例如研究资料、整理文件、编写报告、分析代码。它把文件系统、计划和子智能体这些能力封装得更靠近“深度任务”。

适合的任务类型

  • 资料研究：搜索、整理、归纳多份材料。
  • 报告生成：先收集证据，再分章节写作。
  • 代码分析：读取多个文件，输出结构化结论。
  • 多步骤执行：任务无法一次回答，需要持续观察和修正。

文件任务的关键点

文件能力不是让模型“随便写文件”，而是给它一个可以沉淀中间结果的工作区。长任务里，Agent 可以把调研资料、草稿、计划和最终结果分开保存。 

workspace/
  plan.md          当前计划
  sources.md       资料来源
  notes.md         中间笔记
  report.md        最终报告

子智能体拆分

子智能体应该围绕职责拆分，而不是围绕“多开几个模型”拆分。比如研究任务可以拆成搜索、阅读、校对三个角色。

角色 职责 输出
Researcher 查找资料并记录来源 sources.md
Writer 根据资料组织正文 draft.md
Reviewer 检查遗漏、矛盾和引用 review.md

使用建议

  • 给每个子智能体明确边界，避免重复工作。
  • 把中间产物写入文件，减少上下文压力。
  • 主 Agent 负责最终整合和验收。
  • 长任务要设置阶段性检查点，避免跑偏后才发现。
