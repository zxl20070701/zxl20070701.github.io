结构体、枚举与集合

结构体

结构体将相关数据组合成一个类型。使用 . 访问字段；修改字段时，实例必须声明为可变。 

struct User {
    name: String,
    age: u8,
    active: bool,
}

fn main() {
    let user = User {
        name: String::from("小明"),
        age: 18,
        active: true,
    };
    println!("{}，{} 岁", user.name, user.age);
}

使用 impl 为类型定义关联函数和方法。方法的第一个参数通常是 &self 或 &mut self。 

struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 20 };
    println!("面积：{}", rect.area());
}

枚举与模式匹配

枚举可以定义多种可能的变体，每个变体还可以携带不同类型的数据。 

enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
}

fn main() {
    let message = Message::Move { x: 10, y: 20 };
    match message {
        Message::Quit => println!("退出"),
        Message::Move { x, y } => println!("移动到 {x}, {y}"),
        Message::Write(text) => println!("{text}"),
    }
}

标准库的 Option<T> 表示一个值可能存在或不存在，Some 表示有值，None 表示无值。Rust 没有空指针；使用 Option 时需要明确处理两种情况。 

fn main() {
    let maybe_number: Option<i32> = Some(5);
    match maybe_number {
        Some(value) => println!("值是 {value}"),
        None => println!("没有值"),
    }
}

集合

Vec<T> 是可增长的同类型元素序列。 

fn main() {
    let mut numbers = vec![1, 2, 3];
    numbers.push(4);
    for number in &numbers {
        println!("{number}");
    }
}

HashMap<K, V> 用于保存键值对，读取时可以得到一个 Option。 

use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    scores.insert(String::from("蓝队"), 10);
    scores.insert(String::from("红队"), 8);

    if let Some(score) = scores.get("蓝队") {
        println!("蓝队：{score}");
    }
}
