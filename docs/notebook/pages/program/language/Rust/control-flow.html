流程控制

if 条件表达式

条件必须是 bool 类型。Rust 的 if 也是表达式，可以将分支结果赋给变量。 

fn main() {
let number = 7;

if number < 5 {
    println!("小于 5");
} else if number == 5 {
    println!("等于 5");
} else {
    println!("大于 5");
}

let label = if number % 2 == 0 { "偶数" } else { "奇数" };
println!("{label}");
}

loop 循环

loop 会持续执行，直到遇到 break。break 可以返回一个值，也可以使用循环标签跳出外层循环。 

fn main() {
let mut attempts = 0;
let result = loop {
    attempts += 1;
    if attempts == 3 {
        break attempts * 10;
    }
};
println!("结果：{result}");

'outer: loop {
    loop {
        break 'outer;
    }
}
}

while 与 for 

fn main() {
let mut n = 3;
while n > 0 {
    println!("{n}");
    n -= 1;
}

for score in [90, 85, 100] {
    println!("分数：{score}");
}

for number in 1..=5 {
    println!("{number}");
}
}

1..5 表示左闭右开区间（不包含 5），1..=5 表示两端都包含。遍历集合时，通常优先使用 for。

match 分支

match 按模式匹配值，分支必须覆盖所有可能情况；_ 可作为兜底分支。 

fn main() {
let score = 82;
let grade = match score {
    90..=100 => "优秀",
    60..=89 => "合格",
    0..=59 => "继续努力",
    _ => "分数无效",
};
println!("{grade}");
}
