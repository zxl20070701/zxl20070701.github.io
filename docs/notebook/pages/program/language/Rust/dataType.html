数据类型

Rust 是静态类型语言，编译器通常可以根据上下文推断变量类型；无法推断时，需要显式标注。

标量类型

整数

有符号整数类型为 i8、i16、i32、i64、i128 和 isize；无符号整数类型为 u8、u16、u32、u64、u128 和 usize。isize 与 usize 的位数取决于目标平台。 

fn main() {
let age: u8 = 20;
let distance: i64 = -120;
let count: usize = 3;
let million = 1_000_000; // 下划线可用于分隔数字
}

浮点数、布尔值和字符

f32 和 f64 是两种浮点数类型，默认推断为 f64。布尔类型为 bool；字符类型 char 使用单引号，表示一个 Unicode 标量值。 

fn main() {
let price = 3.14;        // f64
let enabled: bool = true;
let letter: char = '中';
}

复合类型

元组

元组可以把不同类型的多个值组合成一个值。可以通过模式解构或下标访问元素。 

fn main() {
let user: (&str, u8) = ("小明", 18);
let (name, age) = user;
println!("{name}，{age} 岁");
println!("名字：{}", user.0);
}

数组

数组中的元素类型相同，长度固定。数组的类型写作 [类型; 长度]。 

fn main() {
let scores: [i32; 4] = [95, 88, 76, 100];
let zeros = [0; 5]; // [0, 0, 0, 0, 0]
println!("第一个分数：{}", scores[0]);
}

访问越界的数组下标会在运行时触发 panic；需要可变长度集合时，通常使用 Vec。

字符串与切片

字符串字面量的类型是字符串切片 &str；String 是可增长、可修改的字符串类型。切片借用一段连续数据，而不取得其所有权。 

fn main() {
let greeting: &str = "你好";
let mut message = String::from("Hello");
message.push_str(", Rust");
println!("{greeting}，{message}");

let numbers = [10, 20, 30, 40];
let first_two = &numbers[0..2];
println!("{:?}", first_two);
}
