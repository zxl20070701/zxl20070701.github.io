如何搭建环境和运行？

安装 Rust

Rust 官方推荐使用 rustup 安装工具链。可以从 Rust 安装页面 下载适合当前操作系统的安装程序。安装后，rustup 会提供 Rust 编译器 rustc 和包管理、构建工具 cargo。

安装完成后，在终端检查版本： 

rustc --version
cargo --version

Rust 工具链发布更新时，可以使用下面的命令更新： 

rustup update

创建项目

使用 Cargo 创建一个名为 hello-rust 的可执行项目： 

cargo new hello-rust
cd hello-rust

Cargo 会生成 Cargo.toml 项目配置文件和 src/main.rs 程序入口文件。默认程序如下： 

fn main() {
    println!("你好，Rust！");
}

编译和运行

在项目根目录运行： 

cargo run

只检查代码能否通过编译而不生成可执行文件，可以运行 cargo check；准备发布时可以运行 cargo build --release。
