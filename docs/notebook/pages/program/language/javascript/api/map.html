Map 对象

概述 

// Map 是一组键值对的集合，键可以是任何类型
let map = new Map();

Map 对象保存键值对，并且能够记住键的原始插入顺序。任何值（对象或者基本类型）都可以作为一个键或一个值。

set()

语法 

myMap.set(key, value)

为 Map 对象添加或更新一个指定的键值对。返回 Map 对象本身，可链式调用。

get()

语法 

myMap.get(key)

返回 Map 对象中指定的键值。如果键不存在则返回 undefined。

has()

语法 

myMap.has(key)

判断 Map 对象中是否存在指定的键。返回 true 或 false。

delete()

语法 

myMap.delete(key)

从 Map 对象中移除指定的键值对。删除成功返回 true，键不存在返回 false。

clear()

语法 

myMap.clear()

移除 Map 对象中的所有键值对。没有返回值。

size

语法 

myMap.size

返回 Map 对象的成员数量（键值对数）。

forEach()

语法 

myMap.forEach(function(value, key, map) {
    // 遍历回调
}, thisArg)

按插入顺序依次对 Map 对象中的每个键值对执行一次回调函数。

keys()

语法 

myMap.keys()

返回一个包含 Map 对象中所有键的迭代器。

values()

语法 

myMap.values()

返回一个包含 Map 对象中所有值的迭代器。

entries()

语法 

myMap.entries()

返回一个包含 Map 对象中所有键值对的迭代器。每个键值对是 [key, value] 数组。
