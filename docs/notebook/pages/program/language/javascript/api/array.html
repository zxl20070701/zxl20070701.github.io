Array 数组

slice()

语法 

    array.slice(start, end)

从数组中选择元素（start~end，不包括 end ）后返回一个新的数组（不会改变原始数组）。

splice()

语法 

    array.splice(index, howmany, item1, ....., itemX)

把数组 index~index+howmany（不包括 index+howmany ）位置的内容替换成 item1, ....., itemX，并返回删除的项目（会改变原始数组）。

push()

语法 

    array.push(item1, item2, ..., itemX)

向数组末尾添加新项目，并返回新长度。

pop()

语法 

    array.pop()

移除数组的最后一个元素，并返回该元素。

unshift()

语法 

    array.unshift(item1, item2, ..., itemX)

将新项添加到数组的开头，并返回新的长度。

shift()

语法 

    array.shift()

移除数组的第一项，并返回该元素。

some()

语法 

let result = array.some(function(currentValue, index, arr){
    // 如果当前满足，返回true
}, thisValue)

如果有一个元素满足条件，则表达式返回true , 剩余的元素不会再执行检测。

every()

语法 

let result = array.every(function(currentValue, index, arr){
    // 如果当前满足，返回true
}, thisValue)

如果所有元素满足条件，则表达式返回true。

filter()

语法 

let result = array.filter(function(currentValue,index,arr){
    // 如果当前满足，返回true
}, thisValue)

创建一个新的数组，新数组中的元素是通过检查指定数组中符合条件的所有元素。

map()

语法 

let result = array.map(function(currentValue,index,arr){
    // 处理后返回一个新值
}, thisValue)

返回一个新数组，数组中的元素为原始数组元素调用函数处理后的值。

forEach()

语法 

array.forEach(function(currentValue, index, arr), thisValue)

遍历数组，对每个元素执行一次回调函数，不会改变原数组，也没有返回值。

reduce()

语法 

array.reduce(function(total, currentValue, currentIndex, arr), initialValue)

接收一个函数作为累加器，数组中的每个值（从左到右）开始缩减，最终计算为一个值。

indexOf()

语法 

array.indexOf(item, start)

返回数组中某个指定的元素位置。如果存在则返回索引值，如果不存在则返回 -1。

find()

语法 

array.find(function(currentValue, index, arr), thisValue)

返回数组中第一个满足条件的元素。如果没有找到返回 undefined。

findIndex()

语法 

array.findIndex(function(currentValue, index, arr), thisValue)

返回数组中第一个满足条件的元素的索引。如果没有找到返回 -1。

includes()

语法 

array.includes(item, start)

判断一个数组是否包含一个指定的值，根据情况返回 true 或 false。

sort()

语法 

array.sort(sortfunction)

对数组的元素进行排序。排序顺序可以是字母或数字，并按升序或降序。默认排序为字母升序。

reverse()

语法 

array.reverse()

颠倒数组中元素的顺序，会改变原来的数组。

concat()

语法 

array.concat(array2, array3, ..., arrayX)

用于合并两个或多个数组。此方法不会更改现有数组，而是返回一个新数组。

join()

语法 

array.join(separator)

将数组中的所有元素连接成一个字符串。可选的 separator 参数指定连接符，默认为逗号。

fill()

语法 

array.fill(value, start, end)

用一个固定值填充一个数组中从起始索引到终止索引内的全部元素。不包括终止索引。

flat()

语法 

array.flat(depth)

按照一个可指定的深度递归遍历数组，并将所有元素与遍历到的子数组中的元素合并为一个新数组返回。depth 默认为 1。

at()

语法 

array.at(index)

接收一个整数值并返回该索引的元素，支持正数和负数索引。负数索引从数组末尾开始计数。

toSorted()

语法 

array.toSorted(compareFn)

返回排序后的数组副本，不会修改原数组。为 sort() 的非变异版本。

toReversed()

语法 

array.toReversed()

返回反转后的数组副本，不会修改原数组。为 reverse() 的非变异版本。
