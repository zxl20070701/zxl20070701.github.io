Number 数字

toFixed()

语法 

number.toFixed(digits)

把数字转换为字符串，结果的小数点后有指定位数的数字。digits 参数指定小数位数（0-100）。

toPrecision()

语法 

number.toPrecision(length)

把数字格式化为指定的长度。length 指定有效数字位数（1-21）。

toString()

语法 

number.toString(radix)

把数字转换为字符串。radix 指定基数（2-36），如 2 为二进制，16 为十六进制。

valueOf()

语法 

number.valueOf()

返回一个 Number 对象的原始数值。

isFinite()

语法 

Number.isFinite(value)

判断传入的数值是否为有限数。返回 true 或 false。与全局 isFinite() 不同，不会强制转换参数。

isInteger()

语法 

Number.isInteger(value)

判断传入的数值是否为整数。返回 true 或 false。

isNaN()

语法 

Number.isNaN(value)

判断传入的数值是否为 NaN。返回 true 或 false。与全局 isNaN() 不同，不会强制转换参数。

parseFloat()

语法 

Number.parseFloat(string)

解析一个字符串参数，并返回一个浮点数。如果无法解析则返回 NaN。

parseInt()

语法 

Number.parseInt(string, radix)

解析一个字符串参数，并返回指定基数的整数。radix 为 2-36 之间的整数。

MAX_VALUE

语法 

Number.MAX_VALUE

JavaScript 中最大的正数常量，约为 1.7976931348623157e+308。

MIN_VALUE

语法 

Number.MIN_VALUE

JavaScript 中最小的正数常量，约为 5e-324。

MAX_SAFE_INTEGER

语法 

Number.MAX_SAFE_INTEGER

在 JavaScript 中表示的最大安全整数常量，为 2^53 - 1，即 9007199254740991。

MIN_SAFE_INTEGER

语法 

Number.MIN_SAFE_INTEGER

在 JavaScript 中表示的最小安全整数常量，为 -(2^53 - 1)，即 -9007199254740991。
