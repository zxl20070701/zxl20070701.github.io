Math 对象

ceil()

语法 

    Math.ceil(val)

对一个数进行向上取舍，它返回的是大于或等于函数参数，并且与之最接近的整数。

floor()

语法 

    Math.floor(val)

对一个数进行向下取舍，它返回的是小于或等于函数参数，并且与之最接近的整数。

round()

语法 

    Math.round(val)

对一个数就行四舍五入，把一个数字舍入为最接近的整数。

trunc()

语法 

    Math.trunc(val)

会将数字的小数部分去掉，只保留整数部分。

max()

语法 

Math.max(n1, n2, ..., nX)

返回给定参数中的最大值。如果任一参数无法转换为数字，则返回 NaN。

min()

语法 

Math.min(n1, n2, ..., nX)

返回给定参数中的最小值。如果任一参数无法转换为数字，则返回 NaN。

abs()

语法 

Math.abs(val)

返回数的绝对值。计算方法：负数变正数，正数不变。

pow()

语法 

Math.pow(x, y)

返回 x 的 y 次幂。即 x^y。

sqrt()

语法 

Math.sqrt(val)

返回一个数的平方根。如果传入的是负数，则返回 NaN。

cbrt()

语法 

Math.cbrt(val)

返回一个数的立方根。

log()

语法 

Math.log(val)

返回一个数的自然对数。自然对数以常数 e 为底数。

log2()

语法 

Math.log2(val)

返回以 2 为底的对数。

log10()

语法 

Math.log10(val)

返回以 10 为底的对数。

exp()

语法 

Math.exp(x)

返回 e 的 x 次幂。常数 e 约等于 2.71828，x 是传入的指数。

sign()

语法 

Math.sign(val)

返回一个数的符号，正数返回 1，负数返回 -1，零返回 0 或 -0。

random()

语法 

Math.random()

返回一个随机的浮点数，范围是在 0 ~ 1 之间（不包括 1）。

PI

语法 

Math.PI

圆周率，圆的周长与直径之比，约等于 3.14159。

E

语法 

Math.E

欧拉常数，自然对数的底数，约等于 2.71828。

LN2

语法 

Math.LN2

返回 2 的自然对数，约等于 0.693。

LN10

语法 

Math.LN10

返回 10 的自然对数，约等于 2.302。

sqrt2

语法 

Math.SQRT2

返回 2 的平方根，约等于 1.414。
