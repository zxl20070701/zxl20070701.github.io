String 字符串

substr()

语法 

    stringObject.substr(start, length)

温馨提示：此语法已经废弃。

在字符串中抽取从 start 下标开始的指定 length 数目的字符。如果没有指定 length，那么返回的字符串包含从 start 到 stringObject 的结尾的字符。

substring()

语法 

    stringObject.substring(start, stop)

用于提取字符串中介于两个指定下标之间的字符，返回的子串包括 start 处的字符，但不包括 stop 处的字符。

indexOf()

语法 

string.indexOf(searchValue, start)

返回字符串中指定文本首次出现的索引位置。如果未找到返回 -1。

lastIndexOf()

语法 

string.lastIndexOf(searchValue, start)

返回指定文本在字符串中最后一次出现的索引。如果未找到返回 -1。

includes()

语法 

string.includes(searchValue, start)

判断一个字符串是否包含在另一个字符串中，根据情况返回 true 或 false。

startsWith()

语法 

string.startsWith(searchValue, start)

判断字符串是否以指定的子字符串开头，返回 true 或 false。

endsWith()

语法 

string.endsWith(searchValue, length)

判断字符串是否以指定的子字符串结尾，返回 true 或 false。

concat()

语法 

string.concat(string2, string3, ..., stringX)

用于连接两个或多个字符串。此方法不会更改原有字符串，而是返回一个新字符串。

split()

语法 

string.split(separator, limit)

用于把一个字符串分割成字符串数组。separator 为分隔符，limit 为返回数组的长度限制。

replace()

语法 

string.replace(searchValue, newValue)

在字符串中搜索匹配的值，并用新值替换。只替换第一个匹配项，如需替换所有请使用正则或 replaceAll()。

replaceAll()

语法 

string.replaceAll(searchValue, newValue)

在字符串中搜索所有匹配的值，并用新值替换全部匹配项。

slice()

语法 

string.slice(start, end)

提取字符串的某个部分，并以新的字符串返回被提取的部分。start 为起始位置，end 为结束位置（不包含）。

charAt()

语法 

string.charAt(index)

返回指定索引位置处的字符。如果超出有效范围返回空字符串。

charCodeAt()

语法 

string.charCodeAt(index)

返回在指定的位置的字符的 Unicode 编码。返回值是 0 - 65535 之间的整数。

fromCharCode()

语法 

String.fromCharCode(n1, n2, ..., nX)

通过指定的 Unicode 编码点序列返回一个字符串。是 charCodeAt() 的反操作。

toUpperCase()

语法 

string.toUpperCase()

将字符串转换为大写。不会影响原字符串。

toLowerCase()

语法 

string.toLowerCase()

将字符串转换为小写。不会影响原字符串。

trim()

语法 

string.trim()

去除字符串首尾的空格。不会影响原字符串。

padStart()

语法 

string.padStart(length, padString)

用另一个字符串填充当前字符串（如果需要的话），以便产生的字符串达到给定的长度。从左侧开始填充。

padEnd()

语法 

string.padEnd(length, padString)

用另一个字符串填充当前字符串（如果需要的话），以便产生的字符串达到给定的长度。从右侧开始填充。

repeat()

语法 

string.repeat(count)

构造并返回一个新字符串，该字符串包含被连接在一起的指定数量的字符串的副本。

match()

语法 

string.match(regexp)

查找字符串中匹配的字符串。返回一个数组，其中存放匹配的结果。如果未找到匹配，则返回 null。

search()

语法 

string.search(regexp)

用于检索字符串中指定的子字符串，或检索与正则表达式相匹配的子字符串。返回子字符串的起始位置。

at()

语法 

string.at(index)

接收一个整数值并返回该索引的字符，支持正数和负数索引。负数索引从字符串末尾开始计数。
