Set 对象

概述 

// Set 是一组不重复的值的集合
let set = new Set();

Set 对象是值的集合，值可以是任何类型。Set 中的元素只会出现一次，且按插入顺序迭代。

add()

语法 

mySet.add(value)

在 Set 对象尾部添加一个元素。返回 Set 对象本身，可链式调用。

has()

语法 

mySet.has(value)

判断 Set 对象中是否存在指定的值。返回 true 或 false。

delete()

语法 

mySet.delete(value)

从 Set 对象中移除指定的值。删除成功返回 true，值不存在返回 false。

clear()

语法 

mySet.clear()

移除 Set 对象中的所有元素。没有返回值。

size

语法 

mySet.size

返回 Set 对象的元素数量。

forEach()

语法 

mySet.forEach(function(value, value2, set) {
    // value 和 value2 相同（因为 Set 没有键）
}, thisArg)

按插入顺序依次对 Set 对象中的每个元素执行一次回调函数。

values()

语法 

mySet.values()

返回一个包含 Set 对象中所有值的迭代器。

entries()

语法 

mySet.entries()

返回一个包含 Set 对象中所有值的迭代器。每个值都会出现两次，以形成键值对数组 [value, value]。
