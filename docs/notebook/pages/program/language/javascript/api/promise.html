Promise 对象

Promise 基础

创建 Promise 

let promise = new Promise(function(resolve, reject) {
    // 异步操作
    if (/* 成功 */) {
        resolve(value);
    } else {
        reject(error);
    }
});

Promise 对象用于表示异步操作的最终完成（或失败）及其结果值。构造函数接收一个执行器函数，该函数立即执行。

三种状态 

// pending: 初始状态
// fulfilled: 操作成功完成（调用 resolve）
// rejected: 操作失败（调用 reject）

then()

语法 

promise.then(onFulfilled, onRejected)

用于指定 Promise 成功时的回调。返回一个新的 Promise 对象，可实现链式调用。

示例 

promise.then(function(result) {
    console.log(result);
}).then(function(result2) {
    console.log(result2);
});

catch()

语法 

promise.catch(onRejected)

用于指定 Promise 失败时的回调。等价于 then(null, onRejected)。返回一个新的 Promise 对象。

finally()

语法 

promise.finally(onFinally)

用于指定 Promise 状态改变后（无论成功或失败）的回调。返回原 Promise 的结果。

all()

语法 

Promise.all(iterable)

用于将多个 Promise 实例包装成一个新的 Promise 实例。所有 Promise 都成功才返回成功，任一失败则返回失败。

示例 

Promise.all([promise1, promise2]).then(function(results) {
    // results 为所有成功结果的数组
}).catch(function(error) {
    // error 为第一个失败的原因
});

race()

语法 

Promise.race(iterable)

将多个 Promise 实例包装成一个新的 Promise 实例。返回最先解决或拒绝的 Promise 的结果。

allSettled()

语法 

Promise.allSettled(iterable)

返回一个在所有给定的 Promise 都已经解决或拒绝后才解决的 Promise，并带有一个对象数组，每个对象表示对应的 Promise 结果。

any()

语法 

Promise.any(iterable)

只要给定的 Promise 中有一个成功，就返回成功的结果。如果所有 Promise 都失败，则返回一个 AggregateError。

resolve()

语法 

Promise.resolve(value)

返回一个状态由给定 value 决定的 Promise 对象。如果 value 是 Promise 则直接返回，如果是 thenable 对象则等待其完成。

reject()

语法 

Promise.reject(reason)

返回一个带有拒绝原因 reason 的 Promise 对象。通常用于快速创建一个已拒绝的 Promise。
