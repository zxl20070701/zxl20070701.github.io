Date 日期

getFullYear()

语法 

    date.getFullYear()

可返回一个表示年份的4位数字。

getMonth()

语法 

    date.getMonth()

可返回表示月份的数字，返回值是 0（一月） 到 11（十二月） 之间的一个整数。

getDate()

语法 

    date.getDate()

可返回月份的某一天，返回值是 1 ~ 31 之间的一个整数。

getDay()

语法 

    date.getDay()

可返回一周（0~6）的某一天的数字，返回值是 0（周日） 到 6（周六） 之间的一个整数。

getHours()

语法 

    date.getHours()

可返回时间的小时字段，返回值是 0 （午夜） 到 23 （晚上 11 点）之间的一个整数。

getMinutes()

语法 

    date.getMinutes()

可返回时间的分钟字段，以本地时间显示，返回值是 0 ~ 59 之间的一个整数。

getSeconds()

语法 

    date.getSeconds()

可返回时间的秒，返回值是 0 ~ 59 之间的一个整数。

getTime()

语法 

date.getTime()

返回自 1970 年 1 月 1 日以来的毫秒数。通常用于跟踪代码执行时间。

setFullYear()

语法 

date.setFullYear(year, month, day)

设置日期对象的年份。可选的 month 和 day 参数可同时设置月份和日期。

setMonth()

语法 

date.setMonth(month, day)

设置日期对象的月份（0-11）。可选的 day 参数可同时设置日期。

setDate()

语法 

date.setDate(day)

设置日期对象的日期（1-31）。

setHours()

语法 

date.setHours(hour, min, sec, millisec)

设置日期对象的小时（0-23）。可选的 min、sec、millisec 参数可同时设置分、秒、毫秒。

setMinutes()

语法 

date.setMinutes(min, sec, millisec)

设置日期对象的分钟（0-59）。

setSeconds()

语法 

date.setSeconds(sec, millisec)

设置日期对象的秒数（0-59）。

setTime()

语法 

date.setTime(millisec)

通过从 1970 年 1 月 1 日起的指定毫秒数来设置日期。

toDateString()

语法 

date.toDateString()

把 Date 对象的日期部分转换为字符串。返回格式如 "Wed Apr 23 2025"。

toTimeString()

语法 

date.toTimeString()

把 Date 对象的时间部分转换为字符串。返回格式如 "14:30:45 GMT+0800"。

toISOString()

语法 

date.toISOString()

将 Date 对象转换为 ISO 格式字符串（YYYY-MM-DDTHH:mm:ss.sssZ）。使用 UTC 时区。

toJSON()

语法 

date.toJSON()

返回 Date 对象的 JSON 格式字符串。实际上返回的是 ISO 格式的字符串。

toLocaleDateString()

语法 

date.toLocaleDateString(locales, options)

返回日期对象日期部分的字符串，使用本地语言环境。

toLocaleTimeString()

语法 

date.toLocaleTimeString(locales, options)

返回日期对象时间部分的字符串，使用本地语言环境。

toLocaleString()

语法 

date.toLocaleString(locales, options)

返回日期对象的字符串表示，使用本地语言环境。

parse()

语法 

Date.parse(dateString)

解析一个日期字符串，并返回自 1970 年 1 月 1 日以来的毫秒数。

now()

语法 

Date.now()

返回当前时间自 1970 年 1 月 1 日以来的毫秒数。等同于 +new Date()。

UTC()

语法 

Date.UTC(year, month, day, hour, minute, second, millisecond)

根据世界时（UTC）来计算，返回从 1970 年 1 月 1 日起到该日期的毫秒数。
