DOM 节点

查找

querySelector()

语法 

    el.querySelector(selector)

返回查询页面中第一个匹配选择符的元素。

querySelectorAll()

语法 

    el.querySelectorAll(selector)

返回查询页面中所有匹配选择符的元素。

closest()

语法 

    el.closest(selector)

返回当前节点最近的匹配选择符的祖先元素。

getElementById()

语法 

document.getElementById(id)

返回对拥有指定 id 的第一个对象的引用。

getElementsByClassName()

语法 

document.getElementsByClassName(classname)

返回文档中所有指定类名的元素集合，返回值是一个 HTMLCollection。

getElementsByTagName()

语法 

document.getElementsByTagName(tagname)

返回文档中所有指定标签名的元素集合，返回值是一个 HTMLCollection。

属性操作

getAttribute()

语法 

el.getAttribute(attribute)

返回指定属性名的属性值。如果属性不存在则返回 null。

setAttribute()

语法 

el.setAttribute(attribute, value)

在元素上设置指定属性的值。如果属性不存在则创建它。

removeAttribute()

语法 

el.removeAttribute(attribute)

移除元素的指定属性。

hasAttribute()

语法 

el.hasAttribute(attribute)

判断元素是否有指定的属性，返回 true 或 false。

样式操作

style

语法 

el.style.property = value

设置或返回元素的内联样式属性。property 为样式名（如 color、backgroundColor）。

classList.add()

语法 

el.classList.add(class1, class2, ...)

向元素添加一个或多个类名。如果已存在则忽略。

classList.remove()

语法 

el.classList.remove(class1, class2, ...)

从元素移除一个或多个类名。

classList.toggle()

语法 

el.classList.toggle(classname, force)

切换元素的类名。如果类名存在则移除，不存在则添加。force 为 true 时强制添加，为 false 时强制移除。

内容操作

textContent

语法 

el.textContent = text

设置或返回元素的文本内容。会忽略 HTML 标签，只返回纯文本。

innerHTML

语法 

el.innerHTML = html

设置或返回元素的 HTML 内容。可以包含 HTML 标签。

innerText

语法 

el.innerText = text

设置或返回元素的可见文本内容。与 textContent 类似，但受 CSS 样式影响。

DOM 操作

createElement()

语法 

document.createElement(tagName)

创建一个指定元素的 HTML 元素。返回新创建的元素。

appendChild()

语法 

parent.appendChild(child)

向父元素末尾添加新的子元素。如果子元素是 DOM 中已有元素，则将其移动到新位置。

removeChild()

语法 

parent.removeChild(child)

从父元素中移除指定的子元素。返回被移除的元素。

insertBefore()

语法 

parent.insertBefore(newChild, referenceChild)

在指定的子节点之前插入新的子节点。referenceChild 为 null 时，将插入到末尾。

replaceChild()

语法 

parent.replaceChild(newChild, oldChild)

用新节点替换父元素中的指定子节点。
