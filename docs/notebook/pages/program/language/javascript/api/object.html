Object 对象

keys()

语法 

Object.keys(obj)

返回一个由给定对象的所有可枚举属性名组成的数组。属性名的顺序与通过 for...in 循环相同。

values()

语法 

Object.values(obj)

返回一个由给定对象的所有可枚举属性值组成的数组。

entries()

语法 

Object.entries(obj)

返回一个由给定对象的自身可枚举属性的键值对数组。每个键值对是一个数组 [key, value]。

fromEntries()

语法 

Object.fromEntries(iterable)

将键值对数组转换为对象。与 Object.entries() 相反。

assign()

语法 

Object.assign(target, source1, source2, ...)

将一个或多个源对象的可枚举属性复制到目标对象，返回目标对象。会修改原对象。

create()

语法 

Object.create(proto, propertiesObject)

创建一个新对象，使用现有的对象作为新对象的原型。proto 为新对象的原型对象。

defineProperty()

语法 

Object.defineProperty(obj, prop, descriptor)

在一个对象上定义新属性或修改现有属性。descriptor 为属性描述符（包含 value、writable、enumerable、configurable 等）。

getOwnPropertyDescriptor()

语法 

Object.getOwnPropertyDescriptor(obj, prop)

返回指定对象上一个自有属性对应的属性描述符。返回值包含 value、writable、enumerable、configurable、get、set 等。

hasOwnProperty()

语法 

obj.hasOwnProperty(prop)

判断对象自身是否具有指定属性（不包含原型链上的属性）。返回 true 或 false。

hasOwn()

语法 

Object.hasOwn(obj, prop)

判断对象自身是否具有指定属性。与 hasOwnProperty() 类似但更简洁。ES2022 新增。

freeze()

语法 

Object.freeze(obj)

冻结一个对象。冻结后对象不能被修改、删除或新增属性。冻结是浅冻结。

isFrozen()

语法 

Object.isFrozen(obj)

判断一个对象是否被冻结。返回 true 或 false。

seal()

语法 

Object.seal(obj)

封闭一个对象。封闭后对象不能被删除或新增属性，但已有属性的值可以修改。

isSealed()

语法 

Object.isSealed(obj)

判断一个对象是否被封闭。返回 true 或 false。

isExtensible()

语法 

Object.isExtensible(obj)

判断一个对象是否可扩展（是否可以添加新属性）。返回 true 或 false。

is()

语法 

Object.is(value1, value2)

判断两个值是否为同一个值。与 === 类似，但处理 NaN 和 -0 有差异。
