模块化

导出 export

使用 export 关键字导出变量、函数或类。每个模块可以有多个命名导出，但只能有一个默认导出。

命名导出 

// math.js
export const PI = 3.14159;
export function add(a, b) {
    return a + b;
}
export class Calculator { ... }

默认导出 

// app.js
export default function start() {
    console.log('App started');
}

重命名导出 

export { add as sum, PI as CIRCUMFERENCE };

导入 import

使用 import 关键字从其他模块导入绑定。import 语句必须在模块的顶层。

导入命名导出 

import { add, PI } from './math.js';
import { add as sum } from './math.js';

导入默认导出 

import start from './app.js';

混合导入 

import start, { add, PI } from './app.js';

模块整体导入 

import * as math from './math.js';
console.log(math.add(1, 2));

重导出

可以使用 export...from 语法将导入的内容重新导出。 

// index.js
export { add, PI } from './math.js';
export { default as start } from './app.js';

动态导入

使用 import() 函数可以在运行时动态加载模块，返回一个 Promise。 

// 动态导入
let module = await import('./dynamic-module.js');
module.doSomething();
