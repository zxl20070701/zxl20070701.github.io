模板字符串

基本用法

模板字符串使用反引号(``)包裹，可以包含多行文本和变量插值。变量插值使用 ${} 语法。 

let name = 'World';
let greeting = `Hello, ${name}!`;
console.log(greeting); // Hello, World!

多行字符串

模板字符串可以直接书写多行，无需使用 \n 转义。 

let html = `
    

        
Title

        
Content

    

`;

嵌入表达式

${} 中可以放置任意 JavaScript 表达式，包括函数调用、运算、三元运算符等。 

let a = 10;
let b = 20;
let result = `${a} + ${b} = ${a + b}`; // "10 + 20 = 30"
let status = `${a > b ? 'a大' : 'b大'}`;

标签模板字符串

可以在模板字符串前添加一个函数名，该函数会接收模板字符串的各个部分和变量值，用于自定义处理。 

function tag(strings, ...values) {
    let result = '';
    strings.forEach((str, i) => {
        result += str + (values[i] ?? '');
    });
    return result;
}
let x = 10;
let y = 20;
let output = tag`计算结果是 ${x} + ${y}`;

嵌套模板字符串

模板字符串可以嵌套使用，便于构建复杂的字符串结构。 

let items = ['apple', 'banana'];
let list = `
    
    
        ${items.map(item => `
            
  • ${item}
    • 
        `).join('')}
    

`;
