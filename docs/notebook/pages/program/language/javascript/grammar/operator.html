运算符

可选链(.?)

只有obj存在（也就是!!obj为ture）的时候，才会尝试获取其属性key（即使obj是undefined也不会报错）： 

let val = obj.key;

空值合并运算符(??)

当b不是undefined或null的时候，把b赋值给a，否则把c赋值给a： 

let a = b ?? c;

空值赋值运算符(??=)

当a是undefined或null的时候，才把b赋值给a： 

a ??= b;

逻辑与赋值(&&=)

当a为truthy的时候，才把b赋值给a： 

a &&= b;

逻辑或赋值(||=)

当a为falsy的时候，才把b赋值给a： 

a ||= b;

空值合并赋值(??=)

当a是undefined或null的时候，才把b赋值给a： 

a ??= b;

可选链(.?)

只有obj存在（也就是!!obj为true）的时候，才会尝试获取其属性key（即使obj是undefined也不会报错）： 

let val = obj?.key;
let val = obj?.method?.();
let val = arr?.[0];

空值合并运算符(??)

当b不是undefined或null的时候，把b赋值给a，否则把c赋值给a： 

let a = b ?? c;

指数运算符(**)

用于计算指数表达式，左侧为底数，右侧为指数： 

let result = 2 ** 10; // 1024

可选链与空值合并的注意事项

可选链(?.)和空值合并(??)不能直接与运算符(+ - * / 等)一起使用，需要用括号包裹： 

// 错误
a ?? b + c;
// 正确
a ?? (b + c);
