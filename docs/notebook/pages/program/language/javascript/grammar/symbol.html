Symbol 类型

基本概念

Symbol 是一种原始数据类型，用于创建唯一的标识符。每个 Symbol 值都是唯一的，即使使用相同的描述创建。 

let sym1 = Symbol();
let sym2 = Symbol('description');
console.log(typeof sym1); // 'symbol'
console.log(sym1 === sym2); // false

使用场景

Symbol 常用于定义对象的唯一属性名，避免属性名冲突。 

let NAME = Symbol('name');
let user = {
    [NAME]: 'Alice',
    name: 'Bob'
};
console.log(user[NAME]); // 'Alice'
console.log(user.name); // 'Bob'

共享 Symbol

使用 Symbol.for() 可以在全局 Symbol 注册表中创建或获取共享的 Symbol。 

let sym1 = Symbol.for('key');
let sym2 = Symbol.for('key');
console.log(sym1 === sym2); // true
console.log(Symbol.keyFor(sym1)); // 'key'

常用内置 Symbol

JavaScript 提供了一些内置 Symbol，用于定制对象的行为。 

// Symbol.iterator - 定义对象的默认迭代器
let iterable = {
    [Symbol.iterator]() {
        let i = 0;
        return {
            next() {
                return { value: ++i, done: i > 3 };
            }
        };
    }
};
// Symbol.toStringTag - 自定义 Object.prototype.toString 的输出
let obj = {
    [Symbol.toStringTag]: 'MyClass'
};
Object.prototype.toString.call(obj); // '[object MyClass]'
