对象字面量增强

属性简写

当属性名与变量名相同时，可以直接省略冒号和值，使用简写形式。 

let name = 'Alice';
let age = 25;
let user = { name, age };
console.log(user); // { name: 'Alice', age: 25 }

方法简写

对象中的方法可以省略 function 关键字和冒号，使用简写形式。 

let calculator = {
    add(a, b) {
        return a + b;
    },
    subtract(a, b) {
        return a - b;
    }
};
calculator.add(1, 2); // 3

计算属性名

使用方括号 [] 可以在对象字面量中使用表达式作为属性名。 

let key = 'color';
let obj = {
    [key]: 'red',
    ['get' + 'Name']() {
        return 'Alice';
    }
};
console.log(obj.color); // 'red'
console.log(obj.getName()); // 'Alice'

属性简写 + 方法简写结合 

let firstName = 'Bob';
let lastName = 'Smith';
let person = {
    firstName,
    lastName,
    getFullName() {
        return `${this.firstName} ${this.lastName}`;
    }
};
person.getFullName(); // "Bob Smith"
