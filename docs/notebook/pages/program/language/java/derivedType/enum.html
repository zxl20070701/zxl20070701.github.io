枚举类型

定义枚举

枚举用 enum 声明一组有限且固定的常量。每个枚举常量都是该枚举类型的实例： 

enum Direction {
    NORTH, EAST, SOUTH, WEST
}

Direction direction = Direction.NORTH;

枚举常量比较可使用 ==； 输出名称可使用 name()， 但不要依赖 ordinal() 保存业务含义，因为调整声明顺序会改变序号。

带字段和方法的枚举

枚举可以有字段、构造方法和方法。枚举构造方法不能声明为 public 或 protected，常量声明必须位于枚举体开头： 

enum Status {
    PENDING("待处理"),
    DONE("已完成");

    private final String label;

    Status(String label) {
        this.label = label;
    }

    public String label() {
        return label;
    }
}

配合 switch 使用 

switch (direction) {
    case NORTH -> System.out.println("向北");
    case EAST -> System.out.println("向东");
    case SOUTH -> System.out.println("向南");
    case WEST -> System.out.println("向西");
}

switch 箭头语法适用于较新的 Java 版本；在需要兼容旧版 JDK 的项目中，可使用传统的 case ...: 写法并注意 break。
