Lambda 与 Stream

Lambda 表达式

Lambda 表达式可以为函数式接口提供实现。函数式接口只有一个抽象方法，常用类型位于 java.util.function，例如 Predicate、Function 和 Consumer。 Lambda 与方法引用在 Java 8 中引入。 

java.util.function.Predicate<String> nonEmpty =
    value -> !value.isEmpty();

java.util.function.Consumer<String> printer =
    System.out::println;

Stream 管道

Stream 用于描述数据处理管道。中间操作（如 filter、map）通常是惰性的；终止操作（如 collect、forEach）触发处理。Stream 不存储数据，也不应重复使用已经执行过终止操作的流。 

java.util.List<String> names =
    java.util.List.of("Ada", "Lin", "Grace");

java.util.List<String> longNames = names.stream()
    .filter(name -> name.length() > 3)
    .map(String::toUpperCase)
    .toList();

Stream.toList() 从 Java 16 起可用，返回不可修改的列表；若需要可修改结果，可使用 collect(Collectors.toCollection(ArrayList::new))。

何时使用并行流

并行流不一定更快，并会带来线程调度、共享状态和顺序方面的额外约束。只有在任务可安全拆分、数据规模合适且经过测量确认后，再考虑并行处理。
