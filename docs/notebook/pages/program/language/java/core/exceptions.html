异常处理

异常类型

Java 的异常都继承自 Throwable。 Error 通常表示应用不应尝试恢复的严重问题； Exception 表示程序可以处理的异常。检查型异常需要捕获或在方法签名中声明，运行时异常 RuntimeException 不要求显式声明。

捕获和声明异常

使用 try、 catch 处理异常，使用 finally 表达无论是否发生异常都应执行的收尾逻辑。按从具体到宽泛的顺序排列多个 catch 分支。 

try {
    String text = java.nio.file.Files.readString(
        java.nio.file.Path.of("data.txt")
    );
    System.out.println(text);
} catch (java.io.IOException exception) {
    System.err.println("读取文件失败：" + exception.getMessage());
}

方法可用 throws 声明可能抛出的检查型异常；用 throw 主动抛出异常。不要捕获后静默忽略异常，也不要用宽泛的异常类型掩盖可恢复与不可恢复错误的区别。

try-with-resources

对实现 AutoCloseable 的资源，优先使用 try-with-resources 自动关闭资源，包括异常发生时： 

try (var reader = java.nio.file.Files.newBufferedReader(
        java.nio.file.Path.of("data.txt"))) {
    System.out.println(reader.readLine());
}

try-with-resources 自 Java 7 起可用；示例中的 var 局部变量推断则要求 Java 10 或更高版本。
