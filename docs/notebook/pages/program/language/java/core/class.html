类、对象与成员

定义类和创建对象

类是对象的模板，描述对象具有的数据和行为。对象是类的一个实例。Java 源文件通常以 .java 结尾；一个 public 顶层类的名称应与文件名一致。 

public class User {
    private final String name;

    public User(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }

    public static void main(String[] args) {
        User user = new User("小明");
        System.out.println(user.getName());
    }
}

new 会创建对象并调用构造方法。构造方法名称与类名相同，没有返回类型；如果没有声明任何构造方法，编译器才会提供无参构造方法。

字段、局部变量和方法

  • 字段属于对象或类；实例字段各对象分别保存，静态字段由类共享。
  • 局部变量在方法或代码块中声明，使用前必须明确赋值；不会自动获得默认值。
  • 方法定义对象或类可以执行的操作，可接收参数并返回结果。
public class Counter {
    private int value;                 // 实例字段
    private static int createdCount;   // 类字段

    public Counter() {
        createdCount++;
    }

    public int add(int amount) {
        value += amount;
        return value;
    }
}

static 与 final

static 成员属于类本身，可以通过类名访问；实例方法可以访问实例状态，而静态方法不能直接访问实例字段。 final 字段只能赋值一次，常量通常声明为 static final。 final 引用不能改为指向另一个对象，但不代表该对象内部不可变。

访问控制

  • public：任何可访问该类型的代码都能使用。
  • protected：同包可访问，其他包中的子类也可按继承规则访问。
  • 不写修饰符：包级访问，仅同一个包可访问。
  • private：仅声明它的顶层类内部可访问。

通常将字段设为 private，通过构造方法和公开方法控制对象状态，从而保持封装。
