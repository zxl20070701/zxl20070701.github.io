泛型与类型安全

泛型类和泛型方法

泛型让类型作为参数传递，使编译器能在编译期检查类型，而不必在读取时到处强制转换。 

class Box<T> {
    private final T value;

    Box(T value) {
        this.value = value;
    }

    public T get() {
        return value;
    }
}

Box<String> box = new Box<>("hello");
String text = box.get();

泛型方法可以独立声明类型参数，例如 <T> T first(T left, T right)。 编译器通常能够从参数推断类型。泛型类型不支持基本类型作为类型参数，可使用 Integer、 Double 等包装类型。

有界类型参数

使用 extends 限制类型参数，以便在泛型代码中使用边界声明的能力： 

static <T extends Number> double sum(T left, T right) {
    return left.doubleValue() + right.doubleValue();
}

通配符与 PECS

? extends T 表示某种未知的 T 子类型，适合从集合读取 T； ? super T 表示某种未知的 T 父类型，适合向集合写入 T。常用记忆方式是“生产者 extends，消费者 super”（PECS）。 

static double total(java.util.List<? extends Number> values) {
    double result = 0;
    for (Number value : values) {
        result += value.doubleValue();
    }
    return result;
}

Java 泛型主要通过类型擦除实现。不能直接创建 new T() 或 new T[... ]； 也不能重载两个擦除后参数类型相同的方法。
