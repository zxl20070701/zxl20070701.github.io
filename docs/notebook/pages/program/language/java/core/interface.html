接口与实现

定义接口

接口用 interface 声明可由不同类实现的能力契约。类使用 implements 实现接口，并可同时实现多个接口。 

interface Payable {
    double amount();
}

class Invoice implements Payable {
    @Override
    public double amount() {
        return 99.0;
    }
}

接口抽象方法默认是 public abstract； 接口字段默认是 public static final。 实现方法必须是 public，不能缩小接口方法的访问范围。

默认方法、静态方法与私有方法

Java 8 起，接口可以提供 default 默认方法和静态方法。默认方法允许接口在演进时为已有实现提供通用行为；实现类可以重写默认方法。 Java 9 起，接口还可以声明 private 方法，供接口内部复用。 

interface Named {
    String name();

    default String label() {
        return format(name());
    }

    private String format(String value) {
        return "[" + value + "]";
    }
}

何时使用接口或抽象类

  • 接口：表达能力或契约，支持一个类组合多种能力。
  • 抽象类：表达相关类型的共同基础，可共享实例状态、构造逻辑和受保护实现。

若类实现的多个接口提供同签名的默认方法，类需要自行重写以解决冲突；可通过 接口名.super.方法名() 调用指定接口的默认实现。
