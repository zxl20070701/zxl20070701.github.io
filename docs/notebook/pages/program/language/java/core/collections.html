集合框架与常用类型

常见集合接口

  • List：有序序列，可按位置访问；常见实现有 ArrayList、LinkedList。
  • Set：不保存重复元素；HashSet 不保证遍历顺序，TreeSet 按排序规则维护顺序。
  • Map：键值映射，键唯一；常见实现有 HashMap、TreeMap。
  • Queue / Deque：队列和双端队列；ArrayDeque 常用于队列或栈。

声明变量时优先使用接口类型，按是否需要顺序、去重、排序或键值映射选择实现： 

java.util.List<String> names = new java.util.ArrayList<>();
names.add("Ada");
names.add("Lin");

java.util.Map<String, Integer> scores = new java.util.HashMap<>();
scores.put("Ada", 95);

不可修改集合工厂

Java 9 引入 List.of、 Set.of 和 Map.of 等工厂方法，快速创建不可修改集合： 

var colors = java.util.List.of("red", "green", "blue");

这些集合不允许添加、删除或替换元素；集合本身不可修改不等于其中对象一定不可变。Set.of 和 Map.of 遇到重复元素或键时会抛出异常。

选择实现和遍历

ArrayList 适合常见的顺序存储和按下标读取；HashMap 适合按键查找；若需要稳定的插入顺序，可考虑 LinkedHashMap；若需要排序，可考虑 TreeMap 或 TreeSet。应根据访问和更新模式选择，而不是假定某个集合在所有场景下都更快。 

for (String name : names) {
    System.out.println(name);
}

scores.forEach((name, score) ->
    System.out.println(name + ": " + score)
);
