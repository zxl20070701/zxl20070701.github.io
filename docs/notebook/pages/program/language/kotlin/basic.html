基础语法

Kotlin 是一门由 JetBrains 开发的静态类型编程语言，运行在 JVM 上，也可以编译成 JavaScript 或 Native 代码。它和 Java 完全互操作，语法更加简洁、安全，并且原生支持空安全，是目前 Android 官方推荐语言。

程序入口

Kotlin 程序的入口是 main 函数。和 Java 不同的是，Kotlin 不强制要求把整个程序放到一个类里。 

fun main() {
    println("你好，Kotlin！")
}

也可以显式接收命令行参数： 

fun main(args: Array<String>) {
    println("参数个数: ${args.size}")
}

注释

Kotlin 注释和大多数语言一样，支持单行注释、块注释和多行（嵌套）注释。 

// 单行注释

/*
   块注释
   可以跨越多行
*/

/**
 * KDoc 文档注释，
 * 通常写在类、函数、属性上方。
 */
fun add(a: Int, b: Int): Int = a + b

语句与分号

Kotlin 不要求每条语句以分号结尾（写了也不会报错）。一行写多条语句时，需要用分号分隔，但实际开发中不推荐这么做。 

val name = "Kotlin"        // 推荐：省略分号
val version = 1.9          // 推荐：省略分号
val n = 1; val m = 2       // 可以，但不推荐

代码风格

  • 包名使用小写字母，例如 com.example.demo。
  • 类名、对象名使用大驼峰（PascalCase），例如 UserService。
  • 函数、变量、参数使用小驼峰（lowerCamelCase），例如 getUserName。
  • 常量（const val、顶级 val）使用大写下划线，例如 MAX_COUNT。

与 Java 的对比 

// Java 写法
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}

// Kotlin 写法
fun main() {
    println("Hello, Kotlin")
}

可以看到 Kotlin 不需要类外壳、不需要 public、static、void 这些修饰词，语法更轻量。
