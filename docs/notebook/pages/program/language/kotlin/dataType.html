数据类型

Kotlin 是静态类型语言，每个变量和表达式都有明确类型。和 Java 不同，Kotlin 中所有的类型都派生自 Any，并且通过可空类型 ? 来表达“可以为 null”的概念，从语言层面尽量减少空指针异常。

类型层级

Kotlin 把类型分为两大类：

  • 基本数据类型：在 JVM 上会被编译成对应的 Java 基本类型（int、double、boolean 等），但代码层面它们是普通对象。
  • 引用类型：包括 String、Array、List、自定义类等。

类型继承关系大致是： 

Any
 ├── 所有非空类型
 └── Any?
      └── 所有可空类型（Any? 是整个类型系统的顶端）
           └── Nothing（表示“没有值”，例如抛异常的函数返回类型）

可空类型与不可空类型 

// 不可空：编译器保证一定不为 null
var name: String = "Kotlin"
name = null // 编译报错

// 可空：需要在类型后加 ?
var nickname: String? = null
nickname = "Kt"
println(nickname?.length) // 安全调用，结果可能为 null

示例：安全调用与 Elvis

val text: String? = null

// 安全调用 ?.  当左侧为 null 时整体为 null
println(text?.length) // null

// Elvis 运算符 ?:  左侧为 null 时返回右侧默认值
val len = text?.length ?: 0
println(len) // 0

// 非空断言 !!  强制断言不为 null，断言失败会抛 NPE
val raw = text!!.length // 不推荐，仅在你确定不为 null 时使用

类型分类

类型 说明 取值 / 示例
Byte 8 位整数 -128 ~ 127
Short 16 位整数 -32768 ~ 32767
Int 32 位整数（最常用） -2³¹ ~ 2³¹-1
Long 64 位整数 需要加 L 后缀：100L
Float 32 位浮点数 需要加 F 后缀：3.14F
Double 64 位浮点数（默认） 3.14、2.5e2
Boolean 布尔值 true / false
Char 单个字符，用单引号 'a'、'中'
String 字符串，用双引号 "Hello"

变量声明

Kotlin 用 val 声明只读变量（相当于 Java 的 final），用 var 声明可变变量。优先使用 val。 

val a: Int = 1            // 类型显式声明
val b = 2                 // 自动推断为 Int
var name = "Kotlin"       // 可重新赋值
name = "JetBrains"        // OK

val c: Int                // 延迟初始化，必须在使用前赋值
c = 3

类型转换

Kotlin 不支持隐式转换，小类型到大类型必须显式调用 toXxx()。 

val i: Int = 10
val l: Long = i.toLong()
val d: Double = i.toDouble()
val s: String = i.toString()

// 字符串转数字（可能抛异常）
val n: Int = "123".toInt()
val safeN: Int? = "abc".toIntOrNull() // 转换失败返回 null

类型判断 

val obj: Any = "Hello"

// is 判断类型
if (obj is String) {
    println("字符串长度: ${obj.length}") // 这里 obj 已被智能转换为 String
}

// !is 反向判断
if (obj !is String) {
    println("不是字符串")
}
