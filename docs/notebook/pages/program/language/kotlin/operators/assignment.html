赋值运算符

赋值运算符用来给变量赋值。Kotlin 中 = 用于赋值，== 用于比较，这一点和 C、Java 一致。除此之外 Kotlin 还提供了 +=、-= 等复合赋值运算符，它们会就地修改左边的变量并返回新值。

运算符 描述 示例 等价于
= 简单赋值 a = 5 —
+= 加后赋值 a += 3 a = a + 3
-= 减后赋值 a -= 3 a = a - 3
*= 乘后赋值 a *= 3 a = a * 3
/= 除后赋值 a /= 3 a = a / 3
%= 取模后赋值 a %= 3 a = a % 3 
var n = 5
n += 3   // n = 8
n -= 2   // n = 6
n *= 4   // n = 24
n /= 3   // n = 8
n %= 5   // n = 3

println(n) // 3

val 声明的是只读变量，不能使用任何赋值运算符重新赋值；var 声明的可变变量才能使用 +=、-= 等复合赋值运算符。
