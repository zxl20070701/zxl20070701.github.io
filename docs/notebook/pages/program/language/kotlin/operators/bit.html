位运算符

Kotlin 的位运算用单词而不是符号，原因是符号形式（&、|、<< 等）可能与变量名或普通字符混淆。所有位运算符都适用于 Int 和 Long。

Java 写法 Kotlin 写法 含义
& and 按位与
| or 按位或
^ xor 按位异或
~ inv() 按位取反
<< shl 左移
>> shr 算术右移（保留符号位）
>>> ushr 无符号右移 
val a = 0b1100   // 12
val b = 0b1010   // 10

println(a and b)   // 1000 = 8
println(a or b)    // 1110 = 14
println(a xor b)   // 0110 = 6
println(a.inv())   // -13（按位取反）
println(a shl 1)   // 11000 = 24
println(a shr 1)   // 0110 = 6
println(a ushr 1)  // 0110 = 6（高位填 0）

Kotlin 中没有 Java 风格的符号位运算符，必须使用 and、or、xor、shl 等函数形式。
