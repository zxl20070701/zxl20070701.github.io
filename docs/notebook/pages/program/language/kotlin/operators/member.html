区间与成员运算符

Kotlin 提供了几个独有的运算符，用于判断某个值是否在范围内（in、!in），以及构造区间（..、until、downTo、step）。这些运算符在 Kotlin 中被称为区间运算符和成员运算符。

运算符 描述 示例 结果
.. 闭区间 [a, b] 1..5 1, 2, 3, 4, 5
until 半开区间 [a, b) 1 until 5 1, 2, 3, 4
downTo 倒序区间 5 downTo 1 5, 4, 3, 2, 1
step 步长 1..10 step 2 1, 3, 5, 7, 9
in 属于（包含判断） 3 in 1..5 true
!in 不属于 6 !in 1..5 true 
// 构造区间
val range1 = 1..5           // [1, 5]
val range2 = 1 until 5      // [1, 5)
val range3 = 5 downTo 1     // 倒序
val range4 = 1..10 step 2   // 步长 2

// 遍历
for (i in 1..5) {
    print("$i ") // 1 2 3 4 5
}
println()

for (i in 5 downTo 1 step 2) {
    print("$i ") // 5 3 1
}
println()

// in / !in 包含判断
println(3 in 1..5)       // true
println(6 !in 1..5)      // true

// 同样适用于集合
val fruits = listOf("apple", "banana", "orange")
println("apple" in fruits)  // true
println("pear" !in fruits)  // true

.. 创建的是 IntRange（或 LongRange 等），实现了 Iterable 接口，因此可以配合 for 循环遍历，也可以用 contains 方法进行判断。
