算术运算符

算术运算符用于执行基本的数学运算。Kotlin 中所有数值类型（Byte、Short、Int、Long、Float、Double）都支持下面的算术运算符，且 +、* 还可以用于字符串拼接与重复。

运算符 描述 示例 结果
+ 加法 / 一元正号 / 字符串拼接 5 + 3 / +5 / "ab" + "cd" 8 / 5 / "abcd"
- 减法 / 一元负号 10 - 4 / -5 6 / -5
* 乘法 / 字符串重复 3 * 4 / "ab" * 2 12 / "abab"
/ 除法 7 / 2 3（Int 之间是整数除法）
% 取余 / 取模 7 % 3 / -7 % 3 1 / -1
++ 自增 a++ / ++a 先返回后自增 / 先自增后返回
-- 自减 a-- / --a 同上 
val a = 10
val b = 3

println(a + b) // 13
println(a - b) // 7
println(a * b) // 30
println(a / b) // 3，Int 之间相除是整数除法
println(a % b) // 1

// 浮点数之间才是真正的除法
val x = 10.0 / 3.0
println(x) // 3.3333333333333335

// 一元运算
val p = 5
println(+p) // 5
println(-p) // -5

// 自增自减
var i = 1
val a1 = i++ // a1 = 1, i = 2
val a2 = ++i // a2 = 3, i = 3

// 字符串相关
val s = "ab" + "cd" // "abcd"
val r = "ha" * 3    // "hahaha"

Kotlin 没有 Java 中的三目运算符，取而代之的是 if 表达式或 when。
