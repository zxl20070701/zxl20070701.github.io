逻辑运算符

逻辑运算符用于组合布尔表达式。Kotlin 支持 Java 风格的 &&、||、!，同时也提供等价的单词形式 and、or、not。

符号形式 单词形式 描述 示例 结果
&& and 短路与：左侧为 false 则不计算右侧 true && false false
|| or 短路或：左侧为 true 则不计算右侧 false || true true
! not 取反 !true false 
val age = 20
val hasId = true

// 符号形式
println(age >= 18 && hasId) // true
println(age < 18 || !hasId) // false

// 单词形式
println(age >= 18 and hasId) // true
println(age < 18 or !hasId)  // false
println(!true)              // false

&&、|| 是短路的：左侧已经能确定整个表达式的结果时，右侧不再计算；而单词形式 and、or 是函数形式，两侧都会被求值。
