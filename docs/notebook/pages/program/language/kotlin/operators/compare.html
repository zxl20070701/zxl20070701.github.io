比较运算符

比较运算符用于比较两个值，结果为 Boolean。Kotlin 中的 == 比较的是结构相等（内容），而 === 比较的是引用相等（地址），这一点和 Java 的 == 不同。

运算符 描述 示例 结果
< 小于 1 < 2 true
<= 小于等于 2 <= 2 true
> 大于 3 > 1 true
>= 大于等于 2 >= 3 false
== 结构相等（内容相同） "Kotlin" == "Kotlin" true
!= 结构不等 1 != 2 true
=== 引用相等（同一对象） obj1 === obj2 true / false
!== 引用不等 obj1 !== obj2 true / false 
val a = 1
val b = 2

println(a < b)    // true
println(a <= b)   // true
println(a > b)    // false
println(a >= b)   // false
println(a == b)   // false
println(a != b)   // true

// 字符串字典序比较
println("apple" < "banana")  // true

// === 与 == 的差异
val s1 = String(charArrayOf('a', 'b'))
val s2 = String(charArrayOf('a', 'b'))
println(s1 == s2)   // true，内容相等
println(s1 === s2)  // false，是不同对象

Kotlin 中 == 比较结构相等（内容），而 === 比较引用相等（地址）。这一点和 Java 不同。
