运算符优先级

Kotlin 中运算符本质上都是函数，按照函数的优先级决定计算顺序。括号 () 的优先级最高，所有不确定优先级的地方推荐加括号。

优先级 类别 运算符 结合性
高 后缀 ++ -- ?. ?: . [] () 左
前缀 - + ! not ++ -- 右
区间 .. 右
乘性 * / % 左
加性 + - 左
区间扩展 until downTo step 左
位移 shl shr ushr 左
比较 < <= > >= in !in is !is 左
相等 == != === !== 左
位与 and 左
位异或 xor 左
位或 or 左
短路与 && 左
低 短路或 || 左 
// 算术运算优先级
val r1 = 2 + 3 * 4        // 14，先乘后加
val r2 = (2 + 3) * 4      // 20

// 位运算、比较与短路逻辑混合
val r3 = 1 + 2 shl 2      // (1 + 2) << 2 = 12
val r4 = 1 + (2 shl 2)    // 1 + 8 = 9

// in 优先级较低
val r5 = 5 in 1..10 && true  // (5 in 1..10) && true

// 不确定就加括号
val r6 = (a + b) and (c or d)

单词形式运算符（如 and、or、xor）的优先级与对应的短路运算符（&&、||、^）一致。单词形式是函数调用，整个表达式两侧都会被求值。
