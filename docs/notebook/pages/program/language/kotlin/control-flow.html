控制语法

Kotlin 提供了常见的条件分支与循环控制结构，同时用 when 替代了 switch，能力更强也更安全。

if 条件控制 

if (条件表达式) {
    // 分支 1
} else if (条件表达式) {
    // 分支 2
} else {
    // 分支 3
}

示例

// 简单的 if 判断
val age = 18
if (age >= 18) {
    println("你是成年人")
}

// if - else if - else 链
val score = 85
val grade = if (score >= 90) {
    "A"
} else if (score >= 80) {
    "B"
} else if (score >= 70) {
    "C"
} else {
    "D"
}
println("成绩等级: $grade")

// if 作为表达式
val max = if (a > b) a else b

Kotlin 的 if 既可以是语句，也可以是表达式。这意味着 if 可以直接返回一个值并赋值给变量。

when 分支

when 是 Kotlin 用来替代 switch 的关键字，既可以匹配字面量，也可以匹配区间、类型、甚至任意条件。 

when (表达式) {
    值1 -> 语句1
    值2, 值3 -> 语句2
    in 范围 -> 语句3
    is 类型 -> 语句4
    else -> 语句5
}

示例

val day = 3
val name = when (day) {
    1 -> "星期一"
    2 -> "星期二"
    3, 4 -> "星期三或星期四"
    in 5..7 -> "周末之前"
    else -> "无效"
}
println(name) // 星期三或星期四

// when 用来判断类型
val obj: Any = "Hello"
when (obj) {
    is String -> println("字符串长度: ${obj.length}")
    is Int -> println("整数加一: ${obj + 1}")
    else -> println("其它类型")
}

// when 作为表达式（也支持直接返回）
val desc = when {
    age < 12 -> "儿童"
    age < 18 -> "青少年"
    age < 60 -> "成年人"
    else -> "老年人"
}

while 循环 

while (条件表达式) {
    // 循环体
}

do {
    // 循环体
} while (条件表达式)

示例

// 计算 1 到 10 的和
var count = 1
var total = 0
while (count <= 10) {
    total += count
    count++
}
println("1到10的和是: $total")

// do-while：循环体至少执行一次
var number = 3
do {
    println(number)
    number--
} while (number > 0)

for 循环

Kotlin 的 for 只能遍历区间、数组或实现了迭代器的集合，不像 Java 那样的 C 风格 for(;;)。 

for (元素 in 集合) { ... }
for (索引 in 集合.indices) { ... }
for ((索引, 值) in 集合.withIndex()) { ... }

示例

// 遍历区间 1..5
for (i in 1..5) {
    println("第 $i 次循环")
}

// 遍历区间，左闭右开
for (i in 1 until 5) {
    println(i)
}

// 倒序遍历
for (i in 5 downTo 1) {
    println(i)
}

// 步长为 2
for (i in 1..10 step 2) {
    println(i) // 1, 3, 5, 7, 9
}

// 遍历集合
val fruits = listOf("apple", "banana", "orange")
for (fruit in fruits) {
    println("我喜欢吃 $fruit")
}

// 遍历时同时拿到下标
for ((index, fruit) in fruits.withIndex()) {
    println("$index -> $fruit")
}

break 与 continue 

// break 跳出当前循环
for (i in 1..10) {
    if (i == 5) break
    println(i) // 1, 2, 3, 4
}

// continue 跳过本轮循环
for (i in 1..5) {
    if (i == 3) continue
    println(i) // 1, 2, 4, 5
}

// 标签：跳出多层循环
outer@ for (i in 1..3) {
    for (j in 1..3) {
        if (i == 2 && j == 2) break@outer
        println("i=$i, j=$j")
    }
}

return

return 默认从最近的函数或 lambda 中返回。在 lambda 中可以使用标签 return@标签名 指定从哪一层返回。 

fun firstEven(list: List<Int>): Int? {
    list.forEach {
        if (it % 2 == 0) return it // 直接从 firstEven 返回
    }
    return null
}

// 在 lambda 内只退出当前 lambda
list.forEach label@{
    if (it == 3) return@label
    println(it)
}
