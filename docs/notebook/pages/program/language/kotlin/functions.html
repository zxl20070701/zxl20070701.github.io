函数基础概念

Kotlin 中使用 fun 关键字定义函数，函数可以独立存在，不必写在类里，这就是所谓的“顶层函数”。Kotlin 函数支持默认参数、命名参数、扩展函数、Lambda 等特性，灵活度比 Java 高很多。

基本语法 

fun 函数名(参数列表): 返回类型 {
    // 函数体
    return 值
}

示例

// 完整写法
fun add(a: Int, b: Int): Int {
    return a + b
}

// 单表达式函数，推荐用等号表示
fun multiply(a: Int, b: Int): Int = a * b

// 返回类型可推断时，可以省略
fun greet(name: String) = "Hello, $name!"

// 没有返回值，使用 Unit（类似 void）
fun printInfo(name: String): Unit {
    println("姓名: $name")
}

// 可以简写为
fun printInfo2(name: String) {
    println("姓名: $name")
}

println(add(1, 2))         // 3
println(multiply(3, 4))    // 12
println(greet("Kotlin"))   // Hello, Kotlin
printInfo("Alice")

默认参数

Kotlin 函数参数可以带默认值，调用方可以省略。 

fun greet(name: String = "World", prefix: String = "Hello"): String {
    return "$prefix, $name!"
}

println(greet())                       // Hello, World!
println(greet("Kotlin"))               // Hello, Kotlin!
println(greet(prefix = "Hi"))          // Hi, World!
println(greet("Kotlin", "Hi"))         // Hi, Kotlin!
println(greet(prefix = "Hi", name = "Kotlin")) // 命名参数顺序无关

命名参数

调用函数时，参数顺序也可以打乱，只要通过名字指定即可。 

fun config(host: String, port: Int, enableLog: Boolean) {
    println("$host:$port, log=$enableLog")
}

config(host = "127.0.0.1", port = 8080, enableLog = true)
config(enableLog = false, port = 80, host = "localhost") // 顺序可乱

可变参数（vararg） 

// 一个参数可以接收任意多个同类型参数
fun sum(vararg nums: Int): Int {
    return nums.sum()
}

println(sum(1, 2, 3))           // 6
println(sum(1, 2, 3, 4, 5))     // 15

// 传数组时加 * 展开
val arr = intArrayOf(1, 2, 3)
println(sum(*arr))              // 6

局部函数

函数内部可以定义函数，常用于抽取重复逻辑。 

fun isAdult(age: Int): Boolean {
    fun parsePositive(value: Int): Int = if (value < 0) 0 else value
    return parsePositive(age) >= 18
}
println(isAdult(20)) // true

单表达式函数

函数体只有一句表达式时，可以用 = 简化语法。 

fun double(x: Int): Int = x * 2
fun isEven(n: Int): Boolean = n % 2 == 0
fun describe(obj: Any): String = when (obj) {
    1 -> "One"
    "Hello" -> "字符串"
    is Long -> "Long 类型"
    else -> "其他"
}

扩展函数

Kotlin 允许在不修改类源码的情况下，为现有类添加新函数，调用方式与成员函数完全相同。 

// 为 String 添加一个 .last 符号！
fun String.last(): String {
    if (isEmpty()) return ""
    return this[length - 1].toString()
}

泛型函数 

fun <T> identity(value: T): T = value

println(identity(123))      // 123
println(identity("Kotlin")) // Kotlin

内联函数（inline）

以 inline 修饰的函数，编译器会把函数体直接展开到调用处，避免 Lambda 产生额外对象。适合参数里有 Lambda 且没有重载的小函数。 

inline fun measure(block: () -> Unit): Long {
    val start = System.nanoTime()
    block()
    return System.nanoTime() - start
}

val t = measure {
    (1..100_000).sum()
}
println("耗时 $t ns")

函数引用（::）

可以用 :: 把函数作为值传递给高阶函数。 

fun isOdd(n: Int): Boolean = n % 2 != 0

val list = listOf(1, 2, 3, 4, 5)
// 把 isOdd 当成谓词传进去
val odds = list.filter(::isOdd)
println(odds) // [1, 3, 5]

// 绑定方法引用
val name = "kotlin"
val upper = name::uppercase
println(upper()) // KOTLIN
