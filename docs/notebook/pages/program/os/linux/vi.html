vi&vim

首先，我们需要知道vi（或vim，下同）有三种模式：编辑模式、底行模式和命令行模式。

模式间切换

在任何情况下，按ESC都可以切换到命令行模式，而在命令行模式，输入冒号:会进入底行模式，输入字母i会进入编辑模式。

编辑模式下就是普通的文本输入，没有什么特殊的，下面主要说明另外两种模式下的一些命令。

底行模式

常用的命令就几种，分别是:q（退出）、:q!（强制退出）、:wq（保存后退出）、和:w（保存）。

其他常用命令：

  • :set number 显示行号
  • :set nonumber 隐藏行号
  • :/关键字 搜索关键字
  • :%s/旧内容/新内容/g 全文替换

命令行模式

该模式下的命令可以帮助你快速开发，不过不是必须的，下面列出几个常用的：

  • dd:删除一行
  • u:撤消修改或删除操作
  • yy:复制光标所在行到缓冲区
  • p:将缓冲区内的字符贴到光标所在位置
  • i:在光标前进入编辑模式
  • a:在光标后进入编辑模式
  • o:在下一行新建一行并进入编辑模式
  • gg:跳到文件开头
  • G:跳到文件末尾
  • n:跳到下一个搜索结果
  • N:跳到上一个搜索结果

常见操作

保存并退出： 

按 ESC
:wq

不保存退出： 

按 ESC
:q!

删除 10 行： 

    10dd
