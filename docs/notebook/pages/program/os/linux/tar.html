解压缩

快速使用

解压命令

将压缩文件解压到当前目录下（解压后的路径，默认为当前路径）： 

    tar -zxvf test.tar.gz

或者，将压缩文件解压到指定路径下： 

    tar -zxvf test.tar.gz -C /home/

压缩命令

将当前目录下的所有文件压缩： 

    tar -zcvf test.tar.gz ./

或者，指定需要打包的文件（不包含目录 /home/testDir/）： 

    tar -zcvf test.tar.gz -C /home/testDir/ .

查看压缩包内容

不解压，只查看里面有哪些文件： 

    tar -ztvf test.tar.gz

排除文件

打包时排除日志文件和依赖目录： 

    tar -zcvf app.tar.gz ./app --exclude="*.log" --exclude="node_modules"

常用参数 

-c, --create 创建一个新归档
-x, --extract, --get 从归档中解出文件
-f, --file=ARCHIVE 使用归档文件
-z, --gzip, --gunzip, --ungzip 通过 gzip 过滤归档
-C, --directory=DIR 改变至目录 DIR
-v, --verbose 详细地列出处理的文件

zip / unzip

压缩目录： 

    zip -r app.zip app/

解压到当前目录： 

    unzip app.zip

解压到指定目录： 

    unzip app.zip -d /home/app

gzip / gunzip

压缩单个文件： 

    gzip access.log

解压 .gz 文件： 

    gunzip access.log.gz
