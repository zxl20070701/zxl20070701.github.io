文本搜索和处理

grep

grep 用于搜索文本，常见于查日志、查代码、过滤命令输出。 

grep "error" app.log
grep -Rni "TODO" ./src
ps aux | grep nginx

awk

awk 适合按列处理文本，比如只取表格输出中的某一列。 

    df -h | awk '{print $1}'

sed

sed 适合做文本替换。加 -i 会直接修改文件。 

sed 's/old/new/g' file.txt
sed -i 's/old/new/g' file.txt

sort / uniq / xargs

sort 排序，uniq 去重或统计， xargs 把前一个命令的输出转成后一个命令的参数。 

sort access.log | uniq -c
find . -name "*.tmp" | xargs rm
