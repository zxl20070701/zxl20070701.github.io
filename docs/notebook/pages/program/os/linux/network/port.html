端口和网络服务

netstat / ss

netstat 和 ss 都可以查看当前机器的网络连接和监听端口。 新系统更推荐使用 ss，速度更快，信息也更直接。 

netstat -tuln
netstat -tuln | grep LISTEN
ss -tuln
ss -tulnp

参数含义：-t 表示 TCP，-u 表示 UDP， -l 只看监听端口，-n 不解析域名和服务名， -p 显示占用端口的进程。

lsof / nc

lsof 用来查看某个端口被哪个进程占用； nc 常用来测试本机或远程端口是否能连通。 

lsof -i :8080
nc -vz 127.0.0.1 8080

firewall-cmd

如果服务器启用了 firewalld，服务已经启动但外部访问不到时，可能需要放行端口。 

sudo firewall-cmd --add-port=8080/tcp --permanent
sudo firewall-cmd --reload

温馨提示：放行端口前先确认服务确实需要对外暴露。
