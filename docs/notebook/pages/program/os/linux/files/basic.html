文件基础操作

ls

列出当前目录下的文件： 

    ls

查看更详细的信息，包括权限、所有者、大小和修改时间： 

    ls -lah

按修改时间倒序排列，排查最近改动很常用： 

    ls -lt

cd / pwd

切换目录和查看当前路径： 

cd /var/log
pwd

回到上一次所在目录： 

    cd -

cp

复制文件： 

    cp source.txt target.txt

复制文件夹需要递归参数： 

    cp -r source_dir target_dir

温馨提示：覆盖文件前想确认一下，可以使用 cp -i。

rm 

    rm [选项] 文件或目录

比如删除文件的时候： 

    rm 文件

如果是文件夹，可以加个递归： 

    rm -r 文件夹

删除前逐个确认： 

    rm -i 文件

温馨提示：rm -rf 很危险，执行前最好先用 ls 确认路径。

mkdir

创建文件夹： 

    mkdir 文件夹

一次性创建多级目录： 

    mkdir -p logs/nginx/access

touch

创建文件： 

    touch 文件

如果文件已经存在，touch 会更新它的修改时间。

mv

移动文件或文件夹： 

    mv 文件或文件夹 目标文件夹

重命名文件也是使用 mv： 

    mv old.txt new.txt
