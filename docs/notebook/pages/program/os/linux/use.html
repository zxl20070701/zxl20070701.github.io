运维相关

后台运行

执行一个命令的时候，比如启动node服务器，如果希望到后台运行，可以在原命令结尾追加一个“&”符号： 

    npm run dev &
温馨提示：如果是Linux系统，推荐直接：nohup npm run dev &，对于ssh连接的命令行，记得使用 exit命令退出登录。

nohup

让命令在退出终端后继续运行，并把输出写入日志： 

    nohup npm run dev > app.log 2>&1 &

查看后台任务是否还在： 

    ps aux | grep "npm run dev"

重定向

把标准输出写入文件： 

    command > output.log

追加写入文件： 

    command >> output.log

同时保存标准输出和错误输出： 

    command > output.log 2>&1

管道

管道可以把前一个命令的输出交给后一个命令处理： 

    cat app.log | grep "ERROR"

统计日志里错误出现的次数： 

    grep "ERROR" app.log | wc -l

alias

给常用命令起别名： 

    alias ll='ls -lah'

想永久生效，可以写入 ~/.bashrc 或 ~/.zshrc。
