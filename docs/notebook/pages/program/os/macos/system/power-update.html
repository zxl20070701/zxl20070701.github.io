电源和软件更新

运行状态

查看系统负载、进程资源占用、虚拟内存和 CPU 功耗。 

uptime
top
top -o cpu
top -o mem
vm_stat
sudo powermetrics --samplers cpu_power -n 1

电源和休眠

pmset 查看电源策略和电池状态； caffeinate 可以临时阻止系统休眠。 

pmset -g
pmset -g batt
pmset -g log | grep -i "wake"
caffeinate -dimsu

软件更新

查看并安装 macOS 系统更新。 

softwareupdate -l
sudo softwareupdate -ia
