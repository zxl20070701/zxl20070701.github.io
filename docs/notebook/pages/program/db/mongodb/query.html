查询操作

find() 基础查询 

db.collection.find()

查询所有文档，等价于 SQL 中的 SELECT * FROM table。 

db.users.find().pretty()

条件查询 

db.users.find({name: "张三"})
db.users.find({age: 18})
db.users.find({city: "北京", age: {$gt: 20}})

findOne() 查询单条 

db.users.findOne({name: "张三"})

findOne() 只返回符合条件的第一条文档。

投影（指定返回字段） 

db.users.find({}, {name: 1, age: 1})
db.users.find({}, {name: 1, _id: 0})

1 表示显示该字段，0 表示不显示。_id 字段默认总是返回。

sort() 排序 

db.users.find().sort({age: 1})
db.users.find().sort({age: -1})
db.users.find().sort({age: -1, name: 1})

1 表示升序，-1 表示降序。

limit() 和 skip() 

db.users.find().limit(10)
db.users.find().skip(5).limit(10)

limit 限制返回数量，skip 跳过指定数量的文档，常用于分页。

countDocuments() 计数 

db.users.countDocuments()
db.users.countDocuments({age: {$gt: 18}})

去重查询 

db.users.distinct("city")

分页查询示例 

// 第1页，每页10条
db.users.find().skip(0).limit(10)
// 第2页，每页10条
db.users.find().skip(10).limit(10)
// 通用公式：skip = (page-1) * pageSize
