事务与锁

事务概述

MongoDB 4.0+ 支持多文档事务，4.2+ 支持分布式事务。事务需要在副本集或分片集群上运行。

开启事务 

// 开始会话
const session = db.getMongo().startSession();
// 开始事务
session.startTransaction();
// 提交事务
session.commitTransaction();
// 回滚事务
session.abortTransaction();
// 结束会话
session.endSession();

事务示例 

const session = db.getMongo().startSession();
try {
    session.startTransaction();

    // 扣减库存
    db.products.updateOne(
        {_id: productId, stock: {$gte: 1}},
        {$inc: {stock: -1}},
        {session}
    );

    // 创建订单
    db.orders.insertOne({
        userId: userId,
        productId: productId,
        status: "paid"
    }, {session});

    session.commitTransaction();
} catch (error) {
    session.abortTransaction();
} finally {
    session.endSession();
}

分布式事务 

// 分布式事务支持跨分片操作
const session = db.getMongo().startSession();
session.startTransaction({
    readPreference: 'primary',
    readConcern: {level: 'local'},
    writeConcern: {w: 'majority'}
});
// ... 跨分片操作
session.commitTransaction();

隔离级别 

// 支持的隔离级别：
// - readCommitted（默认）
// - snapshot
session.startTransaction({
    readConcern: {level: 'snapshot'}
});

常用事务命令 

// 查看当前事务状态
db.runCommand({
    transactionStatus: 1,
    sessionId: ...
})
// 事务超时设置
db.adminCommand({
    setTransactionTimeout: 1,
    timeoutMs: 5000
})
