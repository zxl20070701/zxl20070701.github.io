多表连接查询

内连接 INNER JOIN

只返回两表中匹配的记录。如果右表中没有匹配的记录，则不会出现在结果中。 

SELECT u.name, o.order_no
FROM users u
INNER JOIN orders o ON u.id = o.user_id;

左连接 LEFT JOIN

返回左表（users）中的所有记录，即使右表（orders）中没有匹配。右表中无匹配的字段显示为 NULL。 

SELECT u.name, o.order_no
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;

右连接 RIGHT JOIN

返回右表（orders）中的所有记录，即使左表（users）中没有匹配。左表中无匹配的字段显示为 NULL。 

SELECT u.name, o.order_no
FROM users u
RIGHT JOIN orders o ON u.id = o.user_id;

全连接 FULL JOIN

返回左右两表中的所有记录。MySQL 不直接支持 FULL JOIN，可以通过 LEFT JOIN + UNION + RIGHT JOIN 实现。 

SELECT u.name, o.order_no FROM users u LEFT JOIN orders o ON u.id = o.user_id
UNION
SELECT u.name, o.order_no FROM users u RIGHT JOIN orders o ON u.id = o.user_id;

多表连接 

SELECT u.name, p.product_name, o.quantity
FROM users u
INNER JOIN orders o ON u.id = o.user_id
INNER JOIN products p ON o.product_id = p.id;

自连接

表与其自身连接，常用于层级结构（如组织架构、评论回复）。 

SELECT e.name AS employee, m.name AS manager
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.id;

交叉连接 CROSS JOIN

返回两表的笛卡尔积，即左表的每一行与右表的每一行组合。 

SELECT * FROM users CROSS JOIN products;
