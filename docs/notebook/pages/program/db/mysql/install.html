安装和使用

在 Mac OS 上安装 MySQL

安装最新稳定版： 

brew install mysql

指定固定版本（如 8.0）： 

brew install mysql@8.0

启动&停止

安装成功后，临时启动（重启电脑不会自启）： 

mysql.server start

如果需要停止： 

mysql.server stop

账号密码

需要mysql先启动才可以哦。

执行下面命令无密登录： 

mysql -u root

然后设置即可： 

-- 刷新权限缓存（必须第一步）
FLUSH PRIVILEGES;
-- 设置localhost的root密码，替换为你自己的密码
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的新密码';
-- 退出
exit;

在 Windows 上安装 MySQL

下载地址： https://downloads.mysql.com/archives/community/

打开后，“Operating System”改成“Microsoft Windows”，选 Windows (x86, 64-bit), MSI Installer（离线完整版，无需全程联网）后正常安装即可。

登录数据库

使用下面的命令进行登录： 

mysql -h 主机名 -u 用户名 -p

回车后输入密码即可。
