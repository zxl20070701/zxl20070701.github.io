Compose 基础

Jetpack Compose 是 Android 官方声明式 UI 框架， 用 Kotlin 函数描述界面，状态变化自动触发 UI 刷新（重组）。

第一个 Composable 

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            MyAppTheme {
                Greeting("Compose")
            }
        }
    }
}

@Composable
fun Greeting(name: String) {
    Text(text = "Hello $name!")
}

状态管理（重组核心）

remember + mutableStateOf 

@Composable
fun Counter() {
    // remember：跨重组保留值
    // mutableStateOf：值变化时触发重组
    var count by remember { mutableStateOf(0) }

    Column {
        Text("点击了 $count 次")
        Button(onClick = { count++ }) {
            Text("点我 +1")
        }
    }
}

rememberSaveable（配置变化不丢） 

// 旋转屏幕 / 深色模式切换后仍保留
var input by rememberSaveable { mutableStateOf("") }

State Hoisting（状态提升）

把状态下移到父组件，子组件只接收值和回调，便于复用与测试： 

@Composable
fun Parent() {
    var name by remember { mutableStateOf("") }
    NameInput(value = name, onValueChange = { name = it })
}

@Composable
fun NameInput(value: String, onValueChange: (String) -> Unit) {
    OutlinedTextField(value = value, onValueChange = onValueChange)
}

Modifier 修饰符 

Text(
    text = "Hello",
    modifier = Modifier
        .fillMaxWidth()                 // 宽度撑满
        .padding(16.dp)                 // 外边距
        .background(Color(0xFF2196F3))  // 背景色
        .padding(8.dp)                  // 内边距（顺序敏感）
        .clickable { /* 点击 */ }
)
Modifier 链式调用顺序敏感：先 padding 再 background 是"内边距"； 反过来则是"外边距"。

副作用 API

  • LaunchedEffect(key) ：进入组合或 key 变化时启动协程；key 变化时旧协程取消。
  • DisposableEffect ：注册监听 / 资源，离开组合时释放。
  • derivedStateOf ：从其他 State 派生，避免不必要的重组。
  • rememberCoroutineScope ：在事件回调中启动协程（非 LaunchedEffect 场景）。 
@Composable
fun TimerScreen() {
    var seconds by remember { mutableStateOf(0) }

    LaunchedEffect(Unit) {
        while (true) {
            delay(1000)
            seconds++
        }
    }
    Text("已计时 $seconds 秒")
}
