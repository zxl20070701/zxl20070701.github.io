Column / Row 线性布局

Compose 中的 Column（纵向）和 Row（横向）用于线性排列子组件， 替代 View 时代的 LinearLayout。

Column 纵向排列 

Column(
    modifier = Modifier
        .fillMaxSize()
        .padding(16.dp),
    verticalArrangement = Arrangement.spacedBy(8.dp), // 子项间距
    horizontalAlignment = Alignment.CenterHorizontally  // 水平对齐
) {
    Text("第一行")
    Text("第二行")
    Text("第三行")
}

Row 横向排列 

Row(
    modifier = Modifier.fillMaxWidth(),
    horizontalArrangement = Arrangement.SpaceBetween, // 两端对齐
    verticalAlignment = Alignment.CenterVertically     // 垂直居中
) {
    Text("左侧")
    Text("右侧")
}

Arrangement 排列方式对照

Compose Arrangement 原 LinearLayout 说明
Arrangement.Top / Start gravity="top/start" 顶部/起始对齐
Arrangement.Center gravity="center" 居中
Arrangement.Bottom / End gravity="bottom/end" 底部/末尾对齐
Arrangement.SpaceBetween 需要嵌套 View 实现 两端对齐，中间等距
Arrangement.SpaceAround 需要嵌套 View 实现 子项周围等距
Arrangement.SpaceEvenly 需要嵌套 View 实现 完全等距分布
Arrangement.spacedBy(8.dp) android:divider + dividerPadding 固定间距

Weight 权重分配 

Row(modifier = Modifier.fillMaxWidth()) {
    // 占 1/3
    Box(
        modifier = Modifier
            .weight(1f)
            .height(50.dp)
            .background(Color.Red)
    )
    // 占 2/3
    Box(
        modifier = Modifier
            .weight(2f)
            .height(50.dp)
            .background(Color.Blue)
    )
}

Column(modifier = Modifier.fillMaxSize()) {
    // 顶部固定高度
    Box(modifier = Modifier.height(100.dp).fillMaxWidth().background(Color.Green))
    // 剩余空间填满
    Box(modifier = Modifier.weight(1f).fillMaxWidth().background(Color.Yellow))
}

滚动支持 

// Column 超出屏幕时滚动
Column(
    modifier = Modifier
        .fillMaxSize()
        .verticalScroll(rememberScrollState()) // 纵向滚动
) {
    repeat(100) {
        Text("第 $it 行", modifier = Modifier.padding(16.dp))
    }
}

// Row 横向滚动
Row(
    modifier = Modifier
        .fillMaxWidth()
        .horizontalScroll(rememberScrollState()) // 横向滚动
) {
    repeat(20) {
        Card(modifier = Modifier.padding(8.dp).size(100.dp)) {
            Text("卡片 $it")
        }
    }
}

嵌套布局 

Column(modifier = Modifier.fillMaxSize().padding(16.dp)) {
    // 顶部标题
    Text("标题", style = MaterialTheme.typography.titleLarge)

    // 中间内容（Row 嵌套）
    Row(
        modifier = Modifier.fillMaxWidth().weight(1f),
        horizontalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Box(modifier = Modifier.weight(1f).fillMaxHeight().background(Color.LightGray))
        Box(modifier = Modifier.weight(2f).fillMaxHeight().background(Color.Gray))
    }

    // 底部按钮
    Button(onClick = { }, modifier = Modifier.fillMaxWidth()) {
        Text("确定")
    }
}
Compose 的 weight 必须在 RowScope / ColumnScope 中使用， 直接写在普通 Modifier 上会编译报错。 同时 spacedBy 比 View 时代的 divider 更简洁。
