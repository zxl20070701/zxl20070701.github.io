Box 相对布局

Compose 中的 Box 用于层叠和相对定位， 替代 View 时代的 RelativeLayout / FrameLayout。 配合 Alignment 可以实现任意相对位置关系。

基础用法 

Box(
    modifier = Modifier
        .fillMaxSize()
        .padding(16.dp)
) {
    // 背景层
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.LightGray)
    )

    // 内容层（默认堆叠在上方）
    Text("前景文字")
}

位置对齐（Alignment） 

Box(modifier = Modifier.fillMaxSize()) {
    // 顶部居中
    Text("顶部居中", modifier = Modifier.align(Alignment.TopCenter))

    // 底部右侧
    Text("右下角", modifier = Modifier.align(Alignment.BottomEnd))

    // 正中心
    Text("中心", modifier = Modifier.align(Alignment.Center))

    // 左侧垂直居中
    Text("左侧居中", modifier = Modifier.align(Alignment.CenterStart))
}

Alignment 对照表

Compose Alignment 原 RelativeLayout 说明
Alignment.TopStart alignParentStart + alignParentTop 左上角
Alignment.TopCenter alignParentTop + centerHorizontal 顶部居中
Alignment.TopEnd alignParentEnd + alignParentTop 右上角
Alignment.CenterStart alignParentStart + centerVertical 左侧居中
Alignment.Center centerInParent 正中心
Alignment.CenterEnd alignParentEnd + centerVertical 右侧居中
Alignment.BottomStart alignParentStart + alignParentBottom 左下角
Alignment.BottomCenter alignParentBottom + centerHorizontal 底部居中
Alignment.BottomEnd alignParentEnd + alignParentBottom 右下角

层叠示例：头像 + 红点 

Box {
    // 头像
    Image(
        painter = painterResource(R.drawable.avatar),
        contentDescription = null,
        modifier = Modifier
            .size(64.dp)
            .clip(CircleShape)
    )

    // 右上角红点
    Box(
        modifier = Modifier
            .align(Alignment.TopEnd)
            .size(16.dp)
            .background(Color.Red, CircleShape)
            .border(2.dp, Color.White, CircleShape)
    )
}

相对于兄弟组件定位

Compose 中没有 layout_below， 使用 Column + Box 或 ConstraintLayout 实现： 

// 方式一：Column 包裹（推荐，简单场景）
Column {
    Text("上方标题")
    Box(modifier = Modifier.fillMaxWidth()) {
        Text("内容区域")
        Button(
            onClick = { },
            modifier = Modifier.align(Alignment.CenterEnd)
        ) {
            Text("右侧按钮")
        }
    }
}

// 方式二：ConstraintLayout（复杂场景）
implementation("androidx.constraintlayout:constraintlayout-compose:1.0.1")

ConstraintLayout(modifier = Modifier.fillMaxSize()) {
    val (title, content, button) = createRefs()

    Text("标题", modifier = Modifier.constrainAs(title) {
        top.linkTo(parent.top, margin = 16.dp)
        start.linkTo(parent.start, margin = 16.dp)
    })

    Box(modifier = Modifier.constrainAs(content) {
        top.linkTo(title.bottom)
        start.linkTo(parent.start)
        end.linkTo(parent.end)
    })

    Button(onClick = { }, modifier = Modifier.constrainAs(button) {
        bottom.linkTo(parent.bottom, margin = 16.dp)
        end.linkTo(parent.end, margin = 16.dp)
    }) {
        Text("确定")
    }
}

matchParentSize 填满父容器 

Box(modifier = Modifier.size(200.dp).background(Color.LightGray)) {
    // 填满父 Box 的剩余空间
    Box(
        modifier = Modifier
            .matchParentSize()
            .padding(16.dp)
            .background(Color.Blue.copy(alpha = 0.5f))
    )
}
Box 内的子组件默认按声明顺序层叠， 后声明的在上层。配合 zIndex 可以调整层级。
