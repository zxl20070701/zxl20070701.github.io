SharedPreferences 与 DataStore

SharedPreferences 用于以键值对形式存储少量数据（用户偏好、设置项等）。

SharedPreferences 基本用法

写入数据 

val sp = getSharedPreferences("config", MODE_PRIVATE)
sp.edit()
    .putString("username", "zxl")
    .putInt("age", 18)
    .apply() // 异步写入磁盘，推荐。commit() 同步返回 Boolean

读取数据 

val sp = getSharedPreferences("config", MODE_PRIVATE)
val username = sp.getString("username", "默认值") ?: ""
val age = sp.getInt("age", 0)

清除数据 

getSharedPreferences("config", MODE_PRIVATE).edit().clear().apply()

DataStore（推荐替代） 

// build.gradle.kts
// implementation("androidx.datastore:datastore-preferences:1.1.1")

// 定义 Keys
object PreferencesKeys {
    val USERNAME = stringPreferencesKey("username")
}

val dataStore: DataStore<Preferences> = preferencesDataStore(name = "settings")

// 写入（suspend，可在 viewModelScope / lifecycleScope 中调用）
suspend fun saveUsername(name: String) {
    dataStore.edit { prefs ->
        prefs[PreferencesKeys.USERNAME] = name
    }
}

// 读取（Flow 异步流）
val usernameFlow: Flow<String> = dataStore.data.map { prefs ->
    prefs[PreferencesKeys.USERNAME] ?: ""
}

// 在 ViewModel 中 collect
viewModelScope.launch {
    usernameFlow.collect { name -> /* 更新 UI */ }
}

Compose 中订阅 

@Composable
fun SettingsScreen(viewModel: SettingsViewModel = viewModel()) {
    // 自动感知生命周期，后台停止收集
    val username by viewModel.username.collectAsStateWithLifecycle()

    OutlinedTextField(
        value = username,
        onValueChange = { viewModel.saveUsername(it) },
        label = { Text("用户名") }
    )
}
