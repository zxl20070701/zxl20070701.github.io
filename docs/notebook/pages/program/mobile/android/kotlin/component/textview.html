Text

Compose 中的 Text 用于显示文本， 替代 View 时代的 TextView。

基础用法 

@Composable
fun TextDemo() {
    Text(
        text = "Hello Compose",
        color = Color(0xFF1A1A1A),
        fontSize = 20.sp,
        fontWeight = FontWeight.Bold,
        fontStyle = FontStyle.Italic,
        textAlign = TextAlign.Center,
        maxLines = 1,
        overflow = TextOverflow.Ellipsis,
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    )
}

常用属性对照表

Compose 属性 原 XML 属性 说明
color android:textColor 文字颜色
fontSize android:textSize 字号（sp）
fontWeight android:textStyle="bold" 字重
fontStyle android:textStyle="italic" 斜体
textAlign android:gravity 对齐方式
maxLines android:maxLines 最大行数
overflow android:ellipsize 溢出处理
lineHeight android:lineHeight 行高

富文本（AnnotatedString） 

val annotatedText = buildAnnotatedString {
    append("点击")
    withStyle(SpanStyle(color = Color.Blue, fontWeight = FontWeight.Bold)) {
        append("查看详情")
    }
    append("了解更多")
}

Text(text = annotatedText)

可点击的文字片段 

val uriHandler = LocalUriHandler.current
val annotatedString = buildAnnotatedString {
    append("阅读并同意")
    withLink(
        LinkAnnotation.Url(
            url = "https://example.com/agreement",
            styles = TextLinkStyles(SpanStyle(color = Color.Blue))
        )
    ) {
        append("《用户协议》")
    }
}

Text(text = annotatedString)

选择复制 

SelectionContainer {
    Column {
        Text("这段文字可以被选择复制")
        Text("也可以复制这一段")
    }
}
Compose 中 fontSize 直接用 sp 单位， padding 等用 dp；不再需要像 XML 那样区分 android:textSize="20sp" 的字符串写法。
