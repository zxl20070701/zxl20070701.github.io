Button 按钮

Compose 中的 Button、 OutlinedButton、 TextButton、 IconButton 用于触发点击操作， 替代 View 时代的 Button / ImageButton。

基础按钮 

@Composable
fun ButtonDemo() {
    Column(
        modifier = Modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        // 实心按钮
        Button(onClick = { /* 点击逻辑 */ }) {
            Text("主要操作")
        }

        // 描边按钮
        OutlinedButton(onClick = { /* 点击逻辑 */ }) {
            Text("次要操作")
        }

        // 文字按钮（最弱强调）
        TextButton(onClick = { /* 点击逻辑 */ }) {
            Text("取消")
        }
    }
}

按钮状态：加载中 

@Composable
fun SubmitButton() {
    var isLoading by remember { mutableStateOf(false) }

    Button(
        onClick = {
            isLoading = true
            // 模拟网络请求
        },
        enabled = !isLoading,
        modifier = Modifier.fillMaxWidth()
    ) {
        if (isLoading) {
            CircularProgressIndicator(
                modifier = Modifier.size(20.dp),
                color = MaterialTheme.colorScheme.onPrimary,
                strokeWidth = 2.dp
            )
            Spacer(modifier = Modifier.width(8.dp))
            Text("提交中...")
        } else {
            Text("提交")
        }
    }
}

点击事件最佳实践 

// 推荐：将事件通过 lambda 传入，便于预览和测试
@Composable
fun ProfileScreen(
    onEditClick: () -> Unit,
    onLogoutClick: () -> Unit
) {
    Column {
        OutlinedButton(onClick = onEditClick) {
            Text("编辑资料")
        }
        TextButton(onClick = onLogoutClick) {
            Text("退出登录", color = Color.Red)
        }
    }
}

// 调用处
ProfileScreen(
    onEditClick = { navController.navigate("edit") },
    onLogoutClick = { viewModel.logout() }
)
Compose 中不再有 setOnClickListener， 所有交互事件都通过 Composable 的参数传入， 天然实现了状态提升和单向数据流。
