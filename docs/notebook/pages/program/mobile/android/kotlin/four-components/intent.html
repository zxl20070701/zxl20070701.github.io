Intent

Intent 是组件之间传递消息的"信使"，可以启动 Activity、Service 和发送广播。

分类

  • 显式 Intent ：明确指定目标组件的类名。
  • 隐式 Intent ：只声明动作和数据，由系统匹配符合条件的组件。

显式 Intent 

val intent = Intent(this, SecondActivity::class.java)
startActivity(intent)

隐式 Intent 

val intent = Intent(Intent.ACTION_VIEW).apply {
    data = Uri.parse("https://zxl20070701.github.io/notebook/index.html")
}
startActivity(intent)

传递数据

写入 

intent.putExtra("name", "zxl")
intent.putExtra("age", 18)

读取 

// 在目标 Activity 的 onCreate 中读取
val name = intent.getStringExtra("name")
val age = intent.getIntExtra("age", 0)

IntentFilter

在清单文件中声明组件能够响应的动作： 

<activity android:name=".SecondActivity">
    <intent-filter>
        <action android:name="com.example.MY_ACTION" />
        <category android:name="android.intent.category.DEFAULT" />
    </intent-filter>
</activity>

Compose 中通过 Intent 跳转 

@Composable
fun ShareScreen() {
    val context = LocalContext.current

    Button(onClick = {
        // 显式 Intent：跳转到另一个 Activity
        val intent = Intent(context, DetailActivity::class.java).apply {
            putExtra("id", 123)
        }
        context.startActivity(intent)
    }) {
        Text("跳转详情页")
    }

    Button(onClick = {
        // 隐式 Intent：打开浏览器
        val intent = Intent(Intent.ACTION_VIEW).apply {
            data = Uri.parse("https://example.com")
        }
        context.startActivity(intent)
    }) {
        Text("打开网页")
    }

    Button(onClick = {
        // 分享文本
        val intent = Intent(Intent.ACTION_SEND).apply {
            type = "text/plain"
            putExtra(Intent.EXTRA_TEXT, "分享内容")
        }
        context.startActivity(Intent.createChooser(intent, "分享到"))
    }) {
        Text("分享")
    }
}
