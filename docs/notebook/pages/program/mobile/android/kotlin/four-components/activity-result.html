Activity Result

页面间返回结果（如选择图片、申请权限、打开系统页面）使用 Activity Result API。 官方已废弃 startActivityForResult， 改用 ActivityResultLauncher。

Activity 中注册 

class MainActivity : ComponentActivity() {

    // 1. 声明 launcher（在 onCreate 之前调用）
    private val pickImageLauncher =
        registerForActivityResult(ActivityResultContracts.GetContent()) { uri: Uri? ->
            uri?.let { /* 处理选中的图片 */ }
        }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            // 2. 在 Compose 中触发
            Button(onClick = { pickImageLauncher.launch("image/*") }) {
                Text("选择图片")
            }
        }
    }
}

Compose 中注册（推荐） 

@Composable
fun PickImageScreen() {
    val pickImageLauncher = rememberLauncherForActivityResult(
        contract = ActivityResultContracts.GetContent()
    ) { uri: Uri? ->
        uri?.let { /* 处理图片 */ }
    }

    Button(onClick = { pickImageLauncher.launch("image/*") }) {
        Text("选择图片")
    }
}

常用 Contract

  • GetContent ：选择内容（图片、视频、文件）。
  • OpenDocument ：选择并长期访问某个文档。
  • TakePicturePreview ：拍照并返回缩略图。
  • RequestPermission ：申请单个运行时权限。
  • RequestMultiplePermissions ：一次申请多个权限。
launcher 必须在 onCreate 之前或 rememberLauncherForActivityResult 中注册， 否则会在配置变化重建时抛出异常。
