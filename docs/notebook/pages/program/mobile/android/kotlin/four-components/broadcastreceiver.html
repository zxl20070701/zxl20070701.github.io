BroadcastReceiver

BroadcastReceiver 用于监听系统或应用发出的广播通知。

分类

  • 静态注册 ：在清单文件中注册，应用未启动也能接收广播。
  • 动态注册 ：在代码中注册，组件销毁时需要取消注册。

自定义广播接收器 

class MyReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val action = intent.action
        // 处理广播逻辑
    }
}

静态注册 

<receiver android:name=".MyReceiver"
          android:exported="true|false">
    <intent-filter>
        <action android:name="com.example.MY_BROADCAST" />
    </intent-filter>
</receiver>
Android 13（API 33）起静态注册必须显式声明 android:exported。

动态注册 

val receiver = MyReceiver()
val filter = IntentFilter("com.example.MY_BROADCAST")
// Android 14（API 34）起统一使用 ContextCompat.registerReceiver，
// 需显式声明 RECEIVER_EXPORTED 或 RECEIVER_NOT_EXPORTED
ContextCompat.registerReceiver(
    this,
    receiver,
    filter,
    ContextCompat.RECEIVER_NOT_EXPORTED
)

// 记得在 onDestroy 中取消注册
override fun onDestroy() {
    super.onDestroy()
    unregisterReceiver(receiver)
}

发送自定义广播 

val intent = Intent("com.example.MY_BROADCAST").apply {
    setPackage(packageName) // 限制接收方，更安全
    putExtra("msg", "hello")
}
sendBroadcast(intent)

Compose 中监听广播 

@Composable
fun BatteryScreen() {
    var batteryLevel by remember { mutableIntStateOf(0) }
    val context = LocalContext.current

    DisposableEffect(Unit) {
        val receiver = object : BroadcastReceiver() {
            override fun onReceive(context: Context, intent: Intent) {
                batteryLevel = intent.getIntExtra(BatteryManager.EXTRA_LEVEL, 0)
            }
        }
        val filter = IntentFilter(Intent.ACTION_BATTERY_CHANGED)
        ContextCompat.registerReceiver(
            context, receiver, filter, ContextCompat.RECEIVER_NOT_EXPORTED
        )
        onDispose {
            context.unregisterReceiver(receiver)
        }
    }

    Text("当前电量：$batteryLevel%")
}
