Kotlin 协程

协程是 Kotlin 官方异步方案，用同步写法实现异步逻辑，替代回调与 RxJava。 核心概念：suspend 函数、 CoroutineScope、 Dispatcher、 Flow。

添加依赖 

implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.9.0")
implementation("androidx.lifecycle:lifecycle-runtime-ktx:2.8.7")
implementation("androidx.lifecycle:lifecycle-viewmodel-ktx:2.8.7")

三大作用域

viewModelScope（首选） 

class MainViewModel : ViewModel() {
    fun loadData() {
        viewModelScope.launch {
            // ViewModel 销毁时自动取消，无内存泄漏
            val data = repository.fetch()
            _uiState.value = data
        }
    }
}

lifecycleScope（Activity / Fragment） 

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        lifecycleScope.launch {
            // 与生命周期绑定，DESTROYED 时取消
        }
    }
}

repeatOnLifecycle（UI 收集 Flow） 

lifecycleScope.launch {
    repeatOnLifecycle(Lifecycle.State.STARTED) {
        // STARTED 时才收集，STOPPED 时暂停，避免后台耗电
        viewModel.uiState.collect { state ->
            // 更新 UI
        }
    }
}

Compose 里等效写法： 

val uiState by viewModel.uiState.collectAsStateWithLifecycle()

Dispatcher 调度器

  • Dispatchers.Main ：UI 线程，更新界面。
  • Dispatchers.IO ：网络、文件、数据库。
  • Dispatchers.Default ：CPU 密集型计算（解析 JSON、排序等）。 
viewModelScope.launch {
    // 默认在 Main
    showLoading()
    val data = withContext(Dispatchers.IO) {
        api.fetchData() // 切到 IO
    }
    showData(data) // 回到 Main
}

suspend 挂起函数 

// 声明
suspend fun fetchUser(id: Int): User {
    return withContext(Dispatchers.IO) {
        api.getUser(id) // 阻塞式写法，实际是非阻塞挂起
    }
}

// 调用：只能在协程或其他 suspend 函数中
viewModelScope.launch {
    val user = fetchUser(1)
}

并发与编排

async 并发执行 

viewModelScope.launch {
    val userDeferred = async { fetchUser(1) }
    val ordersDeferred = async { fetchOrders(1) }
    // 两个请求同时进行，等两者都完成
    show(userDeferred.await(), ordersDeferred.await())
}

超时 

withTimeout(3000) {
    api.fetch() // 超过 3 秒抛 TimeoutCancellationException
}

异常处理 

val handler = CoroutineExceptionHandler { _, e ->
    Log.e("VM", "协程异常", e)
}
viewModelScope.launch(handler) {
    // ...
}
// 或用 try/catch（推荐，粒度更细）
viewModelScope.launch {
    try {
        api.fetch()
    } catch (e: IOException) {
        _error.value = "网络异常"
    }
}

Flow 流

冷流 vs 热流

  • Flow ：冷流，collect 时才发射，每个收集者独立。
  • StateFlow ：热流，持有当前值，UI 状态首选。
  • SharedFlow ：热流，事件总线，可配置 replay。

常用操作符 

flow {
    emit(api.fetch())
}
    .map { it.toUiModel() }        // 转换
    .filter { it.isValid }         // 过滤
    .debounce(300)                 // 防抖（搜索框常用）
    .distinctUntilChanged()        // 去重
    .onStart { emit(Loading) }     // 前置发射
    .catch { e -> emit(Error(e)) } // 异常兜底
    .flowOn(Dispatchers.IO)        // 上游切线程
    .collect { /* 消费 */ }

回调转 Flow 

fun locationFlow(): Flow<Location> = callbackFlow {
    val listener = LocationListener { loc -> trySend(loc) }
    requestUpdates(listener)
    awaitClose { removeUpdates(listener) } // 取消时清理资源
}
不要再使用 GlobalScope，它不受生命周期约束； 业务代码首选 viewModelScope，UI 层用 repeatOnLifecycle / collectAsStateWithLifecycle。
