Compose 事件处理

Compose 中的事件处理基于 Modifier 和 Lambda 回调， 替代 View 时代的 setOnClickListener / OnTouchListener 等。

点击事件 

// 最常用：Button 等组件自带 onClick 参数
Button(onClick = { /* 处理点击 */ }) {
    Text("点我")
}

// 任意组件可点击
Box(
    modifier = Modifier
        .size(100.dp)
        .clickable { /* 处理点击 */ }
        .background(Color.LightGray)
)

// 长按
Box(
    modifier = Modifier
        .size(100.dp)
        .combinedClickable(
            onClick = { /* 单击 */ },
            onLongClick = { /* 长按 */ },
            onDoubleClick = { /* 双击 */ }
        )
)

常用 Modifier 事件对照

Compose Modifier 原 View 事件 说明
Modifier.clickable setOnClickListener 点击
Modifier.combinedClickable setOnLongClickListener 单击 + 长按 + 双击
Modifier.pointerInput setOnTouchListener 自定义触摸手势
Modifier.onFocusChanged setOnFocusChangeListener 焦点变化
Modifier.pointerHoverIcon OnHoverListener 鼠标悬停（桌面端）

文本输入变化 

var text by remember { mutableStateOf("") }

// 方式一：onValueChange 回调（推荐）
OutlinedTextField(
    value = text,
    onValueChange = { newText ->
        text = newText
        // 实时响应输入，如搜索建议
        viewModel.search(newText)
    }
)

// 方式二：防抖搜索
val searchQuery by remember { derivedStateOf { text } }
LaunchedEffect(searchQuery) {
    if (searchQuery.length > 2) {
        delay(300) // 防抖
        viewModel.search(searchQuery)
    }
}

手势处理

拖拽 

var offsetX by remember { mutableStateOf(0f) }
var offsetY by remember { mutableStateOf(0f) }

Box(
    modifier = Modifier
        .offset { IntOffset(offsetX.roundToInt(), offsetY.roundToInt()) }
        .size(100.dp)
        .background(Color.Blue)
        .pointerInput(Unit) {
            detectDragGestures { change, dragAmount ->
                change.consume()
                offsetX += dragAmount.x
                offsetY += dragAmount.y
            }
        }
)

缩放 

var scale by remember { mutableStateOf(1f) }

Box(
    modifier = Modifier
        .fillMaxSize()
        .pointerInput(Unit) {
            detectTransformGestures { _, _, zoom, _ ->
                scale *= zoom
            }
        }
) {
    Image(
        painter = painterResource(R.drawable.photo),
        contentDescription = null,
        modifier = Modifier
            .fillMaxSize()
            .graphicsLayer(
                scaleX = scale,
                scaleY = scale
            )
    )
}

事件消费与拦截

Compose 中事件通过 PointerEventPass 分层传递：

  • Initial ：事件先经过父组件，适合拦截。
  • Main ：事件到达目标组件，默认处理。
  • Final ：事件处理完成后回调，适合清理。 
Box(
    modifier = Modifier
        .fillMaxSize()
        .pointerInput(Unit) {
            awaitEachGesture {
                val down = awaitFirstDown(pass = PointerEventPass.Initial)
                // 父组件拦截
                if (shouldIntercept(down.position)) {
                    down.consume()
                }
            }
        }
) {
    // 子组件
    Button(onClick = { /* ... */ }) { Text("按钮") }
}
Compose 中事件处理天然支持协程， 可以在手势回调中直接调用 suspend 函数， 无需像 View 时代那样手动切换线程。
