RelativeLayout（相对布局）

RelativeLayout 通过相对参照（父容器或兄弟控件）来定位子视图。

常用属性

相对于父容器

  • android:layout_alignParentStart / End / Top / Bottom
  • android:layout_centerInParent / centerHorizontal / centerVertical

相对于兄弟控件

  • android:layout_toStartOf / toEndOf
  • android:layout_above / below
  • android:layout_alignStart / alignTop / alignEnd / alignBottom

示例 

<RelativeLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:id="@+id/tv_top"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_centerHorizontal="true"
        android:text="顶部居中" />

    <Button
        android:id="@+id/btn"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_below="@id/tv_top"
        android:layout_alignParentEnd="true"
        android:text="右下角按钮" />

</RelativeLayout>
