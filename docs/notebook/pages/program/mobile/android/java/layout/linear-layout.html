LinearLayout（线性布局）

LinearLayout 是 Android 中最常用的布局之一，将子视图按水平或垂直方向依次排列。

属性

名称 描述
android:orientation 排列方向，vertical（默认） 或 horizontal。
android:layout_width 布局宽度，常用 match_parent、wrap_content、固定 dp。
android:layout_height 布局高度，取值同上。
android:gravity 内部子元素的对齐方式。
android:layout_weight 按比例分配剩余空间（常用于宽度或高度分配）。

示例：垂直方向 

<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="第一行" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="第二行" />

</LinearLayout>

示例：水平方向 + weight 

<LinearLayout
    android:orientation="horizontal"
    android:layout_width="match_parent"
    android:layout_height="wrap_content">

    <Button
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="1"
        android:text="按钮1" />

    <Button
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="2"
        android:text="按钮2" />

</LinearLayout>
