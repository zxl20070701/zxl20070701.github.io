基于监听的事件处理机制

Android 中最常用的事件处理方式是基于监听（Listener），将事件源（View）和事件处理逻辑解耦。

常见事件监听器

监听器 触发时机
OnClickListener 点击事件。
OnLongClickListener 长按事件。
OnTouchListener 触摸事件。
OnFocusChangeListener 焦点变化。
OnCheckedChangeListener 勾选状态变化（RadioGroup / CheckBox）。

示例：按钮点击 

Button btn = findViewById(R.id.btn);
btn.setOnClickListener(v -> {
    Toast.makeText(this, "按钮被点击", Toast.LENGTH_SHORT).show();
});

示例：长按事件 

btn.setOnLongClickListener(v -> {
    Toast.makeText(this, "长按了按钮", Toast.LENGTH_SHORT).show();
    return true; // true 表示消费该事件
});
