Activity

Activity 是 Android 中负责界面交互的组件，是用户操作的入口。

基本用法

创建 Activity 

public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        // 设置布局
        setContentView(R.layout.activity_main);
    }
}

在清单文件中注册 

<application android:label="@string/app_name">
    <activity android:name=".MainActivity">
        <intent-filter>
            <action android:name="android.intent.action.MAIN" />
            <category android:name="android.intent.category.LAUNCHER" />
        </intent-filter>
    </activity>
</application>

生命周期

  • onCreate ：Activity 被创建时调用。
  • onStart ：Activity 即将可见。
  • onResume ：Activity 获得焦点，可以交互。
  • onPause ：Activity 失去焦点。
  • onStop ：Activity 不可见。
  • onDestroy ：Activity 被销毁。

启动方式

显式 Intent 

Intent intent = new Intent(this, SecondActivity.class);
startActivity(intent);

隐式 Intent 

Intent intent = new Intent(Intent.ACTION_VIEW);
intent.setData(Uri.parse("https://zxl20070701.github.io/notebook/index.html"));
startActivity(intent);
