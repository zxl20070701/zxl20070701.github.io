BroadcastReceiver

BroadcastReceiver 用于监听系统或应用发出的广播通知。

分类

  • 静态注册 ：在清单文件中注册，应用未启动也能接收广播。
  • 动态注册 ：在代码中注册，组件销毁时需要取消注册。

自定义广播接收器 

public class MyReceiver extends BroadcastReceiver {
    @Override
    public void onReceive(Context context, Intent intent) {
        String action = intent.getAction();
        // 处理广播逻辑
    }
}

静态注册 

<receiver android:name=".MyReceiver">
    <intent-filter>
        <action android:name="com.example.MY_BROADCAST" />
    </intent-filter>
</receiver>

动态注册 

MyReceiver receiver = new MyReceiver();
IntentFilter filter = new IntentFilter("com.example.MY_BROADCAST");
// Android 14（API 34）起需显式声明导出标志
ContextCompat.registerReceiver(this, receiver, filter,
        ContextCompat.RECEIVER_NOT_EXPORTED);

// 记得取消注册
unregisterReceiver(receiver);

发送自定义广播 

Intent intent = new Intent("com.example.MY_BROADCAST");
intent.putExtra("msg", "hello");
sendBroadcast(intent);
