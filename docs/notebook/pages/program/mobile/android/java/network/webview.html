WebView

WebView 用于在 App 内显示网页内容，也可以与 JavaScript 交互。

加载网页 

<WebView
    android:id="@+id/web_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />

WebView webView = findViewById(R.id.web_view);
webView.getSettings().setJavaScriptEnabled(true); // 启用 JS
webView.loadUrl("https://zxl20070701.github.io/notebook/index.html");

与 JavaScript 交互

Android 调用 JS 

webView.evaluateJavascript("javascript:showMessage('Hello')", null);

JS 调用 Android 

webView.addJavascriptInterface(new Object() {
    @android.webkit.JavascriptInterface
    public void callFromJs(String msg) {
        runOnUiThread(() -> {
            Toast.makeText(MainActivity.this, msg, Toast.LENGTH_SHORT).show();
        });
    }
}, "Android");

常用设置

设置 说明
setJavaScriptEnabled(true) 启用 JavaScript。
setSupportZoom(true) 支持缩放。
setCacheMode(...) 设置缓存策略。
setDomStorageEnabled(true) 启用 DOM 存储。
