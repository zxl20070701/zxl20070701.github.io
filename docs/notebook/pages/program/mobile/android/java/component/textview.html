TextView

TextView 用于显示一段文本内容，是最常用的控件之一。

常用属性

属性 描述
android:text 显示的文本内容。
android:textColor 文字颜色。
android:textSize 文字大小，常用单位 sp。
android:textStyle 文字样式：bold、italic、normal。
android:gravity 文字在控件中的对齐方式。
android:maxLines 最多显示行数。
android:ellipsize 超出部分的省略方式：start、end、middle、marquee。

示例 

<TextView
    android:id="@+id/tv_title"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Hello Android"
    android:textColor="#FF5722"
    android:textSize="20sp"
    android:textStyle="bold"
    android:maxLines="1"
    android:ellipsize="end" />

代码中动态修改 

TextView tv = findViewById(R.id.tv_title);
tv.setText("新的内容");
tv.setTextColor(Color.RED);
