EditText

EditText 是 TextView 的子类，允许用户输入文本。

常用属性

属性 描述
android:hint 输入框为空时显示的提示文字。
android:inputType 输入类型，如 text、number、textPassword、phone 等。
android:maxLength 最大输入长度。
android:maxLines 最多显示行数，设为 1 即单行（替代已废弃的 singleLine）。

示例 

<EditText
    android:id="@+id/et_name"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="请输入姓名"
    android:inputType="text"
    android:maxLength="20" />

获取输入内容 

EditText et = findViewById(R.id.et_name);
String name = et.getText().toString();
