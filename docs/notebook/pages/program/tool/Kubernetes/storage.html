持久化存储

容器是「短命」的，Pod 一旦重建，容器内部的文件就没了。持久化存储（PV / PVC）用来解决数据在 Pod 重建后依然存在的问题。

三个核心概念

  • PV（PersistentVolume）：集群中的一块存储资源，由管理员创建，代表「实际存在的存储」。
  • PVC（PersistentVolumeClaim）：对存储的「申请单」，由应用创建并声明需要多大的空间、什么访问模式。
  • StorageClass：存储的「规格说明」，描述这类存储用什么provisioner创建（本地磁盘、NFS、云盘等）。

一句话概括它们的配合： PVC 申请存储，StorageClass 负责动态创建 PV，PV 最终挂载到 Pod 上 。

使用 PVC 挂载存储

先声明一个 PVC： 

apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi

在 Deployment 中挂载它： 

apiVersion: apps/v1
kind: Deployment
metadata:
  name: hello
spec:
  replicas: 1
  selector:
    matchLabels:
      app: hello
  template:
    metadata:
      labels:
        app: hello
    spec:
      containers:
        - name: hello
          image: nginx:alpine
          volumeMounts:
            - name: data
              mountPath: /usr/share/nginx/html
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: data-pvc

应用后查看状态： 

kubectl apply -f pvc.yaml
kubectl get pvc

NAME       STATUS   VOLUME   CAPACITY   ACCESS MODES   STORAGECLASS   AGE
data-pvc   Bound    pvc-xxx  1Gi        RWO            standard       10s

STATUS 变成 Bound 就说明存储已经分配好了。

访问模式

模式 含义
ReadWriteOnce (RWO) 只能被一个节点挂载读写，大多数块存储的默认模式
ReadOnlyMany (ROX) 可以被多个节点以只读方式挂载
ReadWriteMany (RWX) 可以被多个节点同时读写，需要 NFS、CephFS 等支持
ReadWriteOncePod (RWOP) 只能被一个 Pod 挂载读写，Pod 释放后卷才能被其它 Pod 使用

StorageClass 与动态供应

kind 默认带有 standard 这个 StorageClass（使用 hostpath 动态供应）。查看集群里可用的存储类： 

kubectl get storageclass

NAME                   PROVISIONER             RECLAIMPOLICY   VOLUMEBINDINGMODE
standard (default)    kubernetes.io/host-path   Delete          WaitForFirstConsumer

声明 PVC 时指定存储类： 

apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  storageClassName: standard
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi

如果不写 storageClassName ，就会使用默认存储类。

本地目录与 emptyDir

有些场景不需要真正的持久化存储，可以用更轻量的 emptyDir ：它在 Pod 创建时生成一个空目录，Pod 被删除时数据一起消失。 

      volumes:
        - name: cache
          emptyDir: {}

常见用途是「缓存目录」和「临时共享目录」（比如多个容器之间交换中间文件）。

还可以用 emptyDir.medium: Memory 把它挂载到内存里，速度更快但会占用节点内存，且受内存 limit 限制。

清理资源 

# 查看存储相关资源
kubectl get pv
kubectl get pvc

# 删除 PVC（PV 的回收策略决定后续行为）
kubectl delete pvc data-pvc

# 手动删除 PV
kubectl delete pv pvc-xxxxx
PVC 删除后，PV 不会立刻消失，它会进入 Released 状态等待处理。回收策略为 Delete 时底层存储会被一并删除， Retain 则保留数据需要手动清理。
