编写 Dockerfile 并构建镜像

Dockerfile 是描述镜像构建步骤的文本文件。下面用 Nginx 托管一个静态页面，练习准备文件、构建镜像和运行容器。

准备项目文件

新建一个目录，在其中创建 index.html 和 Dockerfile 两个文件： 

<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>Docker 入门</title></head>
<body><h1>Hello from Docker</h1></body>
</html>

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html

FROM 指定基础镜像，COPY 将构建目录中的页面复制到镜像内 Nginx 默认的网站目录。

构建镜像

在包含 Dockerfile 的目录中运行构建命令。末尾的点表示将当前目录作为构建上下文： 

docker build -t my-nginx:1.0 .
docker image ls

运行构建好的镜像 

docker run --name my-nginx-demo -d my-nginx:1.0
docker logs my-nginx-demo

容器可以运行，但尚未将网站端口发布到主机，因此浏览器还无法从主机访问它。
