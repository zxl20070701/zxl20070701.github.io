环境与项目结构

Maven是什么

Maven是Java项目常用的构建和依赖管理工具。项目的基本信息、依赖和构建配置通常写在项目根目录的pom.xml中；Maven会根据配置下载依赖，并执行编译、测试和打包等任务。

环境准备

Maven运行需要JDK。安装JDK和Maven后，在终端检查环境： 

java -version
mvn -v

Maven Wrapper（项目中的mvnw或mvnw.cmd）可以按项目配置使用指定的Maven版本。若项目提供了Wrapper，优先使用它；首次运行时可能需要下载Maven和项目依赖。 

# macOS或Linux
./mvnw -v

# Windows
mvnw.cmd -v

项目结构

一个常见的Maven项目目录如下： 

demo/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/       # 应用源码
    │   └── resources/  # 应用资源
    └── test/
        ├── java/       # 测试源码
        └── resources/  # 测试资源

pom.xml定义项目配置和依赖，下一篇将介绍它的基本写法。Java主代码和测试代码分别放在src/main/java和src/test/java中。

常见问题

  • 提示找不到mvn：检查Maven是否已安装，以及Maven的bin目录是否加入PATH；有Wrapper时可直接使用Wrapper。
  • 无法使用指定的Java版本：确认java -version和JAVA_HOME指向预期的JDK。
