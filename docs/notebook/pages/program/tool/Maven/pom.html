pom.xml与依赖

项目坐标和基本配置

Maven通过groupId、artifactId和version标识一个项目（通常称为坐标）。下面的配置声明了项目坐标、Java版本和一个仅用于测试的JUnit依赖： 

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>demo</artifactId>
    <version>1.0.0-SNAPSHOT</version>

    <properties>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.release>17</maven.compiler.release>
    </properties>

    <dependencies>
        <dependency>
            <groupId>junit</groupId>
            <artifactId>junit</artifactId>
            <version>4.13.2</version>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.13.0</version>
            </plugin>
        </plugins>
    </build>
</project>

示例使用Java 17编译；请确保本机JDK版本不低于pom.xml配置的版本。dependencies用于声明项目依赖，build中的plugins用于配置构建插件。

依赖scope

依赖默认使用compile scope。常见scope的含义如下：

scope 用途
compile 默认值，参与主代码编译，并通常包含在运行时类路径中。
provided 编译和测试时可用，预期由运行环境提供，例如Servlet容器。
runtime 运行和测试时需要，但不参与主代码编译。
test 仅用于测试编译和测试运行，例如JUnit。

本机依赖仓库

Maven默认将下载的依赖保存到用户目录下的.m2/repository，供本机其他Maven项目复用。在pom.xml的dependencies中添加依赖后，执行编译或测试命令，Maven会解析并下载所需依赖。

如果依赖下载失败，请检查网络、仓库配置和依赖坐标；也可以使用mvn -U package重新检查远程依赖更新。
