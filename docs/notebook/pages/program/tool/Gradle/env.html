环境与项目结构

Gradle是什么

Gradle是面向多种语言和平台的构建自动化工具。在Java项目中，它可以管理依赖、编译和测试代码，并将项目打包。构建逻辑通常写在build.gradle或build.gradle.kts中，后者使用Kotlin DSL。

环境准备

Gradle运行需要JDK。先确认Java环境可用： 

java -version

安装Gradle后可以检查版本： 

gradle -v

项目通常会提交Gradle Wrapper（gradlew、gradlew.bat及gradle/wrapper目录），它会按项目配置使用对应版本的Gradle。进入项目根目录后优先使用Wrapper，避免本机Gradle版本与项目不一致。 

# macOS或Linux
./gradlew -v

# Windows
gradlew.bat -v

创建项目

安装Gradle后，可以通过init任务创建Java应用项目： 

mkdir demo
cd demo
gradle init --type java-application

按提示选择DSL和测试框架。初始化完成后，项目会包含Wrapper；后续构建和运行命令都可以使用./gradlew（Windows使用gradlew.bat）。

常见项目结构 

demo/
├── settings.gradle.kts
├── gradlew
├── gradlew.bat
├── gradle/
│   └── wrapper/
└── app/
    ├── build.gradle.kts
    └── src/
        ├── main/
        │   ├── java/       # 应用源码
        │   └── resources/  # 应用资源
        └── test/
            ├── java/       # 测试源码
            └── resources/  # 测试资源

settings.gradle.kts描述构建包含哪些项目；app/build.gradle.kts配置app子项目的插件、依赖和任务。项目规模较小时，构建脚本也可以放在根目录。

常见问题

  • 提示找不到Java或无法启动Gradle：检查JDK是否安装，以及JAVA_HOME和PATH是否指向预期的JDK。
  • Wrapper首次运行较慢：它可能需要下载Gradle发行版和项目依赖，请检查网络连接。
