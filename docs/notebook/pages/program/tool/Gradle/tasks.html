常用任务与命令

常用命令

在包含gradlew的项目根目录运行命令。Wrapper可以确保团队成员使用项目指定的Gradle版本。 

# 查看Gradle版本
./gradlew -v

# 查看可用任务
./gradlew tasks

# 编译主代码
./gradlew compileJava

# 运行测试
./gradlew test

# 构建项目（包括编译、测试和打包等）
./gradlew build

# 运行Application插件配置的应用
./gradlew run

# 清理构建产物
./gradlew clean

Windows命令提示符或PowerShell中使用gradlew.bat替代./gradlew。

任务与构建生命周期

Gradle将构建工作组织为任务。任务可以依赖其他任务；执行build等任务时，Gradle会按依赖关系执行所需工作。Java插件提供compileJava、test、jar、build和clean等常用任务。

构建产物通常位于对应项目的build目录。例如，app子项目的产物会生成在app/build中。可使用./gradlew :app:tasks查看子项目任务，或用./gradlew :app:test运行指定子项目的测试。

Wrapper维护

Wrapper配置位于gradle/wrapper/gradle-wrapper.properties。需要升级Gradle时，可使用本机Gradle执行： 

gradle wrapper --gradle-version 8.10.2

将生成或更新的Wrapper文件与项目配置一起提交，其他开发者即可通过Wrapper使用指定版本。升级前请确认该Gradle版本与项目使用的JDK及插件兼容。

常见问题

  • 任务不存在：运行./gradlew tasks确认当前项目包含该任务；多项目构建时检查是否需要使用:子项目名:任务名。
  • 依赖下载失败：检查网络和仓库配置，确认依赖坐标有效。
  • 构建使用了错误的Java版本：检查JAVA_HOME，并核对构建脚本中的Java toolchain配置。
