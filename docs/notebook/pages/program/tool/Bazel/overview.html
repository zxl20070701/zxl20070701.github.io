安装与基本概念

Bazel 是一个开源构建工具，适用于多语言、多平台项目。它根据目标之间声明的依赖关系执行构建，并缓存构建结果，适合从小型项目到大型代码仓库。

安装

初学时建议安装 Bazelisk。它提供 bazel 命令，并能根据项目中的 .bazelversion 自动选择对应版本，避免团队成员使用不同版本的 Bazel。

macOS 可使用 Homebrew 安装： 

brew install bazelisk
bazel --version

Windows、Linux 以及其他安装方式请参考 Bazel 官方安装指南。 安装完成后，可在项目根目录创建 .bazelversion 并填写团队选定的 Bazel 版本号，以固定构建版本。

先认识几个概念

  • 工作区（workspace）：项目的源码目录；在现代 Bazel 项目中，通常由根目录的 MODULE.bazel 声明模块信息和外部模块依赖。
  • 包（package）：包含 BUILD 或 BUILD.bazel 文件的目录。每个 BUILD 文件定义一个包。
  • 目标（target）：BUILD 文件中声明的可构建单元，例如可执行程序、库或测试。
  • 标签（label）：目标的唯一名称。例如根目录包里的 //:hello； //lib:greeter 表示 lib 包中的 greeter 目标。

入门时优先使用 Bzlmod（ MODULE.bazel ）管理模块依赖。较早的项目可能使用 WORKSPACE 文件；阅读旧项目时会遇到它，但新项目不必从 WORKSPACE 开始。
