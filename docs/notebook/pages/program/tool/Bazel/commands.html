构建、运行与测试命令

以下命令在包含 MODULE.bazel 的项目根目录执行。以“创建第一个项目”中的 hello 和 greeter_test 目标为例。

常用命令 

# 构建一个目标
bazel build //:hello

# 构建当前工作区中的所有目标
bazel build //...

# 构建并运行可执行目标
bazel run //:hello

# 运行一个测试目标
bazel test //:greeter_test

# 运行工作区中的全部测试
bazel test //...

目标标签

  • //:hello：根目录包中的 hello 目标。
  • //lib:greeter：lib 包中的 greeter 目标。
  • //...：当前工作区下所有包和目标，常用于批量构建或测试。

常见选项 

# 显示更详细的构建过程
bazel build --verbose_failures //:hello

# 强制重新执行测试，不使用测试结果缓存
bazel test --cache_test_results=no //:greeter_test

Bazel 会缓存构建产物和测试结果；输入和依赖未改变时，重复执行通常会更快。若遇到缓存相关的问题，先确认目标、输入和构建配置，再按需使用清理命令，不要把每次构建前执行清理作为常规步骤。

想了解完整选项，可运行 bazel help 或查看 官方构建命令文档。
