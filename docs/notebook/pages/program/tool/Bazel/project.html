创建第一个项目

下面创建一个由可执行程序、库和测试组成的 C++ 项目。示例目录结构如下： 

hello-bazel/
├── MODULE.bazel
├── BUILD
├── main.cc
├── greeter.h
├── greeter.cc
└── greeter_test.cc

在项目根目录创建 MODULE.bazel，声明模块名称和版本： 

module(
    name = "hello_bazel",
    version = "1.0",
)

创建 greeter.h 和 greeter.cc，分别声明和实现一个函数： 

// greeter.h
#ifndef GREETER_H
#define GREETER_H

#include <string>

std::string greet();

#endif

// greeter.cc
#include "greeter.h"

std::string greet() {
    return "Hello, Bazel!";
}

创建程序入口 main.cc： 

#include <iostream>
#include "greeter.h"

int main() {
    std::cout << greet() << '\n';
    return 0;
}

再创建一个简单测试 greeter_test.cc。测试程序返回非零状态时，Bazel 会将测试标记为失败： 

#include <cassert>
#include "greeter.h"

int main() {
    assert(greet() == "Hello, Bazel!");
    return 0;
}

最后在根目录的 BUILD 文件中声明这些构建目标： 

cc_library(
    name = "greeter",
    srcs = ["greeter.cc"],
    hdrs = ["greeter.h"],
)

cc_binary(
    name = "hello",
    srcs = ["main.cc"],
    deps = [":greeter"],
)

cc_test(
    name = "greeter_test",
    srcs = ["greeter_test.cc"],
    deps = [":greeter"],
)

进入项目根目录后，构建并运行程序： 

bazel build //:hello
bazel run //:hello

运行测试： 

bazel test //:greeter_test

//:hello 是根目录包中名为 hello 的目标； :greeter 是同一个包中的目标。BUILD 中的 deps 声明了目标间的依赖关系，Bazel 会据此确定构建顺序。
