useTransition

帮助你在不阻塞 UI 的情况下更新状态。

语法 

let [isPending, startTransition] = useTransition()
  • isPending： 告诉你是否存在待处理的transition。
  • startTransition： 你可以使用此方法将状态更新标记为transition。

使用说明和举例

基本用法

useTransition 允许你将某些状态更新标记为"过渡"状态，这些状态更新不会阻塞 UI 的渲染，从而提升用户体验。 

function SearchInput() {
    const [query, setQuery] = useState('')
    const [isPending, startTransition] = useTransition()
    const [list, setList] = useState([])

    function handleChange(e) {
        setQuery(e.target.value)
        startTransition(() => {
            const newList = Array(100).fill(0).map((_, i) =>
                `Item ${i}: ${e.target.value}`
            )
            setList(newList)
        })
    }

    return (
        <div>
            <input value={query} onChange={handleChange} />
            {isPending && <div>加载中...</div>}
            <ul>
                {list.map((item, i) => <li key={i}>{item}</li>)}
            </ul>
        </div>
    )
}

在上面的例子中，当用户输入时：

  • setQuery：立即更新输入框的值，这是紧急更新。
  • setList：被包裹在 startTransition 中，是非阻塞的过渡更新。
  • isPending：在过渡更新进行中为 true，可以用来显示加载状态。
