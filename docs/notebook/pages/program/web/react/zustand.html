Zustand

引入和定义

首先，你需要安装 zustand 并创建Store： 

// stores/login.store.js
import { create } from 'zustand'

const useLoginStore = create((set) => ({
    isLogin: false,

    // 修改状态
    changeLoginState: (loginFlag) => set({
        isLogin: loginFlag === 'YES' ? true : false
    })
}))

export default useLoginStore
与Redux不同，Zustand不需要 reducer和 action的区分，状态和修改方法直接定义在一起，更加简洁。

现在，就准备好可以使用了。

获取状态

在组件中获取 isLogin 和修改方法，可以这样： 

import useLoginStore from './stores/login.store'

function App() {
    // 按需获取，避免不必要的渲染
    const isLogin = useLoginStore(state => state.isLogin)
    const changeLoginState = useLoginStore(state => state.changeLoginState)

    return (
        <div>
            <p>登录状态：{isLogin ? '已登录' : '未登录'}</p>
            <button onClick={() => changeLoginState('YES')}>登录</button>
        </div>
    )
}

使用选择器函数 state => state.xxx 可以精确订阅某个状态，只有该状态变化时组件才会重新渲染，性能更好。

修改状态

除了在定义时通过 set 方法创建修改函数外，也可以在任意地方调用： 

import useLoginStore from './stores/login.store'

// 在事件处理或异步逻辑中直接调用
useLoginStore.getState().changeLoginState('YES')

// 也可以直接使用 set 修改
useLoginStore.setState({ isLogin: true })

使用 getState() 可以在组件外部获取当前状态，使用 setState() 可以直接修改状态，无需通过 dispatch 派发action。

监听变化

如果需要在组件外部监听状态变化，可以使用 subscribe： 

import useLoginStore from './stores/login.store'

// 订阅指定状态的变化
useLoginStore.subscribe(
    state => state.isLogin,
    isLogin => {
        console.log('登录状态变化：', isLogin)
    }
)
默认的 subscribe 监听整个state，配合选择器可以只监听关心的部分。如需使用选择器版本的subscribe，需要引入 zustand/middleware 中的 subscribeWithSelector 中间件。

对比 Redux，Zustand省去了 action.type、 reducer和 combineReducers 等样板代码，API更少，上手更简单。
