项目结构与进程模型

Electron 应用由主进程和一个或多个渲染进程组成。主进程管理应用生命周期、创建窗口并访问原生能力；渲染进程运行网页界面。Preload 脚本在两者之间提供受控的桥梁。

创建窗口

主进程使用 BrowserWindow 创建应用窗口。以下是简化示例；Electron Forge 脚手架生成的入口路径可能不同。 

const { app, BrowserWindow } = require("electron");
const path = require("node:path");

function createWindow() {
    const window = new BrowserWindow({
        webPreferences: {
            preload: path.join(__dirname, "preload.js"),
            contextIsolation: true,
            nodeIntegration: false
        }
    });

    window.loadFile("index.html");
}

app.whenReady().then(createWindow);

Preload 与渲染页面

Preload 在页面加载前运行。用 contextBridge 暴露经过筛选的函数，而不是把 Node.js 的 require 或整个 IPC 对象直接交给页面。 

const { contextBridge } = require("electron");

contextBridge.exposeInMainWorld("desktop", {
    electronVersion: process.versions.electron
});

页面通过 window.desktop.electronVersion 读取该值。访问主进程功能时，应进一步通过明确的 IPC 通道实现。

牢记安全默认值

对加载远程内容的窗口尤其要谨慎：保持 contextIsolation 开启、nodeIntegration 关闭；不要在渲染进程中直接使用 Node API。仅加载可信页面，及时更新 Electron，并按 Electron 安全指南 检查应用配置。
