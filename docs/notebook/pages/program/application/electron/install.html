安装与创建项目

Electron 使用 Chromium 显示应用界面，并通过 Node.js 主进程访问桌面能力。建议初学者使用 Electron Forge 创建项目，它会生成开发脚本和打包配置。

安装前准备

安装 Node.js 的 LTS 版本，并确认 npm 可用： 

node --version
npm --version

创建 Electron 项目

在项目所在目录运行 Electron Forge 脚手架： 

npm init electron-app@latest my-electron-app
cd my-electron-app

脚手架会生成应用入口和 Forge 配置。首次运行开发模式前按提示安装项目依赖。

启动应用 

npm start

成功后会打开桌面窗口。开发过程中修改代码后，可按项目脚本重新启动或使用模板配置的开发工具。

生成安装包

Electron Forge 项目可以使用下面的命令构建并打包： 

npm run make

安装包会生成在项目的 out/make/ 目录。不同操作系统的打包目标和签名要求不同；准备发布时请查看 Electron Forge 文档。

本教程使用 Electron Forge。仓库中另有 electron-builder 相关问题记录；Forge 与 electron-builder 是不同的打包方案，请根据项目实际配置选择，不要把两套配置命令混用。
