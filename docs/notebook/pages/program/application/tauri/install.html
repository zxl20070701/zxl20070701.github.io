环境搭建与创建项目

Tauri 使用系统 WebView 显示前端界面，并以 Rust 实现桌面端功能。开始前需要安装 Rust 工具链和当前操作系统所需的原生依赖；如果前端使用 JavaScript 或 TypeScript，还需要安装 Node.js。

安装开发环境

  • Rust：通过 rustup 安装，并确认终端可以运行 rustc --version 和 cargo --version。
  • macOS：仅开发桌面应用可先安装 Xcode Command Line Tools，执行 xcode-select --install。
  • Windows：安装 Visual Studio C++ Build Tools 的“使用 C++ 的桌面开发”工作负载，以及 Microsoft Edge WebView2 Runtime。
  • Linux：根据发行版安装 WebKitGTK、编译工具链和相关系统开发库。依赖包名称因发行版而异，请按 Tauri 官方先决条件说明 选择对应命令。

本教程使用 npm 展示命令；也可以选择 pnpm、Yarn 等包管理器，执行时将命令替换为对应工具的写法。

创建项目

在希望保存项目的目录执行官方脚手架： 

npm create tauri-app@latest

按提示填写项目名称和应用标识符，选择前端语言、包管理器及界面模板。初学者可以选择 Vanilla + JavaScript，也可以选择熟悉的 Vue、React 或 Svelte 模板。

安装依赖并启动

进入新建的项目目录，安装前端依赖并启动桌面开发模式： 

cd tauri-app
npm install
npm run tauri dev

首次运行时，Rust 依赖需要编译，启动可能会花一些时间。成功后会打开桌面窗口；之后修改前端代码通常可以通过开发服务器热更新看到效果。

项目中的主要目录

  • src/：前端页面和应用代码，具体结构由所选模板决定。
  • src-tauri/：Tauri 与 Rust 后端代码、Cargo 配置及桌面应用配置。
  • src-tauri/tauri.conf.json：应用名称、标识符、开发命令和打包资源等配置。
