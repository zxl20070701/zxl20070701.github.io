前端调用 Rust

Tauri command 是前端调用 Rust 后端函数的常用方式。Rust 函数需要使用 #[tauri::command] 标记，并注册到应用；前端通过 invoke 按命令名调用。参数使用 JSON 对象传递，字段名使用 camelCase。

在 Rust 中定义并注册命令

在 Tauri Rust 入口（模板通常位于 src-tauri/src/lib.rs 或 src-tauri/src/main.rs）中添加命令： 

#[tauri::command]
fn greet(name: String) -> String {
    format!("你好，{name}！")
}

pub fn run() {
    tauri::Builder::default()
        .invoke_handler(tauri::generate_handler![greet])
        .run(tauri::generate_context!())
        .expect("运行 Tauri 应用失败");
}

这是应用初始化部分的示意。若模板已经提供 run 函数或 main 入口，请将命令注册到现有的 Builder 链中，不要再额外创建第二个入口函数。

在前端调用

JavaScript/TypeScript 脚手架通常已包含 @tauri-apps/api。若项目尚未安装，可在项目根目录执行： 

npm install @tauri-apps/api

import { invoke } from "@tauri-apps/api/core";

async function sayHello() {
    try {
        const message = await invoke("greet", { name: "Rust" });
        console.log(message);
    } catch (error) {
        console.error("调用 greet 命令失败：", error);
    }
}

Rust 参数 name 对应前端对象中的 name 属性。命令调用是异步的，返回值会作为 Promise 的结果；调用失败时应处理拒绝状态。

数据类型与错误处理

Tauri 会在 Rust 与 JavaScript 之间序列化数据。命令的参数和返回值需要使用可序列化类型；对复杂类型通常会使用 serde。如果命令可能失败，可以返回 Result<T, E>，其中错误类型需要可序列化（例如 String），并让前端处理调用失败，而不是将错误伪装成正常结果。

修改 Rust 代码后，开发构建需要重新编译后端。若命令未注册、名称不一致或参数不能序列化，前端调用会失败，请同时检查 Rust 输出和浏览器控制台。
