隐私政策

本网站（zxl20070701.github.io/notebook，下称“本站”）由 GitHub Pages 托管，向访问者提供编程、数学、计算机、英语、历史、经济学等原创笔记与文档内容。本站重视您的隐私，本政策说明本站如何处理与您相关的信息。

一、我们收集的信息

本站不提供登录账号，不主动收集您的姓名、邮箱、手机号等个人身份信息。您访问本站时，托管服务商 GitHub Pages 及网络基础设施可能会自动记录标准访问日志（如 IP 地址、浏览器类型、访问时间等），用于站点运行与安全维护，我们不会将其用于广告定向。

二、广告与 Cookie

本站展示 Google AdSense 提供的广告。Google 及其广告合作伙伴可能使用 Cookie 或类似技术，根据您过去访问本站及其他网站的情况，向您展示个性化或非个性化广告。有关 Google 如何使用此类信息的说明，请参阅 Google 的隐私政策及其“Google 如何利用数据”说明。

您可以通过 Google 的广告设置页面管理并停用个性化广告；也可以通过 www.aboutads.info 选择退出部分第三方广告商的 Cookie 使用。清除浏览器 Cookie 也会影响个性化广告的展示，但不影响本站正常浏览。

三、第三方链接

本站部分内容可能包含指向第三方网站（如 GitHub、外部文档等）的链接。这些网站受各自隐私政策的约束，本站不对其处理行为负责，请您在使用时留意。

四、您的选择

您可以在浏览器中随时清除本站相关的 Cookie，或启用浏览器的“禁止跟踪”功能。上述操作不会影响您阅读本站内容。
